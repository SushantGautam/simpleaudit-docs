    Simpleaudit reframing

    simpleaudit.reframing

    Re-grade stored transcripts with the judge only, varying one thing at a time.

    Re-grade stored transcripts with the judge only, varying one thing at a time.

    The reproducibility leg of an audit resamples: the same scenario is run n_repetitions times and the spread of the verdicts is reported. Resampling varies the conversation as well as the grading, so a verdict that moves may be telling you about the target, the auditor, or the judge.

    This module holds the transcript fixed and lets exactly one grading condition vary per variant:

    • the wording of the judge prompt (the original reframing check);
    • the judge model or client, so two graders read one transcript (CrossJudgeExperiment cannot do this: each judge there regenerates its own transcripts and, by default, serves as its own auditor);
    • nothing at all, graded k times, which isolates judge-only sampling noise from target and auditor noise;
    • a deterministic perturbation of the transcript's assistant turns, which measures how much a style artifact (an apology, a disclaimer, padding, an authority claim) moves the verdict on unchanged substance. Built-in perturbations live in :mod:simpleaudit.perturbations.

    A verdict that survives resampling but flips between two semantically equivalent rubrics, two judges, or a transcript with and without an apology is measuring the apparatus rather than the target.

    Nothing here calls the target model or the auditor. The transcripts are already stored, so every check costs judge tokens only. Variants are supplied by the caller and never generated by a model: a tool built to detect apparatus-induced verdict movement cannot introduce a model-generated axis of its own.

    The judge call never sets temperature; k resampling therefore measures the provider's default sampling.

    Usage::

    from simpleaudit.judges import get_judge
from simpleaudit.reframing import (
    PromptVariant, load_stored_records, make_judge_client, reframing_check,
)

base = get_judge("safety")["judge_prompt"]
records = load_stored_records("examples/nav_aap/nav_aap_sonnet_4_6.json")
client = make_judge_client("anthropic")

# Prompt wording
results = reframing_check(client, "claude-opus-4-7", records, [
    PromptVariant("baseline", base),
    PromptVariant("reordered", reordered_rubric_text),
])
for entry in results.shifts():
    if entry["shifted"]:
        print(entry["scenario"], entry["modals"], entry["direction"])

# Judge swap on the same transcripts, then a panel over the two
results = reframing_check(client, "claude-opus-4-7", records, [
    PromptVariant("opus", base),
    PromptVariant("haiku", base, judge_model="claude-haiku-4-5-20251001"),
])
print(results.panel().flagged())

# Judge-only resampling
results = reframing_check(client, "claude-opus-4-7", records,
                          [PromptVariant("safety", base)], k=5)
print(results.fragile())

class PanelResults:
    """Per-scenario panel verdicts over a set of judge variants."""

    labels: List[str]
    per_scenario: Dict[str, PanelVerdict] = field(default_factory=dict)

    def unanimous_rate(self) -> float:
        """Fraction of scenarios on which every judge agreed; 0.0 when empty."""
        if not self.per_scenario:
            return 0.0
        return sum(1 for v in self.per_scenario.values() if v.unanimous) / len(self.per_scenario)

    def flagged(self, threshold: float = FRAGILE_THRESHOLD_DEFAULT) -> List[str]:
        """Scenarios whose majority share is below *threshold*: a review queue.

        Strict comparison, matching ``ModelStabilityReport.fragile``.
        """
        if not 0.0 <= threshold <= 1.0:
            raise ValueError(f"threshold must be between 0.0 and 1.0, got {threshold}.")
        return [name for name, v in self.per_scenario.items() if v.majority_share < threshold]

    def to_dict(self) -> Dict[str, Any]:
        return {
            "labels": list(self.labels),
            "per_scenario": {k: v.to_dict() for k, v in self.per_scenario.items()},
            "unanimous_rate": self.unanimous_rate(),
            "flagged": self.flagged(),
        }

class PromptVariant:
    """One grading condition.

    The original use is one wording of the judge prompt. A variant may also
    name its own judge (``judge_model`` / ``judge_client``, falling back to the
    call-level values) and carry a ``transform`` applied to the transcript
    before grading. Whatever it varies, the transcript's substance is held
    fixed by the caller.

    Variants are supplied explicitly rather than generated. A tool built to
    detect apparatus-induced verdict movement cannot introduce a
    model-generated prompt, judge or perturbation of its own: that would be an
    uncontrolled axis inside the instrument measuring that axis.
    """

    label: str
    judge_prompt: str
    response_schema: Optional[Dict[str, Any]] = None
    judge_model: Optional[str] = None
    judge_client: Any = None
    transform: Optional[Transform] = None
    #: Applied to the parsed judge output (see judges/checklist.py). Recorded
    #: in variant_meta; a panel refuses variants that differ in it.
    postprocess: Optional[Callable[..., Dict[str, Any]]] = None
    #: Records without expected_behavior are graded by the default judge
    #: instead (same fallback as ModelAuditor), tagged judge_fallback.
    requires_expected_behavior: bool = False

    @classmethod
    def from_judge(
        cls, name: Union[str, Dict[str, Any]], label: Optional[str] = None, **overrides: Any
    ) -> "PromptVariant":
        """A variant carrying a judge's prompt, schema and hooks.

        ``name`` is a registry name or a config dict (see judges/compose.py).

        ``overrides`` are any other field (``judge_model``, ``judge_client``,
        ``transform``, ...) and win over the config's values.
        """
        config = get_judge(name)
        _refuse_code_graded(config, name)
        fields: Dict[str, Any] = {
            "label": label or (config.get("name") or "custom judge" if isinstance(name, dict) else name),
            "judge_prompt": config["judge_prompt"],
            "response_schema": config.get("response_schema"),
            "postprocess": config.get("postprocess"),
            "requires_expected_behavior": bool(config.get("requires_expected_behavior")),
        }
        fields.update(overrides)
        return cls(**fields)

class ReframingResults:
    """Verdicts for every (scenario, variant) pair, and the movement between them.

    Attributes
    ----------
    variant_labels : list of str
        Variant labels in the order they were run.
    per_scenario : dict
        ``{scenario_name: {variant_label: modal_severity}}``. At ``k=1`` the
        modal is the one verdict.
    judgments : dict
        ``{scenario_name: {variant_label: raw_judgment_dict}}`` — the judge
        output behind the modal verdict (the first sample that produced it),
        kept so a shift can be read back to its reasoning.
    input_tokens, output_tokens : int
        Judge tokens spent. No target tokens are spent on this path.
    k : int
        Samples per (scenario, variant) cell.
    baseline_label : str or None
        Variant that ``effects()`` compares against; the first variant if unset.
    samples : dict
        ``{scenario_name: {variant_label: [severity, ...]}}`` — every sample.
    sample_judgments : dict
        ``{scenario_name: {variant_label: [raw_judgment_dict, ...]}}``.
    variant_meta : dict
        ``{variant_label: {judge_model, judge_client_id, prompt_sha1,
        schema_sha1, transform}}`` — what each variant actually varied, so a
        result file is self-describing and ``panel()`` can check its inputs.
    tokens_by_variant : dict
        ``{variant_label: {"input": n, "output": n}}``.
    """

    variant_labels: List[str]
    per_scenario: Dict[str, Dict[str, str]] = field(default_factory=dict)
    judgments: Dict[str, Dict[str, Dict[str, Any]]] = field(default_factory=dict)
    input_tokens: int = 0
    output_tokens: int = 0
    k: int = 1
    baseline_label: Optional[str] = None
    samples: Dict[str, Dict[str, List[str]]] = field(default_factory=dict)
    sample_judgments: Dict[str, Dict[str, List[Dict[str, Any]]]] = field(default_factory=dict)
    variant_meta: Dict[str, Dict[str, Any]] = field(default_factory=dict)
    tokens_by_variant: Dict[str, Dict[str, int]] = field(default_factory=dict)

    # -- existing surface, unchanged semantics --------------------------------

    def shifts(self) -> List[Dict[str, Any]]:
        """Per-scenario modal verdicts across variants, with shift detection.

        Returns
        -------
        list of dict
            One entry per scenario:

            - ``scenario``: scenario name
            - ``modals``: ``{variant_label: severity}`` — only variants that
              actually produced a verdict appear
            - ``shifted``: True if any two variants disagree
            - ``direction``: (two-variant case only) ``idx_b - idx_a`` in
              ``SEVERITY_ORDER``; positive means the second variant is
              stricter. None when either verdict is off the ladder.

        The shape matches ``CrossJudgeResults.severity_shifts()`` so the same
        reporting code reads both. For three or more variants there is no
        single direction; use :meth:`effects` for pairwise movement against
        the baseline.
        """
        out = []
        for name, by_variant in self.per_scenario.items():
            modals = {label: by_variant[label] for label in self.variant_labels if label in by_variant}
            entry: Dict[str, Any] = {
                "scenario": name,
                "modals": modals,
                "shifted": len(set(modals.values())) > 1,
            }
            if entry["shifted"] and len(modals) == 2 and len(self.variant_labels) == 2:
                first, second = self.variant_labels
                entry["direction"] = severity_direction(modals[first], modals[second])
            out.append(entry)
        return out

    def invariant_rate(self) -> float:
        """Fraction of scenarios whose modal verdict is identical across all variants.

        Returns 0.0 for an empty result rather than raising, so a caller
        reporting several runs side by side does not need to special-case one
        that produced nothing.
        """
        if not self.per_scenario:
            return 0.0
        stable = sum(1 for entry in self.shifts() if not entry["shifted"])
        return stable / len(self.per_scenario)

    # -- resampling ----------------------------------------------------------

    def stability(self) -> Dict[str, Dict[str, SampleStats]]:
        """Per-cell sample statistics: ``{scenario: {variant_label: SampleStats}}``."""
        return {
            name: {label: _sample_stats(sevs) for label, sevs in by_label.items()}
            for name, by_label in self.samples.items()
        }

    def fragile(
        self, threshold: float = FRAGILE_THRESHOLD_DEFAULT
    ) -> Dict[str, Dict[str, SampleStats]]:
        """Cells whose modal share is below *threshold* (strict), keyed like
        :meth:`stability`. Scenarios with no fragile cell are omitted.

        Warns when ``k < 2``: one sample cannot disagree with itself, so an
        empty result then means "not measured", not "nothing is fragile".
        """
        if not 0.0 <= threshold <= 1.0:
            raise ValueError(
                f"threshold must be between 0.0 and 1.0, got {threshold}. "
                "It is compared against the modal-verdict share, a fraction."
            )
        if self.k < 2:
            warnings.warn(
                f"fragile() needs k >= 2 to mean anything — this result has k={self.k}. "
                "Every cell will read as stable because a single sample cannot disagree "
                "with itself. Re-run with k > 1.",
                stacklevel=2,
            )
        out: Dict[str, Dict[str, SampleStats]] = {}
        for name, by_label in self.stability().items():
            hits = {label: st for label, st in by_label.items() if st.agreement_rate < threshold}
            if hits:
                out[name] = hits
        return out

    # -- effects against the baseline ----------------------------------------

    def _resolve_baseline(self, baseline: Optional[str]) -> str:
        chosen = baseline or self.baseline_label or (self.variant_labels[0] if self.variant_labels else None)

    async def reframing_check_async(
    judge_client: Any,
    judge_model: str,
    records: Sequence[StoredRecord],
    variants: Sequence[PromptVariant],
    json_format: bool = True,
    max_retries: int = 0,
    retry_backoff: float = 0.5,
    k: int = 1,
    max_concurrency: int = 1,
    baseline: Optional[str] = None,
) -> ReframingResults:
    """
    Re-grade every stored transcript ``k`` times per variant.

    Parameters
    ----------
    judge_client : Any
        An AnyLLM client for the judge. Variants may override it.
    judge_model : str
        Judge model identifier. Variants may override it.
    records : sequence of StoredRecord
        Transcripts to re-grade, e.g. from ``load_stored_records()``.
    variants : sequence of PromptVariant
        At least two grading conditions, or exactly one when ``k > 1``
        (resampling one judge is itself a comparison).
    json_format : bool, default True
        Whether the judge is asked for schema-constrained JSON.
    max_retries, retry_backoff
        Forwarded to the judge call.
    k : int, default 1
        Samples per (scenario, variant) cell. The judge call does not set
        ``temperature``, so this measures the provider's default sampling.
    max_concurrency : int, default 1
        Judge calls in flight at once. Results are assigned by position, so
        the value never changes what is reported, only how fast.
    baseline : str, optional
        Variant label that ``effects()`` compares against. Defaults to the
        first variant.

    Returns
    -------
    ReframingResults
    """
    if k < 1:
        raise ValueError(f"k must be >= 1, got {k}.")
    if max_concurrency < 1:
        raise ValueError(f"max_concurrency must be >= 1, got {max_concurrency}.")
    if len(variants) < 2 and k == 1:
        raise ValueError(
            "variants must contain at least two entries — one wording yields nothing to compare "
            "(pass k > 1 to resample a single variant instead)."
        )
    if not variants:
        raise ValueError("variants must contain at least one entry.")
    labels = [variant.label for variant in variants]
    if len(set(labels)) != len(labels):
        raise ValueError(f"variant labels must be unique, got {labels}.")
    if baseline is not None and baseline not in labels:
        raise ValueError(f"baseline {baseline!r} is not one of the variant labels {labels}.")
    _warn_on_duplicate_names([record.scenario_name for record in records])

    results = ReframingResults(variant_labels=labels, k=k, baseline_label=baseline or labels[0])
    for variant in variants:
        results.variant_meta[variant.label] = _variant_meta(variant, judge_client, judge_model)
        results.tokens_by_variant[variant.label] = {"input": 0, "output": 0}

    # Prepare every (record, variant) cell once — a transform runs once per
    # cell, not once per sample — and validate it before spending any tokens.
    prepared: Dict[tuple, List[Dict[str, Any]]] = {}
    for ri, record in enumerate(records):
        for vi, variant in enumerate(variants):
            conversation = record.conversation
            if variant.transform is not None:
                conversation = variant.transform(record.conversation)
                _check_transform_output(record.conversation, conversation, variant.label)
            prepared[(ri, vi)] = conversation

    jobs = [(ri, vi, rep) for ri in range(len(records)) for vi in range(len(variants)) for rep in range(k)]
    semaphore = asyncio.Semaphore(max_concurrency)

    def make_call(ri: int, vi: int):
        record, variant = records[ri], variants[vi]
        client = variant.judge_client if variant.judge_client is not None else judge_client
        model = variant.judge_model or judge_model
        return _grade(
            client,
            model,
            record.scenario_description or record.scenario_name,
            prepared[(ri, vi)],
            record.expected_behavior,
            variant.judge_prompt,
            variant.response_schema,
            json_format,
            max_retries,
            retry_backoff,
            semaphore,
            postprocess=variant.postprocess,
            scenario_meta=record.scenario_meta(),
            requires_expected_behavior=variant.requires_expected_behavior,
        )

    outcomes = await asyncio.gather(*(make_call(ri, vi) for ri, vi, _ in jobs))

    # Assemble per record in order, so a later record with a duplicate name
    # overwrites an earlier one rather than merging samples with it.
    per_record: Dict[int, Dict[str, List[Any]]] = {}
    per_record_raw: Dict[int, Dict[str, List[Any]]] = {}
    for (ri, vi, _), (judgment, tokens_in, tokens_out) in zip(jobs, outcomes, strict=True):
        label = variants[vi].label
        per_record.setdefault(ri, {}).setdefault(label, []).append(
            ModelAuditor._severity_from_judgment(judgment)
        )
        per_record_raw.setdefault(ri, {}).setdefault(label, []).append(judgment)
        results.input_tokens += tokens_in
        results.output_tokens += tokens_out
        results.tokens_by_variant[label]["input"] += tokens_in
        results.tokens_by_variant[label]["output"] += tokens_out

    for ri, record in enumerate(records):
        name = record.scenario_name
        by_label = per_record.get(ri, {})
        raw_by_label = per_record_raw.get(ri, {})
        results.samples[name] = {label: list(sevs) for label, sevs in by_label.items()}
        results.sample_judgments[name] = {label: list(js) for label, js in raw_by_label.items()}
        results.per_scenario[name] = {}
        results.judgments[name] = {}
        for label, sevs in by_label.items():
            modal = _modal(sevs)
            results.per_scenario[name][label] = modal
            results.judgments[name][label] = raw_by_label[label][sevs.index(modal)]

    return results

    async def rejudge_async(
    results_or_path: Union[AuditResults, str, Path],
    judge_client: Any,
    judge_model: str,
    judge_prompt: Optional[str] = None,
    response_schema: Optional[Dict[str, Any]] = None,
    json_format: bool = True,
    max_retries: int = 0,
    retry_backoff: float = 0.5,
    max_concurrency: int = 1,
    judge: Optional[Union[str, Dict[str, Any]]] = None,
    postprocess: Optional[Callable[..., Dict[str, Any]]] = None,
    scenario_severities: Optional[Mapping[str, str]] = None,
) -> AuditResults:
    """
    Grade a saved run again under another judge, keeping every transcript.

    Returns a new ``AuditResults`` whose judge fields (severity, issues,
    positive behaviours, summary, recommendations, raw judgment, judge
    tokens) come from the new judge and whose conversations, expectations,
    auditor tokens and target tokens are copied unchanged. The output has the
    same scenario set as the input, so it drops straight into
    ``compare_judges`` or ``RepeatedExperimentResults``.

    ``judge`` names a registry config (``"checklist"``, ``"safety"``, ...) and
    supplies its prompt, schema and hooks wherever the explicit arguments are
    None, with the same precedence as ``ModelAuditor(judge=..., judge_prompt=
    ...)``. With neither ``judge`` nor ``judge_prompt`` the built-in default
    judge is used. Scenario-level ``judge_notes`` are not stored on results
    and cannot be reapplied here.

    ``scenario_severities`` (``{scenario name: designed severity}``) supplies
    the ceiling a checklist post-processor derives against, for saved runs
    that do not already record it in their judgments. Without it the ceiling
    defaults to medium and a warning says so.

    Entries with an empty conversation are kept as ``ERROR`` results (with one
    warning) rather than dropped, so scenario sets stay aligned.
    """
    if max_concurrency < 1:
        raise ValueError(f"max_concurrency must be >= 1, got {max_concurrency}.")
    if isinstance(results_or_path, (str, Path)):
        source = AuditResults.load(str(results_or_path))
    else:
        source = results_or_path

    requires_expected_behavior = False
    if judge is not None:
        config = get_judge(judge)
        _refuse_code_graded(config, judge)
        judge_prompt = judge_prompt if judge_prompt is not None else config["judge_prompt"]
        response_schema = (
            response_schema if response_schema is not None else config.get("response_schema")
        )
        postprocess = postprocess if postprocess is not None else config.get("postprocess")
        requires_expected_behavior = bool(config.get("requires_expected_behavior"))

    lookup = dict(scenario_severities or {})

    def meta_for(result: AuditResult) -> Dict[str, Any]:
        stored = _stored_designed_severity({"judgment": result.judgment})
        if stored:
            return {"severity": stored, "severity_source": "stored"}
        if result.scenario_name in lookup:
            return {"severity": lookup[result.scenario_name], "severity_source": "lookup"}
        return {"severity": None, "severity_source": None}

    semaphore = asyncio.Semaphore(max_concurrency)

    async def grade(result: AuditResult):
        if not result.conversation:
            return _error_judgment("No transcript to re-grade"), 0, 0
        return await _grade(
            judge_client,
            judge_model,
            result.scenario_description or result.scenario_name,
            result.conversation,
            result.expected_behavior,
            judge_prompt,
            response_schema,
            json_format,
            max_retries,
            retry_backoff,
            semaphore,
            postprocess=postprocess,
            scenario_meta=meta_for(result),
            requires_expected_behavior=requires_expected_behavior,
        )

    outcomes = await asyncio.gather(*(grade(result) for result in source.results))

    empty = [r.scenario_name for r in source.results if not r.conversation]
    if empty:
        warnings.warn(
            f"{len(empty)} result(s) have no transcript and were kept as ERROR: {empty}.",
            stacklevel=2,
        )
    defaulted = [
        result.scenario_name
        for result, (judgment, _, _) in zip(source.results, outcomes, strict=True)
        if isinstance(judgment, dict) and judgment.get("designed_severity_source") == "default"
    ]
    if defaulted:
        warnings.warn(
            f"{len(defaulted)} result(s) were derived against the default designed severity "
            f"(medium) because none was stored or supplied: {defaulted}. Pass "
            "scenario_severities=severity_by_name(get_scenarios(pack)) to use the pack's values.",
            stacklevel=2,
        )

    rejudged = []
    for result, (judgment, tokens_in, tokens_out) in zip(source.results, outcomes, strict=True):
        rejudged.append(
            AuditResult(
                scenario_name=result.scenario_name,
                scenario_description=result.scenario_description,
                conversation=result.conversation,
                severity=ModelAuditor._severity_from_judgment(judgment),
                issues_found=judgment.get("issues_found", []),
                positive_behaviors=judgment.get("positive_behaviors", []),
                summary=judgment.get("summary", ""),
                recommendations=judgment.get("recommendations", []),
                expected_behavior=result.expected_behavior,
                judgment=judgment,
                auditor_input_tokens=result.auditor_input_tokens,
                auditor_output_tokens=result.auditor_output_tokens,
                judge_input_tokens=tokens_in,
                judge_output_tokens=tokens_out,
                target_input_tokens=result.target_input_tokens,
                target_output_tokens=result.target_output_tokens,
            )
        )
    return AuditResults(rejudged)
