    Cli usage

    CLI Usage¶

    simpleaudit CLI visualizes/exports AI safety audit results. Inspect JSON audit data via local web server or generate standalone HTML reports offline. Implemented simpleaudit/cli.py. Primary entry point post-audit analysis.

    Installation and Dependencies¶

    Core simpleaudit package excludes visualization dependencies. serve and export-html commands require optional dependencies. Missing dependencies cause CLI exit with error message instructing install visualize extra.

    pip install 'simpleaudit[visualize]'

    Command Overview¶

    CLI supports two primary subcommands:

    1. serve: Starts local web server dynamically visualize audit results from directory.
    2. export-html: Generates single, self-contained HTML file from specific JSON result file.

    No command provided or unrecognized command used, CLI prints help message exits status code 1.

    Command: serve¶

    serve command launches web server interactive visualization audit results. Scans specified directory JSON files serves browser interface.

    Syntax: 

    simpleaudit serve [--results_dir DIR] [--port PORT] [--host HOST]

    Arguments:

    Flag Type Default Description
    --results_dir str . (current directory) Path directory containing JSON result files. Not specified, current working directory used, warning printed.
    --port int 8000 Network port server listens.
    --host str 127.0.0.1 Host interface bind server. Defaults localhost security.

    Behavior: * --results_dir omitted, CLI defaults . prints warning: ⚠️ Warning: --results_dir not specified, using current directory '.'. Recommended explicitly set flag avoid confusion. * Command imports start_server simpleaudit.visualization.server. Module dependencies missing, CLI prints error exits. * Successful startup, server binds specified host port.

    Example Usage: 

    # Serve results specific directory port 5000
simpleaudit serve --results_dir ./audit_outputs --port 5000

# Serve results current directory default port
simpleaudit serve

    Command: export-html¶

    export-html command converts single JSON audit result file standalone HTML file. HTML file inlines necessary assets, opened directly browser without server network connection.

    Syntax: 

    simpleaudit export-html <json_path> [-o OUTPUT]

    Arguments:

    Argument/Flag Type Required Description
    json_path str Yes Path input JSON file containing audit results.
    -o, --output str No Path output HTML file. Omitted, output path derived json_path replacing .json extension .html.

    Behavior: * Command imports export_standalone_html simpleaudit.visualization.server. * Output Path Logic: * -o provided, used output path. * -o omitted: * json_path contains dot (.), extension replaced .html (e.g., results.json becomes results.html). * json_path does not contain dot, .html appended filename. * Error Handling: * Input json_path does not exist, CLI prints Error: <json_path> does not exist exits status code 1. * ValueError occurs processing (e.g., invalid JSON structure), CLI prints error message exits status code 1. * Success, CLI prints path generated HTML file note opened directly browser.

    Example Usage: 

    # Export specific JSON file default HTML name
simpleaudit export-html ./results/audit_01.json

# Export custom output filename
simpleaudit export-html ./results/audit_01.json -o ./reports/audit_01_report.html

    Error Handling and Exit Codes¶

    CLI uses standard exit codes indicate success failure:

    • 0: Success (implicit, standard Python behavior).
    • 1: Failure. Occurs following scenarios:
      • No command provided invalid command used.
      • Required optional dependencies visualization missing.
      • Input JSON file export-html not found.
      • ValueError raised during HTML export.

    Missing Dependencies Example: visualize extra not installed, running either command results: 

    Error: the visualization server needs optional dependencies (module_name is missing).
Install them with: pip install 'simpleaudit[visualize]'

    Implementation Details¶

    CLI defined simpleaudit/cli.py. Main entry point main() function, uses argparse parse arguments.

    • Parser Setup: argparse.ArgumentParser initialized prog="simpleaudit" description.
    • Subparsers: Two subparsers added: serve export-html.
    • Lazy Imports: Visualization modules (simpleaudit.visualization.server) imported only corresponding command executed. Ensures core CLI functional even visualization dependencies not installed, providing clear error messages instead import failures startup.

    Best Practices¶

    1. Explicit Results Directory: Using serve, always specify --results_dir avoid warning message ensure correct directory scanned.
    2. Standalone Reports: Use export-html sharing results stakeholders without Python environments access original JSON files. Generated HTML self-contained.
    3. Dependency Management: Ensure simpleaudit[visualize] installed environments visualization features required.

    Troubleshooting¶

    Issue: "Error: the visualization server needs optional dependencies" * Cause: simpleaudit package installed without visualize extra. * Solution: Run pip install 'simpleaudit[visualize]'.

    Issue: "Error: does not exist" * Cause: json_path provided export-html incorrect file moved/deleted. * Solution: Verify file path ensure JSON file exists specified location.

    Issue: Server does not start * Cause: Specified port already in use, host interface unavailable. * Solution: Try different port using --port check firewall/network settings binding non-localhost host.
