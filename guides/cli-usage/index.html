    Cli usage

    CLI Usage¶

    SimpleAudit provides command-line interface (CLI) access audit engine. Execute simpleaudit binary or python -m simpleaudit. CLI parses arguments, loads configuration, runs audit, outputs results.

    Overview¶

    CLI entry point simpleaudit/cli.py. Uses argparse standard library. Supports audit execution, report generation, configuration management. Exit codes indicate success/failure.

    Command Structure¶

    simpleaudit [global-options] <command> [command-options]

    Global options apply all commands. Command options specific action.

    Global Options¶

    Flag Short Description Default
    --config -c Path config file (YAML/JSON) ~/.simpleaudit/config.yaml
    --verbose -v Increase output verbosity (stackable) 0
    --quiet -q Suppress non-error output False
    --version Print version, exit N/A
    --help -h Show help message N/A

    Verbosity levels: - -v: Info logs - -vv: Debug logs - -vvv: Trace logs (raw data)

    Commands¶

    audit¶

    Execute audit scan.

    simpleaudit audit [target] [options]

    Parameters:

    • target: Path file/directory to audit. Omit uses config default.

    Options:

    Flag Short Description Default
    --rules -r Rule set name or path default
    --output -o Output file path stdout
    --format -f Output format: json, yaml, text, sarif text
    --severity -s Minimum severity threshold: low, medium, high, critical low
    --exclude -e Glob pattern exclude paths (repeatable) N/A
    --include -i Glob pattern include paths (repeatable) N/A
    --timeout -t Scan timeout seconds 300
    --workers -w Parallel worker count 4
    --fail-on Exit code 1 if findings >= threshold N/A
    --no-cache Disable result cache False

    Examples:

    Audit single file: 

    simpleaudit audit src/main.py

    Audit directory, JSON output, high severity only: 

    simpleaudit audit ./src --format json --severity high -o report.json

    Parallel scan, exclude tests: 

    simpleaudit audit ./project --workers 8 --exclude "tests/*" --exclude "*.min.js"

    CI integration (fail on critical): 

    simpleaudit audit ./src --fail-on critical --quiet

    report¶

    Generate report from cached audit results.

    simpleaudit report [options]

    Options:

    Flag Short Description Default
    --cache-id Specific cache entry ID latest
    --format -f Report format: html, pdf, json html
    --output -o Output file path stdout
    --filter Filter by rule ID (repeatable) N/A
    --summary Show summary only False

    Examples:

    Generate HTML report: 

    simpleaudit report --format html -o audit-report.html

    JSON summary for CI logs: 

    simpleaudit report --format json --summary

    Filter specific rule: 

    simpleaudit report --filter SEC-001 --filter SEC-002

    config¶

    Manage configuration files.

    simpleaudit config <subcommand>

    Subcommands:

    • init: Create default config file
    • show: Display current effective configuration
    • validate: Validate config file syntax/schema

    Examples:

    Initialize config: 

    simpleaudit config init -c ./my-config.yaml

    Show config: 

    simpleaudit config show

    Validate config: 

    simpleaudit config validate -c ./custom.yaml

    rules¶

    List or inspect available rule sets.

    simpleaudit rules [options]

    Options:

    Flag Short Description Default
    --list -l List all available rule sets False
    --show -s Show rule details by ID N/A
    --search Search rules by keyword N/A

    Examples:

    List rule sets: 

    simpleaudit rules --list

    Show rule details: 

    simpleaudit rules --show SEC-001

    Search rules: 

    simpleaudit rules --search "sql injection"

    Configuration File¶

    Default config location: ~/.simpleaudit/config.yaml. Override with --config.

    Example config.yaml: 

    audit:
  target: ./src
  rules: default
  workers: 4
  timeout: 300
  exclude:
    - "node_modules/*"
    - "*.min.js"
    - "dist/*"

output:
  format: text
  severity: low

cache:
  enabled: true
  path: ~/.simpleaudit/cache
  ttl: 3600

    Exit Codes¶

    Code Meaning
    0 Success, no findings above threshold
    1 Findings detected above --fail-on threshold
    2 Usage error (invalid arguments)
    3 Configuration error
    4 Scan timeout
    5 Internal error

    Environment Variables¶

    Variable Description
    SIMPLEAUDIT_CONFIG Override config file path
    SIMPLEAUDIT_CACHE_DIR Override cache directory
    SIMPLEAUDIT_LOG_LEVEL Override verbosity: DEBUG, INFO, WARNING, ERROR

    Practical Examples¶

    Pre-commit hook: 

    #!/bin/bash
simpleaudit audit "$@" --quiet --fail-on high

    Docker container scan: 

    docker run --rm -v $(pwd):/app simpleaudit audit /app --format sarif -o report.sarif

    Batch audit multiple targets: 

    for dir in ./project1 ./project2 ./project3; do
    simpleaudit audit "$dir" --format json -o "reports/$(basename $dir).json"
done

    Troubleshooting¶

    • Permission denied: Ensure target directory readable. Run with appropriate user privileges.
    • Timeout: Increase --timeout or reduce --workers for large codebases.
    • No output: Check --quiet flag. Verify --output path writable.
    • Config not loading: Run simpleaudit config validate to check syntax.
