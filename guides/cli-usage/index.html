    Cli usage

    CLI Usage¶

    SimpleAudit provides command-line interface (CLI) entry points for executing audit workflows without Python scripting. CLI suitable for automation, CI/CD pipelines, quick manual checks.

    Overview¶

    CLI wraps core audit engine. Accepts file paths, config files, output formats. Supports batch processing, single-file analysis. Exit codes indicate success/failure.

    Installation¶

    Install package. CLI command available as simpleaudit.

    pip install simpleaudit

    Verify installation:

    simpleaudit --version

    Basic Execution¶

    Run audit on single file:

    simpleaudit audit path/to/file.py

    Run audit on directory:

    simpleaudit audit path/to/project/

    Specify output format:

    simpleaudit audit path/to/file.py --format json

    Command Structure¶

    General syntax:

    simpleaudit <command> [options] <target>

    Commands:

    • audit: Execute audit analysis.
    • report: Generate report from previous audit data.
    • config: Manage configuration files.
    • version: Display version info.
    • help: Show help message.

    Options¶

    Global options apply to all commands.

    Option Short Description
    --verbose -v Enable debug logging.
    --quiet -q Suppress non-error output.
    --config -c Path to configuration file.
    --version Show version and exit.
    --help -h Show help message.

    Audit command specific options:

    Option Short Default Description
    --format -f text Output format: text, json, csv, html.
    --rules -r all Comma-separated list of rule IDs to run.
    --exclude -e None File patterns to exclude (glob syntax).
    --include -i None File patterns to include.
    --severity -s low Minimum severity level: low, medium, high, critical.
    --output -o stdout Output file path. If omitted, print to console.
    --fail-on None Exit code 1 if findings meet criteria: any, high, critical.
    --timeout 30 Max seconds per file.

    Configuration Files¶

    CLI reads configuration from YAML or JSON files. Default location: ~/.simpleaudit/config.yaml. Override with --config flag.

    Example config.yaml:

    rules:
  - id: "security.eval"
    enabled: true
    severity: "high"
  - id: "style.print"
    enabled: false

exclude:
  - "*.min.js"
  - "node_modules/*"
  - ".git/*"

output:
  format: "json"
  color: true

    Priority order: 1. Command-line arguments. 2. Configuration file specified by --config. 3. Default configuration file. 4. Built-in defaults.

    Examples¶

    Basic Audit¶

    Audit Python file, print text results:

    simpleaudit audit main.py

    JSON Output to File¶

    Audit directory, save JSON to file:

    simpleaudit audit ./src/ --format json --output audit-results.json

    Filter by Severity¶

    Only show high and critical issues:

    simpleaudit audit ./src/ --severity high

    Specific Rules¶

    Run only security rules:

    simpleaudit audit ./src/ --rules "security.eval,security.sql_injection"

    CI/CD Integration¶

    Fail build if any high-severity issues found:

    simpleaudit audit ./src/ --fail-on high --format json --output ci-report.json

    Exit code 0: No issues or issues below threshold. Exit code 1: Issues found meeting --fail-on criteria. Exit code 2: Execution error (invalid path, config error).

    Excluding Files¶

    Ignore test files and generated code:

    simpleaudit audit ./src/ --exclude "*_test.py" --exclude "generated/*"

    Output Formats¶

    Text (Default)¶

    Human-readable. Colorized if terminal supports ANSI.

    [CRITICAL] security.eval: eval() usage detected
  File: app.py
  Line: 42
  Message: Use of eval() allows arbitrary code execution.

[HIGH] security.sql_injection: Unparameterized SQL query
  File: db.py
  Line: 18
  Message: Use parameterized queries to prevent SQL injection.

    JSON¶

    Machine-readable. Suitable for parsing.

    {
  "version": "1.0.0",
  "timestamp": "2023-10-27T10:00:00Z",
  "files_scanned": 5,
  "findings": [
    {
      "rule_id": "security.eval",
      "severity": "critical",
      "file": "app.py",
      "line": 42,
      "message": "Use of eval() allows arbitrary code execution."
    }
  ]
}

    CSV¶

    Comma-separated values. Importable into spreadsheets.

    rule_id,severity,file,line,message
security.eval,critical,app.py,42,Use of eval() allows arbitrary code execution.

    HTML¶

    Standalone HTML report. Includes CSS styling. Suitable for sharing.

    simpleaudit audit ./src/ --format html --output report.html

    Environment Variables¶

    CLI respects environment variables for configuration overrides.

    Variable Description
    SIMPLEAUDIT_CONFIG Path to config file.
    SIMPLEAUDIT_FORMAT Default output format.
    SIMPLEAUDIT_SEVERITY Default minimum severity.
    SIMPLEAUDIT_TIMEOUT Default timeout in seconds.

    Example:

    export SIMPLEAUDIT_FORMAT=json
simpleaudit audit ./src/

    Troubleshooting¶

    Error: "No such file or directory" Target path invalid. Verify path exists. Use absolute paths for clarity.

    Error: "Invalid config file" YAML/JSON syntax error. Validate config file. Check indentation.

    Error: "Timeout exceeded" File processing took longer than --timeout. Increase timeout or exclude large files.

    No output Check --severity filter. If set to critical, low/medium issues hidden. Lower severity or remove flag.

    Best Practices¶

    1. Use --format json for programmatic processing.
    2. Use --fail-on in CI to enforce quality gates.
    3. Store config in repository for team consistency.
    4. Use --exclude to skip generated code, tests, dependencies.
    5. Use --quiet in scripts to avoid log clutter.
    6. Use --verbose for debugging configuration issues.

    API Reference¶

    CLI functions defined in simpleaudit/cli.py.

    • main(): Entry point. Parses arguments, dispatches commands.
    • run_audit(args): Executes audit logic. Returns exit code.
    • load_config(path): Loads YAML/JSON config. Returns dict.
    • format_output(findings, fmt): Converts findings to specified format. Returns string.

    For advanced usage, import these functions directly:

    from simpleaudit.cli import run_audit, load_config

config = load_config("my-config.yaml")
exit_code = run_audit(["./src/", "--format", "json"], config=config)
