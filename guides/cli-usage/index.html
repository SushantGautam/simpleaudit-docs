    Cli usage

    CLI Usage¶

    SimpleAudit CLI provides command-line interface for audit execution, report generation, and configuration management. Interface wraps core Python API, enables direct terminal execution without script creation.

    Installation¶

    Install package globally or locally.

    pip install simpleaudit

    Verify installation.

    simpleaudit --version

    Core Commands¶

    audit¶

    Execute audit scan against target directory or file.

    simpleaudit audit [TARGET] [OPTIONS]

    Arguments:

    Argument Description
    TARGET Path to file or directory to audit. Defaults to current directory.

    Options:

    Flag Short Description
    --config -c Path to YAML/JSON config file.
    --rules -r Comma-separated list of rule IDs to enable.
    --exclude -e Glob pattern to exclude files.
    --include -i Glob pattern to include specific files.
    --output -o Output file path for results.
    --format -f Output format: json, csv, html, text. Default: text.
    --verbose -v Enable debug logging.
    --quiet -q Suppress non-error output.

    Example:

    # Audit current directory, output JSON
simpleaudit audit . -f json -o results.json

# Audit specific folder, exclude tests
simpleaudit audit src/ -e "test_*.py" -f html -o report.html

    report¶

    Generate summary report from existing audit results.

    simpleaudit report [INPUT_FILE] [OPTIONS]

    Arguments:

    Argument Description
    INPUT_FILE Path to JSON audit results file.

    Options:

    Flag Short Description
    --format -f Report format: pdf, html, text. Default: text.
    --summary -s Output summary statistics only.
    --filter-severity Filter by severity: low, medium, high, critical.

    Example:

    # Generate PDF report from JSON results
simpleaudit report results.json -f pdf -o audit_report.pdf

# Show only high severity issues
simpleaudit report results.json -s --filter-severity high

    config¶

    Manage configuration files.

    simpleaudit config [COMMAND] [OPTIONS]

    Subcommands:

    Command Description
    init Create default configuration file.
    validate Check config file syntax and schema.
    show Display current effective configuration.

    Example:

    # Initialize config
simpleaudit config init -o my_config.yaml

# Validate config
simpleaudit config validate my_config.yaml

# Show effective config
simpleaudit config show

    rules¶

    List and inspect available audit rules.

    simpleaudit rules [COMMAND] [OPTIONS]

    Subcommands:

    Command Description
    list List all available rules.
    show Display details for specific rule.
    test Test rule against sample code.

    Example:

    # List all rules
simpleaudit rules list

# Show rule details
simpleaudit rules show SEC-001

# Test rule
simpleaudit rules test SEC-001 --sample "password = '123456'"

    Configuration¶

    CLI reads configuration from multiple sources, priority order:

    1. Command-line flags
    2. Environment variables
    3. Config file (specified via --config or SIMPLEAUDIT_CONFIG)
    4. Default values

    Environment Variables:

    Variable Description
    SIMPLEAUDIT_CONFIG Path to config file.
    SIMPLEAUDIT_OUTPUT_DIR Default output directory.
    SIMPLEAUDIT_LOG_LEVEL Logging level: DEBUG, INFO, WARNING, ERROR.

    Config File Structure:

    # simpleaudit.yaml
audit:
  target: "."
  exclude:
    - "**/node_modules/**"
    - "**/.git/**"
  include:
    - "**/*.py"

rules:
  enabled:
    - SEC-001
    - PERF-002
  disabled:
    - STYLE-010

output:
  format: json
  path: "./reports"

logging:
  level: INFO
  file: "./logs/audit.log"

    Exit Codes¶

    CLI returns specific exit codes for scripting integration.

    Code Meaning
    0 Success, no issues found.
    1 Issues found, audit completed.
    2 Configuration error.
    3 Target path not found.
    4 Output file write error.
    5 Internal error.

    Scripting Example:

    #!/bin/bash
simpleaudit audit . -f json -o results.json
exit_code=$?

if [ $exit_code -eq 0 ]; then
    echo "Audit passed."
elif [ $exit_code -eq 1 ]; then
    echo "Audit found issues."
    simpleaudit report results.json -f text
else
    echo "Audit error: $exit_code"
fi

    Advanced Workflows¶

    CI/CD Integration¶

    Add audit step to pipeline.

    # .github/workflows/audit.yml
name: Audit
on: [push, pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.10'
      - run: pip install simpleaudit
      - run: simpleaudit audit . -f json -o audit.json
      - run: simpleaudit report audit.json -f html -o audit.html
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: audit-report
          path: audit.html

    Custom Rules¶

    Load custom rules from local directory.

    simpleaudit audit . --rules-dir ./custom_rules

    Custom rules must follow Rule class interface defined in simpleaudit.rules.base.

    Parallel Execution¶

    Enable parallel processing for large codebases.

    simpleaudit audit . --workers 4

    --workers flag controls concurrent processes. Default: 1.

    Troubleshooting¶

    Permission Denied:

    Ensure target directory readable.

    chmod -R +r /path/to/target

    Config Not Found:

    Specify config path explicitly.

    simpleaudit audit . -c /path/to/config.yaml

    Slow Execution:

    Exclude large directories, increase workers.

    simpleaudit audit . -e "**/vendor/**" --workers 8

    Output Encoding:

    Force UTF-8 output.

    simpleaudit audit . -f json -o results.json --encoding utf-8

    API Reference¶

    CLI wraps core API functions. Direct Python usage available for programmatic control.

    from simpleaudit.cli import main

# Equivalent to: simpleaudit audit . -f json
main(["audit", ".", "-f", "json"])

    Module path: simpleaudit/cli.py

    Key functions:

    Function Description
    main(args) Entry point, parses arguments, executes command.
    parse_args(args) Parse CLI arguments into namespace.
    execute_audit(config) Run audit with config object.
    generate_report(results, format) Create report from results.

    Best Practices¶

    1. Use Config Files: Store settings in simpleaudit.yaml, version control it.
    2. Exclude Generated Code: Always exclude build artifacts, dependencies.
    3. Save Results: Output JSON for historical tracking, trend analysis.
    4. Filter Severity: Use --filter-severity in CI to block on critical issues only.
    5. Cache Rules: Pre-compile rules if using custom rule sets.
    # Recommended CI command
simpleaudit audit . \
  -c .simpleaudit.yaml \
  -f json \
  -o audit-results.json \
  -q
