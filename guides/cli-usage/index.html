    Cli usage

    CLI Usage¶

    SimpleAudit provides command-line interface (CLI) entry points. Execute audits, manage configuration, and inspect results directly from terminal. No Python script required.

    Installation and Entry Point¶

    Install package via pip.

    pip install simpleaudit

    Invoke CLI using simpleaudit command.

    simpleaudit --help

    Global Options¶

    Global flags apply to all subcommands.

    Flag Description Default
    -v, --verbose Enable debug logging. False
    -q, --quiet Suppress non-error output. False
    --config Path to YAML/JSON config file. ~/.simpleaudit/config.yaml
    --version Print version number. N/A

    Subcommands¶

    audit¶

    Run security audit. Primary execution mode.

    Syntax:

    simpleaudit audit [OPTIONS] <TARGET>

    Arguments:

    • TARGET: File path, directory, or URL to audit.

    Options:

    Flag Description
    --rules Comma-separated list of rule IDs to enable. Default: all enabled.
    --exclude Regex pattern for files to skip.
    --output Output format: json, html, text. Default: text.
    --out-file Write results to file instead of stdout.
    --fail-on Exit code 1 if severity meets threshold. Options: low, medium, high, critical.
    --timeout Max seconds per file. Default: 30.
    --workers Parallel worker count. Default: 1.

    Example:

    Audit current directory, output JSON, fail on high severity.

    simpleaudit audit . --output json --out-file report.json --fail-on high

    Audit specific file, exclude tests.

    simpleaudit audit src/main.py --exclude "test_.*"

    rules¶

    List available audit rules.

    Syntax:

    simpleaudit rules [OPTIONS]

    Options:

    Flag Description
    --format Output format: table, json. Default: table.
    --severity Filter by severity: low, medium, high, critical.
    --category Filter by category: security, performance, style.

    Example:

    List all high-severity security rules.

    simpleaudit rules --severity high --category security

    Output:

    ID          NAME                SEVERITY  CATEGORY
SEC-001     SQL Injection       high      security
SEC-002     XSS Vulnerability   high      security

    config¶

    Manage configuration files.

    Sub-subcommands:

    • init: Create default config file.
    • show: Print current effective configuration.
    • validate: Check config file syntax.

    Example:

    Initialize config in current directory.

    simpleaudit config init

    Validate existing config.

    simpleaudit config validate --config my_config.yaml

    version¶

    Print library version.

    simpleaudit version

    Configuration File¶

    CLI reads configuration from ~/.simpleaudit/config.yaml or path specified via --config.

    Example config.yaml:

    default_rules:
  - SEC-001
  - SEC-002

exclude_patterns:
  - "node_modules/*"
  - "*.min.js"

output:
  format: json
  directory: ./reports

logging:
  level: INFO
  file: ./audit.log

    Exit Codes¶

    CLI returns specific exit codes for automation.

    Code Meaning
    0 Success. No issues found or issues below --fail-on threshold.
    1 Audit failed. Issues found meeting --fail-on threshold.
    2 Usage error. Invalid arguments or missing file.
    3 Internal error. Unexpected exception.

    Example CI Integration:

    if simpleaudit audit . --fail-on high; then
  echo "Audit passed"
else
  echo "Audit failed"
  exit 1
fi

    Advanced Usage¶

    Parallel Auditing¶

    Increase --workers for large codebases.

    simpleaudit audit /large/project --workers 4

    Custom Rules¶

    Load custom rule definitions from directory.

    simpleaudit audit . --rules-dir ./custom_rules

    Custom rules must implement Rule interface. See simpleaudit.rules.base.

    Output Filtering¶

    Pipe output to jq for JSON processing.

    simpleaudit audit . --output json | jq '.findings[] | select(.severity == "critical")'

    Troubleshooting¶

    Permission Denied:

    Ensure target directory readable. Run with elevated privileges if needed.

    sudo simpleaudit audit /protected/dir

    Config Not Found:

    Explicitly specify config path.

    simpleaudit audit . --config /path/to/config.yaml

    Slow Performance:

    Increase timeout or reduce worker count.

    simpleaudit audit . --timeout 60 --workers 2

    API Reference¶

    CLI wraps core library functions.

    • simpleaudit.cli.main: Entry point.
    • simpleaudit.cli.audit_cmd: Audit subcommand handler.
    • simpleaudit.cli.rules_cmd: Rules subcommand handler.
    • simpleaudit.cli.config_cmd: Config subcommand handler.

    Source file: simpleaudit/cli.py.

    Best Practices¶

    1. Use --fail-on in CI/CD pipelines.
    2. Store config in version control.
    3. Use --exclude for generated files.
    4. Set --workers based on CPU cores.
    5. Log output to file for historical tracking.

    Compatibility¶

    • Python 3.8+
    • Cross-platform: Linux, macOS, Windows
    • Shell: Bash, Zsh, PowerShell
