    Cli usage

    CLI Usage¶

    SimpleAudit exposes command-line interface (CLI) capabilities via simpleaudit.cli module. Primary entry point audit command. Subcommands: scan, report, config.

    Command Structure¶

    simpleaudit <command> [options]

    Global flags apply all commands.

    Flag Alias Description Default
    --verbose -v Enable debug logging False
    --quiet -q Suppress non-error output False
    --version Display version info N/A
    --help -h Show help message N/A

    Scan Command¶

    scan command performs static analysis. Target path required.

    simpleaudit scan <target_path> [options]

    Options:

    Flag Alias Type Description
    --recursive -r bool Traverse subdirectories
    --include -i str Glob pattern include files
    --exclude -x str Glob pattern exclude files
    --rules str Comma-separated rule IDs
    --severity -s str Minimum severity level
    --output -o str Output file path
    --format -f str Output format (json, html, text)

    Severity Levels: low, medium, high, critical.

    Example: Basic Scan

    simpleaudit scan ./src --recursive

    Example: Filtered Scan

    simpleaudit scan ./src \
  --include "*.py" \
  --exclude "test_*" \
  --severity high \
  --format json \
  --output results.json

    Report Command¶

    report command generates summary from previous scan data. Requires --input flag pointing to JSON scan results.

    simpleaudit report [options]

    Options:

    Flag Alias Type Description
    --input -i str Path to JSON scan file
    --format -f str Report format (pdf, html, txt)
    --template -t str Custom Jinja2 template path
    --title str Report title string

    Example: Generate HTML Report

    simpleaudit report \
  --input results.json \
  --format html \
  --title "Security Audit Q3"

    Config Command¶

    config command manages configuration files.

    simpleaudit config <action> [options]

    Actions:

    • init: Create default config file.
    • show: Display current config.
    • set: Modify specific key.
    • get: Retrieve specific key value.

    Options:

    Flag Alias Type Description
    --path -p str Config file location
    --key -k str Configuration key name
    --value -v str Configuration value

    Example: Initialize Config

    simpleaudit config init --path ./audit.yaml

    Example: Set Rule Threshold

    simpleaudit config set \
  --path ./audit.yaml \
  --key "rules.max_severity" \
  --value "medium"

    Configuration File¶

    Default config file: audit.yaml. CLI flags override file values.

    # audit.yaml
scan:
  recursive: true
  include:
    - "*.py"
  exclude:
    - "*/tests/*"
    - "*/migrations/*"

rules:
  enabled:
    - "S001"
    - "S002"
  disabled:
    - "S999"

report:
  format: "html"
  template: "default.html.j2"

logging:
  level: "INFO"
  file: "audit.log"

    Exit Codes¶

    CLI returns specific exit codes for automation.

    Code Meaning
    0 Success, no issues found
    1 Issues found (severity >= threshold)
    2 Configuration error
    3 File not found / Invalid path
    4 Internal error

    Shell Script Example:

    #!/bin/bash
simpleaudit scan ./src --severity high
exit_code=$?

if [ $exit_code -eq 0 ]; then
    echo "Audit passed."
elif [ $exit_code -eq 1 ]; then
    echo "Audit failed: High severity issues detected."
    exit 1
else
    echo "Audit error: Code $exit_code"
    exit 2
fi

    Integration Examples¶

    CI/CD Pipeline (GitHub Actions):

    - name: Run SimpleAudit
  run: |
    pip install simpleaudit
    simpleaudit scan . \
      --recursive \
      --severity medium \
      --format json \
      --output audit-report.json
- name: Upload Report
  if: always()
  uses: actions/upload-artifact@v3
  with:
    name: audit-report
    path: audit-report.json

    Makefile:

    audit:
    simpleaudit scan ./src --recursive --format text

audit-strict:
    simpleaudit scan ./src --recursive --severity low --format html -o report.html

.PHONY: audit audit-strict

    Troubleshooting¶

    "No rules loaded" Error Verify rules.enabled list in config. Ensure rule IDs valid. Run simpleaudit config show to inspect.

    Permission Denied Ensure target path readable. Run as user with appropriate filesystem permissions.

    Output File Overwrite CLI overwrites existing output files. Backup previous reports before re-running.

    API Reference¶

    CLI wraps simpleaudit.core.Auditor class.

    • scan maps to Auditor.run_scan(target, options)
    • report maps to Auditor.generate_report(data, format)
    • config maps to simpleaudit.config.ConfigManager

    For programmatic control, import simpleaudit directly. CLI intended for quick checks, CI integration, manual audits.
