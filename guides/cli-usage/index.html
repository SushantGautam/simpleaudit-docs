    Cli usage

    CLI Usage¶

    SimpleAudit provides command-line interface (CLI) access audit functionality. Developers execute audits, configure parameters, retrieve results directly terminal. No Python script required basic usage.

    Overview¶

    CLI wraps core SimpleAudit class. Handles argument parsing, configuration loading, execution, output formatting. Useful for automation, CI/CD pipelines, quick manual checks.

    Installation¶

    Install package first.

    pip install simpleaudit

    Verify installation.

    simpleaudit --version

    Basic Execution¶

    Run audit target directory.

    simpleaudit /path/to/target

    Command scans target directory. Generates report. Default output console.

    Command Syntax¶

    General syntax:

    simpleaudit [OPTIONS] TARGET

    TARGET required. Path directory, file, URL.

    Options and Flags¶

    CLI supports various options. Modify behavior, output format, logging level.

    Target Specification¶

    Flag Description Example
    TARGET Path audit target. Directory, file, URL. simpleaudit ./src
    -t, --target Explicit target flag. simpleaudit -t ./src

    Output Control¶

    Flag Description Default
    -o, --output Output file path. stdout
    -f, --format Output format. json, yaml, csv, html. json
    --quiet Suppress non-error output. False
    --verbose Enable detailed logging. False

    Example: Save JSON report file.

    simpleaudit ./src -o report.json -f json

    Example: Generate HTML report.

    simpleaudit ./src -o report.html -f html

    Configuration¶

    Flag Description
    -c, --config Path configuration file. YAML or JSON.
    --rules Path rules file. Override default rules.

    Configuration file example (config.yaml):

    audit:
  depth: 5
  ignore_patterns:
    - "*.log"
    - ".git"
  timeout: 30

    Run with config:

    simpleaudit ./src -c config.yaml

    Rules and Filters¶

    Flag Description
    --include Regex pattern include files. Repeatable.
    --exclude Regex pattern exclude files. Repeatable.
    --rule Specific rule ID execute. Repeatable.

    Example: Audit only Python files.

    simpleaudit ./src --include ".*\.py"

    Example: Exclude test files.

    simpleaudit ./src --exclude ".*test.*"

    Example: Run specific security rule.

    simpleaudit ./src --rule SEC-001 --rule SEC-002

    Logging and Debugging¶

    Flag Description
    -v, --verbose Increase verbosity. Multiple flags increase level.
    --debug Enable debug logging.
    --log-file Write logs specific file.

    Example: Debug mode.

    simpleaudit ./src --debug --log-file audit.log

    Exit Codes¶

    CLI returns specific exit codes. Useful scripting.

    Code Meaning
    0 Success. No critical issues found.
    1 Error. Invalid arguments, file not found.
    2 Audit completed. Critical issues found.
    3 Audit completed. Warnings found.

    Example script usage:

    simpleaudit ./src
if [ $? -eq 2 ]; then
    echo "Critical issues detected"
    exit 1
fi

    Advanced Examples¶

    Full Audit with Custom Config¶

    simpleaudit \
  --target ./project \
  --config ./audit-config.yaml \
  --output ./reports/audit.json \
  --format json \
  --verbose

    Multiple Targets¶

    CLI supports multiple targets.

    simpleaudit ./src ./lib ./tests

    Pipe Output¶

    Pipe JSON output other tools.

    simpleaudit ./src -f json | jq '.findings[] | select(.severity == "critical")'

    HTML Report with Browser¶

    simpleaudit ./src -o report.html -f html
open report.html

    Configuration File Details¶

    Configuration file YAML or JSON. Structure:

    audit:
  depth: 10
  timeout: 60
  parallel_workers: 4
  ignore_patterns:
    - "node_modules"
    - ".venv"
  include_patterns:
    - ".*\.py"
    - ".*\.js"
rules:
  enabled:
    - SEC-001
    - SEC-002
    - PERF-001
  disabled:
    - STYLE-001
logging:
  level: INFO
  file: audit.log

    Configuration Parameters¶

    Parameter Type Description
    audit.depth int Max directory depth scan.
    audit.timeout int Seconds per file check.
    audit.parallel_workers int Concurrent processes.
    audit.ignore_patterns list Glob patterns ignore.
    audit.include_patterns list Glob patterns include.
    rules.enabled list Rule IDs enable.
    rules.disabled list Rule IDs disable.
    logging.level str DEBUG, INFO, WARNING, ERROR.
    logging.file str Log file path.

    Integration with CI/CD¶

    GitHub Actions example:

    name: Audit
on: [push]
jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install SimpleAudit
        run: pip install simpleaudit
      - name: Run Audit
        run: simpleaudit ./src -o report.json -f json --quiet
      - name: Check Exit Code
        run: |
          if [ $? -ne 0 ]; then
            echo "Audit failed"
            exit 1
          fi

    Troubleshooting¶

    Permission Denied Ensure target directory readable.

    chmod -R +r /path/to/target

    Timeout Errors Increase timeout config.

    simpleaudit ./src -c config.yaml # Ensure timeout high enough

    No Output Check --quiet flag. Remove if needed.

    simpleaudit ./src

    Invalid Config Validate YAML syntax.

    python -c "import yaml; yaml.safe_load(open('config.yaml'))"

    API Reference¶

    CLI uses argparse module. Main entry point simpleaudit.cli.main().

    Key classes:

    • AuditRunner: Executes audit logic.
    • ConfigLoader: Parses configuration files.
    • ReportGenerator: Formats output.

    For programmatic access, use Python API instead CLI.

    from simpleaudit import SimpleAudit

audit = SimpleAudit(config_path="config.yaml")
results = audit.run(target="./src")

    CLI best suited automation, quick checks. Python API complex workflows, custom reporting.
