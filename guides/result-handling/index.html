    Result handling

    Result Handling¶

    SimpleAudit result handling module manages parsing, storage, and interpretation of audit outputs. Handles repeated runs. Provides structured access to findings.

    Overview¶

    Audit execution produces raw data. This subsystem transforms raw data into structured AuditResult objects. Supports comparison between runs. Enables programmatic access to findings, metrics, and status.

    Core Classes¶

    AuditResult¶

    Primary container for single audit run output.

    Attributes:

    Attribute Type Description
    run_id str Unique identifier for execution instance
    timestamp datetime UTC start time of audit
    status str Execution state: success, error, partial
    findings List[Finding] Detected issues list
    metrics Dict[str, float] Performance and coverage statistics
    raw_output str Unprocessed stdout/stderr

    Methods:

    • get_findings(severity=None, category=None): Filter findings by severity level or category.
    • summary(): Return human-readable text summary.
    • to_dict(): Serialize object to JSON-compatible dictionary.

    Finding¶

    Represents single detected issue.

    Attributes:

    Attribute Type Description
    id str Unique finding identifier
    severity str critical, high, medium, low, info
    message str Description of issue
    location str File path and line number
    rule_id str Associated audit rule identifier

    Repeated Runs¶

    Multiple audit executions require comparison. RunHistory class manages sequence of AuditResult objects.

    RunHistory¶

    Methods:

    • add(result: AuditResult): Append new result to history.
    • compare(run_id_a, run_id_b): Return diff between two runs.
    • trend(metric_name): Generate time-series data for specific metric.
    • latest(): Return most recent AuditResult.

    Parsing Logic¶

    Raw audit output parsing handled by ResultParser.

    ResultParser¶

    Parameters:

    • format: Output format type. Supported: json, xml, text.
    • strict: Boolean. If True, invalid format raises exception. If False, returns partial result with warnings.

    Usage:

    from simpleaudit.results import ResultParser, AuditResult

parser = ResultParser(format="json", strict=True)
raw_data = '{"run_id": "abc123", "findings": []}'
result = parser.parse(raw_data)
print(result.status)  # Output: success

    Storing Results¶

    Persist results to disk or database. ResultStore abstracts storage backend.

    ResultStore¶

    Methods:

    • save(result: AuditResult): Persist result.
    • load(run_id: str): Retrieve result by ID.
    • list_runs(limit=10): Return list of recent run_id values.
    • delete(run_id: str): Remove result from storage.

    Configuration:

    Storage backend configured via SimpleAuditConfig.

    config = SimpleAuditConfig()
config.result_storage_path = "/var/lib/simpleaudit"
config.storage_backend = "sqlite"  # Options: "sqlite", "json_file", "postgres"

    Interpreting Results¶

    Developers should check status field first.

    Status Values:

    • success: Audit completed. All rules executed.
    • error: Fatal exception occurred. No valid findings.
    • partial: Some rules failed. Findings may be incomplete.

    Severity Filtering:

    result = audit.run()
critical_issues = result.get_findings(severity="critical")
for finding in critical_issues:
    print(f"[{finding.rule_id}] {finding.message} at {finding.location}")

    Metric Access:

    coverage = result.metrics.get("code_coverage", 0.0)
if coverage < 80.0:
    logger.warning("Low code coverage: %.2f%%", coverage * 100)

    Comparison Example¶

    Compare two runs to detect regressions.

    from simpleaudit.results import RunHistory

history = RunHistory()
history.add(run_1_result)
history.add(run_2_result)

diff = history.compare(run_1_result.run_id, run_2_result.run_id)
new_findings = diff.get("new", [])
resolved_findings = diff.get("resolved", [])

if new_findings:
    print(f"Found {len(new_findings)} new issues")

    Error Handling¶

    Parsing errors raise ResultParseError.

    from simpleaudit.exceptions import ResultParseError

try:
    result = parser.parse(invalid_json_string)
except ResultParseError as e:
    logger.error("Parse failed: %s", e.message)

    Storage errors raise StorageError. Check e.cause for underlying database or file system exception.

    Best Practices¶

    1. Always check status before accessing findings.
    2. Use strict=False parser for legacy or malformed outputs.
    3. Store results immediately after execution to prevent data loss.
    4. Use RunHistory for CI/CD pipelines to track trend over time.
    5. Filter findings by severity in automated alerts. Ignore info level for critical alerts.

    File Paths¶

    • simpleaudit/results/parser.py: Contains ResultParser class.
    • simpleaudit/results/models.py: Contains AuditResult, Finding, RunHistory.
    • simpleaudit/results/storage.py: Contains ResultStore implementations.
    • simpleaudit/exceptions.py: Contains ResultParseError, StorageError.

    Notes¶

    • Timestamps always UTC. Convert to local time for display.
    • raw_output may contain sensitive data. Sanitize before logging.
    • metrics dictionary keys vary by audit type. Check specific audit documentation for available metrics.
    • RunHistory comparison assumes same audit configuration. Different configurations produce invalid diffs.
