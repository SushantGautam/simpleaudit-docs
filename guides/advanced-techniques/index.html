    Advanced techniques

    Advanced Techniques¶

    SimpleAudit provides advanced analysis capabilities beyond basic log parsing. These techniques enable deep inspection of model behavior, including cross-judging multiple outputs, reframing prompts for consistency checks, and analyzing repeated results to detect variance.

    Cross-Judging¶

    Cross-judging evaluates model outputs against a reference standard or another model's response. This technique helps identify hallucinations, factual errors, or stylistic deviations.

    Class: CrossJudge

    Location: simpleaudit/analysis/cross_judge.py

    The CrossJudge class compares two or more text outputs. It uses a configurable judge prompt to score alignment, accuracy, and coherence.

    Parameters:

    Parameter Type Description
    judge_model str Name of the LLM used for judging (e.g., "gpt-4o").
    reference str Ground truth or reference text. Optional.
    criteria list[str] List of evaluation criteria (e.g., ["accuracy", "tone"]).
    temperature float Temperature for the judge model. Default: 0.0.

    Example:

    from simpleaudit.analysis.cross_judge import CrossJudge

judge = CrossJudge(
    judge_model="gpt-4o",
    reference="The capital of France is Paris.",
    criteria=["factual_accuracy"]
)

result = judge.evaluate(
    candidate="The capital of France is London."
)

print(result.score)      # 0.1
print(result.reasoning)  # "Candidate states London is capital, which is incorrect."

    Configuration:

    Define custom judge prompts in config/judge_prompts.yaml:

    cross_judge:
  default_prompt: "Compare candidate against reference. Score 0-10."
  criteria_weights:
    factual_accuracy: 0.8
    tone: 0.2

    Reframing¶

    Reframing tests model robustness by altering prompt structure without changing semantic intent. This detects sensitivity to phrasing, order, or formatting.

    Function: reframe_prompt

    Location: simpleaudit/analysis/reframe.py

    Generates variations of a base prompt. Variations include synonym substitution, sentence reordering, and format changes (e.g., bullet points to paragraph).

    Parameters:

    Parameter Type Description
    base_prompt str Original prompt text.
    strategy str Reframing strategy: "synonym", "reorder", "format", "all".
    count int Number of variations to generate. Default: 3.
    seed int Random seed for reproducibility.

    Returns: list[str] – List of reframed prompts.

    Example:

    from simpleaudit.analysis.reframe import reframe_prompt

base = "Summarize this article in 3 sentences."
variations = reframe_prompt(
    base_prompt=base,
    strategy="synonym",
    count=2,
    seed=42
)

# Output:
# [
#   "Condense this article into 3 sentences.",
#   "Provide a 3-sentence summary of this article."
# ]

    Class: ReframeAnalyzer

    Location: simpleaudit/analysis/reframe.py

    Runs the model on all reframed prompts and compares outputs.

    Parameters:

    Parameter Type Description
    model str Target model to test.
    base_prompt str Original prompt.
    reframe_strategy str Strategy passed to reframe_prompt.
    similarity_metric str Metric for comparing outputs: "cosine", "bleu", "exact".

    Example:

    from simpleaudit.analysis.reframe import ReframeAnalyzer

analyzer = ReframeAnalyzer(
    model="gpt-4o-mini",
    base_prompt="Explain quantum entanglement.",
    reframe_strategy="reorder",
    similarity_metric="cosine"
)

report = analyzer.run()

print(report.avg_similarity)  # 0.85
print(report.variance)         # 0.02

    Repeated Result Analysis¶

    Repeated result analysis runs the same prompt multiple times to measure output stability. High variance indicates low reliability or high temperature settings.

    Class: RepeatAnalyzer

    Location: simpleaudit/analysis/repeat.py

    Executes a prompt N times and aggregates statistics.

    Parameters:

    Parameter Type Description
    model str Target model.
    prompt str Input prompt.
    iterations int Number of runs. Default: 10.
    temperature float Sampling temperature. Default: 0.7.
    metric str Similarity metric: "cosine", "jaccard", "exact".

    Methods:

    • run() – Executes all iterations. Returns RepeatReport.
    • get_outliers() – Returns indices of runs with similarity below threshold.

    Example:

    from simpleaudit.analysis.repeat import RepeatAnalyzer

analyzer = RepeatAnalyzer(
    model="gpt-4o",
    prompt="Write a haiku about code.",
    iterations=20,
    temperature=0.9,
    metric="cosine"
)

report = analyzer.run()

print(report.mean_similarity)   # 0.72
print(report.std_dev)           # 0.15
print(report.outlier_count)     # 3

    Output Structure:

    RepeatReport contains:

    • outputs: list[str] – Raw model responses.
    • similarities: list[float] – Pairwise similarity scores.
    • mean_similarity: float – Average similarity across all pairs.
    • std_dev: float – Standard deviation of similarities.
    • outlier_indices: list[int] – Indices of runs deviating significantly.

    Integration with Audit Pipeline¶

    These advanced techniques integrate into the main AuditPipeline via the analysis stage.

    Configuration:

    In audit_config.yaml:

    pipeline:
  stages:
    - name: parse
    - name: analyze
      techniques:
        - type: cross_judge
          model: gpt-4o
          criteria: [accuracy]
        - type: reframe
          strategy: all
          count: 5
        - type: repeat
          iterations: 10
          metric: cosine
    - name: report

    Code Usage:

    from simpleaudit.pipeline import AuditPipeline

pipeline = AuditPipeline(config="audit_config.yaml")
results = pipeline.run(input_logs="logs/sample.jsonl")

# Access advanced analysis results
cross_results = results.get("cross_judge")
reframe_results = results.get("reframe")
repeat_results = results.get("repeat")

for r in repeat_results:
    if r.std_dev > 0.2:
        print(f"High variance detected in prompt: {r.prompt}")

    Best Practices¶

    1. Temperature Control: Use low temperature (0.0-0.2) for cross-judging to ensure consistent evaluation. Use higher temperature (0.7-1.0) for repeat analysis to capture natural variance.
    2. Sample Size: For repeat analysis, minimum 10 iterations recommended. 50+ for statistical significance.
    3. Reframing Strategy: Start with "synonym" for quick checks. Use "all" for comprehensive robustness testing.
    4. Judge Model Selection: Use a model stronger than the target model for cross-judging. Avoid using the same model for both generation and judging to reduce bias.

    Error Handling¶

    All advanced analysis classes raise SimpleAuditError on failure. Common errors:

    • ModelTimeoutError: LLM response timeout.
    • InvalidPromptError: Prompt exceeds token limit.
    • SimilarityCalculationError: Metric calculation failed.
    from simpleaudit.exceptions import SimpleAuditError

try:
    analyzer.run()
except SimpleAuditError as e:
    logger.error(f"Analysis failed: {e}")

    File Paths¶

    • simpleaudit/analysis/cross_judge.py – Cross-judging logic.
    • simpleaudit/analysis/reframe.py – Reframing and robustness testing.
    • simpleaudit/analysis/repeat.py – Repeated execution and variance analysis.
    • simpleaudit/analysis/metrics.py – Similarity calculation utilities.
    • config/judge_prompts.yaml – Custom judge prompt templates.

    These techniques provide comprehensive insight into model behavior, enabling developers to identify weaknesses, ensure consistency, and validate factual accuracy in automated audits.
