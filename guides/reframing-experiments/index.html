    Reframing experiments

    Reframing & Experiments¶

    Reframing and experimental design module enables advanced prompt manipulation and systematic testing. Core subsystem handles prompt transformation, A/B testing, and result aggregation.

    Overview¶

    simpleaudit.reframing package provides tools for: - Prompt reframing: Transform prompts to test robustness, bias, or clarity - Experimental design: Run controlled experiments across prompt variants - Result comparison: Statistical analysis of experiment outcomes

    Module located at simpleaudit/reframing/__init__.py.

    Available Strategies:

    Strategy Description Use Case
    paraphrase Rewrite with different wording Test semantic invariance
    simplify Reduce complexity Test model robustness
    formalize Increase formality Test tone sensitivity
    bias_check Inject potential bias markers Detect bias in responses
    adversarial Add confusing elements Test failure modes

    Configuration¶

    Configuration via simpleaudit/reframing/config.py:

    REFRAMING_CONFIG = {
    "default_strategy": "paraphrase",
    "default_temperature": 0.7,
    "max_retries": 3,
    "timeout_seconds": 30,
    "metrics": ["accuracy", "consistency"],
    "significance_level": 0.05
}

    Override via environment variables: - SIMPLEAUDIT_REFRAMING_STRATEGY - SIMPLEAUDIT_REFRAMING_TEMPERATURE - SIMPLEAUDIT_EXPERIMENT_OUTPUT_DIR

    Usage Examples¶

    Basic Reframing¶

    from simpleaudit.reframing import PromptReframer

reframer = PromptReframer(strategy="simplify", temperature=0.5)

original = "Please analyze the financial statements and provide detailed recommendations for investment strategy optimization."
simplified = reframer.reframe(original)
print(simplified)
# "Analyze financials. Recommend investment strategy."

    Running an Experiment¶

    from simpleaudit.reframing import PromptReframer, Experiment

reframer = PromptReframer(strategy="bias_check")

exp = Experiment(
    name="bias_test_001",
    baseline_prompt="Evaluate this resume for senior engineer role.",
    reframer=reframer,
    n_trials=20
)

results = exp.run(model="gpt-4", metrics=["accuracy", "consistency"])
print(f"Baseline: {results['baseline_score']:.2f}")
print(f"Reframed: {results['reframed_score']:.2f}")
print(f"Significant: {results['p_value'] < 0.05}")

    Batch Experiment Pipeline¶

    from simpleaudit.reframing import PromptReframer, Experiment, ExperimentRunner

runner = ExperimentRunner(output_dir="./results")

strategies = ["paraphrase", "simplify", "formalize"]
for strategy in strategies:
    reframer = PromptReframer(strategy=strategy)
    exp = Experiment(
        name=f"test_{strategy}",
        baseline_prompt="Summarize this document.",
        reframer=reframer,
        n_trials=15
    )
    runner.add_experiment(exp)

results = runner.run_all(parallel=True)
report = runner.generate_report(format="markdown")
print(report)

    Statistical Methods¶

    Module uses scipy for statistical testing:

    • t-test: Compare mean scores between baseline and reframed
    • Confidence intervals: 95% CI for score differences
    • Effect size: Cohen's d for practical significance

    Results include: - p_value: Probability of observing difference by chance - confidence_interval: Tuple (lower, upper) bounds - effect_size: Standardized mean difference

    Error Handling¶

    Common exceptions:

    Exception Cause Resolution
    ReframingError LLM API failure Check API key, retry
    InvalidStrategyError Unknown strategy name Use valid strategy from list
    InsufficientTrialsError Too few trials for statistics Increase n_trials to ≥10
    ModelNotFoundError Invalid model identifier Verify model name

    Best Practices¶

    1. Baseline stability: Run baseline multiple times to establish variance
    2. Trial count: Minimum 10 trials per variant for statistical power
    3. Strategy selection: Match strategy to testing goal
    4. Metric alignment: Choose metrics relevant to use case
    5. Parallel execution: Use parallel=True for large experiment sets

    Limitations¶

    • Requires LLM API access for reframing
    • Statistical tests assume normal distribution
    • Parallel execution limited by API rate limits
    • Bias detection strategy not exhaustive
