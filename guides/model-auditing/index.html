    Model auditing

    Model Auditing¶

    simpleaudit.models handles model configuration, loading, and inference. Supports local Hugging Face models and remote API endpoints (OpenAI, Anthropic, etc.).

    Overview¶

    Auditing requires two model roles: 1. Target Model: Generates responses to audit scenarios. 2. Judge Model: Scores target responses for safety, harm, factuality, helpfulness.

    Both roles use ModelConfig dataclass. Inference logic wraps transformers (local) or openai/anthropic SDKs (remote).

    ModelConfig¶

    Dataclass defining model parameters.

    from simpleaudit.models import ModelConfig

config = ModelConfig(
    name="gpt-4",              # Identifier for logs/results
    provider="openai",          # "openai", "anthropic", "local"
    model_id="gpt-4",           # Hugging Face ID or API model name
    temperature=0.0,            # Sampling temperature
    max_tokens=1024,            # Max generation length
    api_key=None,               # Optional; defaults to env vars
    base_url=None,              # Optional; custom API endpoint
    device="cuda",              # "cuda", "cpu", "mps" (local only)
    dtype="float16"             # "float16", "bfloat16", "float32" (local only)
)

    Parameters:

    Parameter Type Default Description
    name str Required Unique identifier for this model instance.
    provider str Required "local", "openai", "anthropic". Determines inference backend.
    model_id str Required Model identifier. HF repo ID for local; API model string for remote.
    temperature float 0.0 Sampling temperature. 0.0 recommended for deterministic judging.
    max_tokens int 1024 Maximum tokens to generate.
    api_key str None API key. If None, reads from environment (OPENAI_API_KEY, ANTHROPIC_API_KEY).
    base_url str None Custom API base URL. Useful for local LLM proxies (Ollama, vLLM).
    device str "cuda" Compute device for local models.
    dtype str "float16" Data type for local model weights.

    Model Class¶

    Wraps inference logic. Use Model.from_config() to instantiate.

    from simpleaudit.models import Model

# Local Hugging Face model
local_model = Model.from_config(
    ModelConfig(
        name="llama-7b",
        provider="local",
        model_id="meta-llama/Llama-2-7b-chat-hf",
        device="cuda",
        dtype="float16"
    )
)

# OpenAI API model
openai_model = Model.from_config(
    ModelConfig(
        name="gpt-4",
        provider="openai",
        model_id="gpt-4"
    )
)

# Anthropic API model
anthropic_model = Model.from_config(
    ModelConfig(
        name="claude-3-opus",
        provider="anthropic",
        model_id="claude-3-opus-20240229"
    )
)

    Methods¶

    generate(prompt: str, system_prompt: str = None) -> str

    Generates response for given prompt.

    • prompt: User input string.
    • system_prompt: Optional system instruction. Prepended to messages for chat models.
    • Returns: Generated text string.

    batch_generate(prompts: list[str], system_prompt: str = None) -> list[str]

    Generates responses for multiple prompts.

    • prompts: List of user input strings.
    • system_prompt: Optional system instruction applied to all prompts.
    • Returns: List of generated text strings, same order as input.

    Note: For local models, this uses sequential generation. For API models, this may use concurrent requests depending on provider implementation.

    Provider-Specific Configuration¶

    Local Models (provider="local")¶

    Uses transformers library. Requires torch and transformers installed.

    pip install torch transformers

    Hardware Requirements: * device="cuda": NVIDIA GPU with CUDA support. * device="mps": Apple Silicon Mac. * device="cpu": CPU only (slow for large models).

    Quantization: ModelConfig does not currently expose explicit quantization flags (e.g., bitsandbytes). For 4-bit/8-bit quantization, modify the underlying AutoModelForCausalLM call in simpleaudit/models/local.py or use a pre-quantized model ID from Hugging Face Hub.

    OpenAI API (provider="openai")¶

    Uses openai Python SDK.

    pip install openai

    Environment Variables: * OPENAI_API_KEY: Required. * OPENAI_BASE_URL: Optional. Overrides default https://api.openai.com/v1. Useful for Azure OpenAI or local proxies.

    Example: Azure OpenAI 

    config = ModelConfig(
    name="azure-gpt-4",
    provider="openai",
    model_id="gpt-4",
    base_url="https://your-resource.openai.azure.com/openai/deployments/gpt-4",
    api_key="your-azure-key"
)

    Anthropic API (provider="anthropic")¶

    Uses anthropic Python SDK.

    pip install anthropic

    Environment Variables: * ANTHROPIC_API_KEY: Required.

    Example: 

    config = ModelConfig(
    name="claude-3-sonnet",
    provider="anthropic",
    model_id="claude-3-sonnet-20240229"
)

    Integration with Audit Runner¶

    Pass Model instances to AuditRunner to define target and judge models.

    from simpleaudit.audit import AuditRunner
from simpleaudit.models import Model, ModelConfig
from simpleaudit.scenarios import ScenarioPack

# Define models
target = Model.from_config(
    ModelConfig(name="llama-7b", provider="local", model_id="meta-llama/Llama-2-7b-chat-hf")
)
judge = Model.from_config(
    ModelConfig(name="gpt-4", provider="openai", model_id="gpt-4")
)

# Load scenarios
scenarios = ScenarioPack.load("safety_basic")

# Run audit
runner = AuditRunner(
    target_model=target,
    judge_model=judge,
    scenarios=scenarios,
    output_dir="./results"
)

results = runner.run()

    Error Handling¶

    • Missing API Keys: Raises EnvironmentError if api_key is None and environment variable is not set.
    • Model Not Found: Raises ValueError if model_id does not exist in Hugging Face Hub or API provider.
    • Inference Errors: Raises RuntimeError with provider-specific error message.

    Best Practices¶

    1. Judge Temperature: Set temperature=0.0 for judge models to ensure consistent scoring.
    2. Max Tokens: Set max_tokens appropriately for judge models. Judges typically output short JSON or numeric scores. max_tokens=512 usually sufficient.
    3. Local Model Memory: Large local models (7B+) require significant VRAM. Use dtype="float16" or quantized models to fit in memory.
    4. API Rate Limits: For high-volume audits, implement retry logic with exponential backoff. simpleaudit.models does not include built-in retry logic.

    File Paths¶

    • simpleaudit/models/__init__.py: Exports ModelConfig, Model.
    • simpleaudit/models/config.py: ModelConfig dataclass.
    • simpleaudit/models/local.py: Local model inference logic.
    • simpleaudit/models/openai.py: OpenAI API inference logic.
    • simpleaudit/models/anthropic.py: Anthropic API inference logic.
