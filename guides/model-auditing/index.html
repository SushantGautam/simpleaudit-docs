    Model auditing

    Model Auditing¶

    Model Auditing evaluates language models against defined criteria. Supports local inference and remote API endpoints. Use simpleaudit.audit module.

    Core Components¶

    ModelAuditor class orchestrates evaluation. - __init__(self, model_config: dict, criteria: list[dict]) - model_config: Dictionary specifying model source. - criteria: List of evaluation rules. - run(self, test_cases: list[dict]) -> AuditReport - Executes tests. Returns report object. - validate_config(self) -> bool - Checks configuration validity.

    AuditReport class holds results. - summary: Aggregated scores. - detailed_results: Per-case outcomes. - export_json(path: str): Saves report to file. - export_csv(path: str): Saves report to file.

    Configuration¶

    Define model source via model_config.

    Local Models¶

    Use local type. Requires transformers or llama_cpp installed.

    model_config = {
    "type": "local",
    "model_name": "meta-llama/Llama-3-8b-instruct",
    "device": "cuda",
    "max_new_tokens": 512,
    "temperature": 0.7
}

    Parameters: - model_name: HuggingFace ID or local path. - device: cuda, cpu, or mps. - max_new_tokens: Generation limit. - temperature: Sampling randomness.

    API Models¶

    Use api type. Supports OpenAI-compatible endpoints.

    model_config = {
    "type": "api",
    "base_url": "https://api.openai.com/v1",
    "api_key": "sk-...",
    "model_name": "gpt-4",
    "timeout": 30
}

    Parameters: - base_url: Endpoint URL. - api_key: Authentication token. - model_name: Provider-specific model ID. - timeout: Request timeout seconds.

    Criteria Definition¶

    Define evaluation rules in criteria list. Each rule is a dictionary.

    Supported Criteria Types:

    Type Description Required Fields
    exact_match String equality check expected
    contains Substring presence substring
    regex Pattern matching pattern
    llm_judge Secondary model evaluation judge_prompt, judge_model
    metric Custom metric function function_name

    Example Criteria:

    criteria = [
    {
        "name": "accuracy",
        "type": "exact_match",
        "expected": "Paris",
        "weight": 1.0
    },
    {
        "name": "tone_check",
        "type": "llm_judge",
        "judge_prompt": "Rate politeness 1-10",
        "judge_model": "gpt-4",
        "threshold": 8
    }
]

    Test Cases¶

    Provide input data via test_cases. Each case is a dictionary.

    test_cases = [
    {
        "id": "case_001",
        "prompt": "What is the capital of France?",
        "metadata": {"category": "geography"}
    },
    {
        "id": "case_002",
        "prompt": "Explain quantum entanglement simply.",
        "metadata": {"category": "physics"}
    }
]

    Fields: - id: Unique identifier. - prompt: Input text for model. - metadata: Optional context data.

    Usage Example¶

    Complete workflow:

    from simpleaudit import ModelAuditor

# 1. Configure model
model_config = {
    "type": "api",
    "base_url": "https://api.openai.com/v1",
    "api_key": "sk-your-key",
    "model_name": "gpt-4"
}

# 2. Define criteria
criteria = [
    {
        "name": "correctness",
        "type": "contains",
        "substring": "Paris",
        "weight": 1.0
    }
]

# 3. Prepare test cases
test_cases = [
    {"id": "1", "prompt": "Capital of France?"},
    {"id": "2", "prompt": "Capital of Germany?"}
]

# 4. Initialize auditor
auditor = ModelAuditor(model_config=model_config, criteria=criteria)

# 5. Validate configuration
if not auditor.validate_config():
    raise ValueError("Invalid configuration")

# 6. Run audit
report = auditor.run(test_cases=test_cases)

# 7. Process results
print(report.summary)
report.export_json("audit_results.json")

    Batch Processing¶

    Process large datasets efficiently.

    # Use generator for memory efficiency
def load_test_cases():
    with open("tests.jsonl") as f:
        for line in f:
            yield json.loads(line)

report = auditor.run(test_cases=load_test_cases())

    Custom Metrics¶

    Define custom evaluation logic.

    from simpleaudit.metrics import register_metric

@register_metric
def check_length(response: str) -> float:
    """Return 1.0 if response under 100 chars, else 0.0"""
    return 1.0 if len(response) < 100 else 0.0

criteria = [
    {
        "name": "conciseness",
        "type": "metric",
        "function_name": "check_length",
        "weight": 0.5
    }
]

    Parallel Execution¶

    Enable concurrent API requests.

    model_config = {
    "type": "api",
    "api_key": "sk-...",
    "model_name": "gpt-4",
    "max_workers": 10  # Concurrent requests
}

    Error Handling¶

    Common exceptions:

    • ConfigurationError: Invalid model or criteria setup.
    • APIError: Network or authentication failure.
    • EvaluationError: Criteria execution failure.
    try:
    report = auditor.run(test_cases)
except ConfigurationError as e:
    print(f"Config error: {e}")
except APIError as e:
    print(f"API failed: {e}")

    Performance Tips¶

    1. Cache Responses: Enable caching for repeated prompts. 
      model_config["cache_enabled"] = True
    2. Limit Tokens: Reduce max_new_tokens for faster inference.
    3. Batch API Calls: Use max_workers for parallel requests.
    4. Local Models: Prefer cuda over cpu for speed.

    Best Practices¶

    • Version Control: Save model_config and criteria with reports.
    • Baseline Comparison: Store historical reports for trend analysis.
    • Granular Criteria: Use multiple weighted criteria instead of single score.
    • Metadata Tracking: Include context in metadata for debugging.

    Troubleshooting¶

    Issue: APIError: 401 Unauthorized Solution: Verify api_key validity. Check environment variables.

    Issue: ConfigurationError: Unknown model type Solution: Ensure type is local or api.

    Issue: Slow execution Solution: Increase max_workers for API. Check local device utilization.
