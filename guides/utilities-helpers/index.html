    Utilities helpers

    Utilities & Helpers¶

    simpleaudit.utils module contains shared utility functions, data processing helpers, and internal tools used across SimpleAudit library. These functions standardize data formatting, file handling, and audit trail generation.

    Overview¶

    Utility functions handle: - Timestamp generation and formatting - File path resolution - Data normalization for audit records - Log level mapping - Safe JSON serialization

    All functions are pure functions unless noted. No side effects on input data.

    Public Functions¶

    generate_timestamp()¶

    Generates ISO 8601 formatted timestamp with UTC timezone.

    Parameters: - format (str, optional): Custom format string. Default: %Y-%m-%dT%H:%M:%S.%fZ

    Returns: - str: Formatted timestamp

    Example: 

    from simpleaudit.utils import generate_timestamp

ts = generate_timestamp()
# "2024-01-15T14:30:45.123456Z"

    normalize_record(record)¶

    Normalizes audit record dictionary for consistent storage.

    Parameters: - record (dict): Raw audit record

    Returns: - dict: Normalized record with standard keys

    Standard Keys: | Key | Type | Description | |-----|------|-------------| | timestamp | str | ISO 8601 timestamp | | action | str | Audit action type | | entity | str | Target entity identifier | | user | str | User identifier | | metadata | dict | Additional context data |

    Example: 

    from simpleaudit.utils import normalize_record

raw = {
    "time": "2024-01-15 14:30:45",
    "action": "create",
    "target": "user_123",
    "actor": "admin"
}

normalized = normalize_record(raw)
# {
#     "timestamp": "2024-01-15T14:30:45Z",
#     "action": "create",
#     "entity": "user_123",
#     "user": "admin",
#     "metadata": {}
# }

    resolve_path(path)¶

    Resolves relative paths to absolute paths relative to project root.

    Parameters: - path (str): File path (relative or absolute)

    Returns: - str: Absolute path

    Example: 

    from simpleaudit.utils import resolve_path

abs_path = resolve_path("logs/audit.log")
# "/home/user/project/logs/audit.log"

    safe_json_serialize(data)¶

    Serializes data to JSON string with custom encoder for non-serializable types.

    Parameters: - data: Any Python object - indent (int, optional): JSON indentation. Default: 2

    Returns: - str: JSON string

    Handles: - datetime objects → ISO 8601 strings - set objects → lists - bytes objects → base64 encoded strings - Custom objects → str(obj)

    Example: 

    from simpleaudit.utils import safe_json_serialize
from datetime import datetime

data = {
    "created": datetime.now(),
    "tags": {"admin", "user"},
    "raw": b"binary_data"
}

json_str = safe_json_serialize(data)
# {
#   "created": "2024-01-15T14:30:45.123456",
#   "tags": ["admin", "user"],
#   "raw": "YmluYXJ5X2RhdGE="
# }

    map_log_level(level)¶

    Maps string log level to numeric value.

    Parameters: - level (str): Log level name

    Returns: - int: Numeric log level

    Supported Levels: | String | Numeric | |--------|---------| | DEBUG | 10 | | INFO | 20 | | WARNING | 30 | | ERROR | 40 | | CRITICAL | 50 |

    Example: 

    from simpleaudit.utils import map_log_level

level = map_log_level("WARNING")
# 30

    Data Processing Helpers¶

    flatten_dict(d)¶

    Flattens nested dictionary into single-level dict with dot notation keys.

    Parameters: - d (dict): Nested dictionary

    Returns: - dict: Flattened dictionary

    Example: 

    from simpleaudit.utils import flatten_dict

nested = {
    "user": {
        "name": "Alice",
        "address": {
            "city": "NYC"
        }
    }
}

flat = flatten_dict(nested)
# {
#     "user.name": "Alice",
#     "user.address.city": "NYC"
# }

    validate_audit_schema(record)¶

    Validates audit record against expected schema.

    Parameters: - record (dict): Audit record to validate

    Returns: - bool: True if valid, False otherwise

    Required Fields: - timestamp (str) - action (str) - entity (str) - user (str)

    Example: 

    from simpleaudit.utils import validate_audit_schema

valid = {
    "timestamp": "2024-01-15T14:30:45Z",
    "action": "create",
    "entity": "user_123",
    "user": "admin"
}

is_valid = validate_audit_schema(valid)
# True

    File Handling¶

    ensure_directory(path)¶

    Creates directory if it does not exist.

    Parameters: - path (str): Directory path

    Returns: - None

    Raises: - OSError: If directory cannot be created

    Example: 

    from simpleaudit.utils import ensure_directory

ensure_directory("logs/audit")

    read_json_file(path)¶

    Reads and parses JSON file.

    Parameters: - path (str): File path

    Returns: - dict or list: Parsed JSON data

    Raises: - FileNotFoundError: If file does not exist - json.JSONDecodeError: If file contains invalid JSON

    Example: 

    from simpleaudit.utils import read_json_file

data = read_json_file("config/audit.json")

    Configuration¶

    No configuration options in this module. All functions use default behavior unless parameters specified.

    Error Handling¶

    All utility functions raise standard Python exceptions: - ValueError: For invalid input values - TypeError: For incorrect parameter types - OSError: For file system errors - json.JSONDecodeError: For invalid JSON

    No custom exception classes defined in this module.

    Usage Patterns¶

    Typical usage in audit pipeline:

    from simpleaudit.utils import (
    generate_timestamp,
    normalize_record,
    safe_json_serialize,
    ensure_directory
)

def log_audit_action(action, entity, user, metadata=None):
    record = {
        "timestamp": generate_timestamp(),
        "action": action,
        "entity": entity,
        "user": user,
        "metadata": metadata or {}
    }

    normalized = normalize_record(record)
    json_output = safe_json_serialize(normalized)

    ensure_directory("logs/audit")
    with open("logs/audit/audit.log", "a") as f:
        f.write(json_output + "\n")

    return normalized

    Performance Notes¶

    • All functions operate in O(n) time where n is data size
    • No external dependencies
    • Thread-safe: All functions are pure or use atomic file operations
    • Memory efficient: No large data structures created internally

    Limitations¶

    • normalize_record does not validate semantic correctness of fields
    • safe_json_serialize may lose precision for floating point numbers
    • resolve_path relies on current working directory for relative paths
    • No support for binary file operations in this module
