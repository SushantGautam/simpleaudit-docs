    Results analysis

    Results & Analysis¶

    simpleaudit results module processes raw audit data. Generates structured outputs. Provides statistical analysis. Handles repeated runs. Ensures reproducibility.

    Overview¶

    Audit execution produces raw event logs. Results class transforms logs into analyzable structures. Supports JSON, CSV, DataFrame formats. Statistical module computes metrics. Detects anomalies. Compares baseline vs current state.

    Core Classes¶

    AuditResults¶

    Primary container for audit output. Wraps raw events. Provides accessors.

    Attributes:

    Attribute Type Description
    raw_events List[Dict] Unprocessed audit events
    metadata Dict Run metadata (timestamp, version)
    summary Dict High-level counts and status

    Methods:

    • to_dataframe(): Converts raw_events to pandas.DataFrame.
    • to_json(path: str): Serializes results to JSON file.
    • to_csv(path: str): Serializes results to CSV file.
    • filter_by(action: str, resource: str = None): Filters events by action type or resource ID.

    Example:

    from simpleaudit.results import AuditResults

# Assume 'audit' is a completed AuditSession
results = audit.get_results()

# Convert to DataFrame for analysis
df = results.to_dataframe()

# Filter specific actions
login_events = results.filter_by(action="LOGIN")

# Save output
results.to_json("audit_output.json")
results.to_csv("audit_output.csv")

    StatisticalAnalyzer¶

    Computes statistical metrics on audit data. Detects deviations.

    Parameters:

    • results: AuditResults instance.
    • baseline: Optional AuditResults instance for comparison.

    Methods:

    • frequency_distribution(field: str): Returns count of unique values in specified field.
    • temporal_analysis(interval: str): Aggregates events by time interval ("hour", "day", "week").
    • anomaly_detection(threshold: float = 3.0): Flags events exceeding standard deviation threshold. Returns list of anomalous events.
    • compare_baseline(): Calculates delta metrics between current run and baseline.

    Example:

    from simpleaudit.results import StatisticalAnalyzer

analyzer = StatisticalAnalyzer(results=results)

# Get login frequency per hour
hourly_logins = analyzer.temporal_analysis(interval="hour")

# Detect anomalies (z-score > 3.0)
anomalies = analyzer.anomaly_detection(threshold=3.0)

if anomalies:
    print(f"Detected {len(anomalies)} anomalous events")
    for event in anomalies:
        print(event["timestamp"], event["action"])

    Repeated Results¶

    simpleaudit supports tracking changes across multiple runs. Useful for trend analysis.

    ResultHistory¶

    Manages sequence of AuditResults objects.

    Methods:

    • add_run(results: AuditResults): Appends new results to history.
    • get_trend(field: str, metric: str = "count"): Calculates trend over time.
    • export_comparison(start_index: int, end_index: int): Generates diff report between two runs.

    Example:

    from simpleaudit.results import ResultHistory

history = ResultHistory()

# Simulate multiple runs
for i in range(5):
    run_results = execute_audit() # Hypothetical execution
    history.add_run(run_results)

# Analyze trend in failed logins
failed_login_trend = history.get_trend(field="action", metric="count", filter_value="LOGIN_FAILED")

# Compare first and last run
diff_report = history.export_comparison(start_index=0, end_index=4)

    Statistical Analysis Details¶

    Statistical module uses numpy and scipy for computations.

    Frequency Distribution¶

    Counts occurrences of categorical fields.

    dist = analyzer.frequency_distribution(field="source_ip")
# Output: {'192.168.1.1': 150, '10.0.0.5': 42, ...}

    Temporal Analysis¶

    Aggregates events within time buckets.

    • interval: String defining bucket size.
    • Returns: List of dictionaries with bucket_start, bucket_end, count.
    daily_counts = analyzer.temporal_analysis(interval="day")
# Output: [{'bucket_start': '2023-10-01', 'count': 1200}, ...]

    Anomaly Detection¶

    Uses Z-score method.

    1. Calculate mean and standard deviation of event timestamps or numeric fields.
    2. Flag events where |z-score| > threshold.
    3. Returns list of flagged events with computed z-score.

    Configuration:

    • threshold: Float. Default 3.0. Higher values reduce false positives.
    • field: String. Field to analyze. Default timestamp.

    Data Export Formats¶

    AuditResults supports multiple export formats.

    Format Method Use Case
    JSON to_json(path) API integration, archival
    CSV to_csv(path) Excel, spreadsheet analysis
    DataFrame to_dataframe() In-memory Python analysis
    Parquet to_parquet(path) Large datasets, columnar storage

    Parquet Example:

    results.to_parquet("audit_data.parquet")

    Error Handling¶

    • EmptyResultsError: Raised when accessing results from failed or empty audit run.
    • InvalidFieldError: Raised when frequency_distribution or anomaly_detection targets non-existent field.
    • BaselineMismatchError: Raised when comparing baselines with incompatible schemas.

    Handling Example:

    try:
    dist = analyzer.frequency_distribution(field="unknown_field")
except InvalidFieldError as e:
    print(f"Field error: {e}")

    Best Practices¶

    1. Save Raw Data: Always export raw JSON/Parquet before filtering. Enables re-analysis without re-running audit.
    2. Baseline Management: Store baseline results in versioned storage. Do not overwrite.
    3. Time Zones: Ensure metadata contains UTC timestamps. temporal_analysis assumes UTC unless configured otherwise.
    4. Memory: Large audits may consume significant RAM when converting to DataFrame. Use chunked processing for datasets > 1GB.

    Configuration¶

    Statistical analysis behavior controlled via AnalyzerConfig.

    from simpleaudit.config import AnalyzerConfig

config = AnalyzerConfig(
    anomaly_threshold=2.5,
    default_interval="hour",
    include_metadata=True
)

analyzer = StatisticalAnalyzer(results=results, config=config)
    Parameter Type Default Description
    anomaly_threshold float 3.0 Z-score threshold for anomaly flagging
    default_interval str "hour" Default time bucket for temporal analysis
    include_metadata bool True Include metadata in export outputs

    Summary¶

    Results & Analysis module transforms raw audit logs into actionable insights. AuditResults handles data structure and export. StatisticalAnalyzer provides metrics and anomaly detection. ResultHistory tracks trends over time. Developers should utilize DataFrame conversion for complex analysis and JSON/Parquet for archival.
