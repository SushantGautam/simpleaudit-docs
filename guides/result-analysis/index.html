    Result analysis

    Result Analysis¶

    Result Analysis module processes, aggregates, interprets audit results. Provides tools transform raw audit data into actionable insights. Handles data cleaning, statistical aggregation, anomaly detection, report generation.

    Overview¶

    Audit results raw, unstructured. Result Analysis subsystem standardizes output. Enables developers query, filter, summarize audit logs. Supports multiple output formats: JSON, CSV, Pandas DataFrames. Integrates with SimpleAudit core engine.

    Key Capabilities: - Normalization: Convert heterogeneous audit records into uniform schema. - Aggregation: Group results by user, action, timestamp, resource. - Filtering: Exclude noise, focus specific events. - Scoring: Assign risk scores based on severity rules. - Export: Serialize results for external tools.

    Core Classes¶

    AuditResult¶

    Represents single audit event. Immutable data structure.

    Attributes:

    Attribute Type Description
    id str Unique identifier for event.
    timestamp datetime Event occurrence time (UTC).
    user_id str Identifier of actor.
    action str Action performed (e.g., login, delete).
    resource str Target object (e.g., user:123, file:report.pdf).
    status str Outcome: success, failure, warning.
    metadata dict Additional context (IP, user-agent, etc.).
    severity int Risk level (0-10).

    Example:

    from simpleaudit.results import AuditResult
from datetime import datetime, timezone

result = AuditResult(
    id="evt_001",
    timestamp=datetime.now(timezone.utc),
    user_id="user_42",
    action="login",
    resource="auth:session",
    status="success",
    metadata={"ip": "192.168.1.5"},
    severity=1
)

    ResultAnalyzer¶

    Main processing engine. Accepts list of AuditResult objects. Provides methods for aggregation and analysis.

    Initialization:

    analyzer = ResultAnalyzer(results: list[AuditResult])

    Methods:

    aggregate_by(key: str, func: str = "count") -> dict¶

    Groups results by specified attribute. Applies aggregation function.

    Parameters: - key: Attribute name (user_id, action, status, etc.). - func: Aggregation type (count, sum, mean, max, min).

    Returns: Dictionary mapping key values to aggregated results.

    Example:

    # Count events per user
user_counts = analyzer.aggregate_by("user_id", "count")
# Output: {"user_42": 5, "user_10": 12}

# Average severity per action
avg_severity = analyzer.aggregate_by("action", "mean")
# Output: {"login": 1.2, "delete": 7.8}
    filter_results(status: str = None, severity_min: int = 0, action: str = None) -> list[AuditResult]¶

    Filters results based on criteria. Returns new list.

    Parameters: - status: Filter by outcome (success, failure). - severity_min: Minimum severity threshold. - action: Specific action type.

    Example:

    # Get all failed actions with high severity
critical_failures = analyzer.filter_results(status="failure", severity_min=7)
    detect_anomalies(threshold: float = 2.0) -> list[AuditResult]¶

    Identifies outliers using statistical deviation. Compares event frequency against baseline.

    Parameters: - threshold: Standard deviation multiplier. Higher value = stricter detection.

    Returns: List of AuditResult objects flagged as anomalous.

    Example:

    # Find unusual activity patterns
anomalies = analyzer.detect_anomalies(threshold=3.0)
for event in anomalies:
    print(f"Anomaly: {event.user_id} performed {event.action}")
    to_dataframe() -> pd.DataFrame¶

    Converts results to Pandas DataFrame. Enables advanced data manipulation.

    Returns: pandas.DataFrame with columns: id, timestamp, user_id, action, resource, status, severity.

    Example:

    import pandas as pd

df = analyzer.to_dataframe()
# Perform custom analysis
df.groupby("user_id")["severity"].mean().sort_values(ascending=False)
    to_json(indent: int = 2) -> str¶

    Serializes results to JSON string.

    Parameters: - indent: Indentation level for pretty printing.

    Returns: JSON formatted string.

    Example:

    json_output = analyzer.to_json(indent=4)
with open("audit_report.json", "w") as f:
    f.write(json_output)

    Utility Functions¶

    calculate_risk_score(results: list[AuditResult]) -> float¶

    Computes overall risk score for dataset. Weighted average of severity, adjusted by frequency.

    Formula: $$ \text{Risk} = \frac{\sum (\text{severity}_i \times \text{weight}_i)}{\sum \text{weight}_i} $$

    Returns: Float value (0.0 - 10.0).

    Example:

    from simpleaudit.results import calculate_risk_score

score = calculate_risk_score(analyzer.results)
if score > 7.0:
    alert_security_team()

    generate_summary(results: list[AuditResult]) -> dict¶

    Creates high-level summary statistics.

    Returns: Dictionary containing: - total_events: Count of all results. - unique_users: Count of distinct user_id. - failure_rate: Percentage of failed actions. - avg_severity: Mean severity score. - time_range: Tuple of (min_timestamp, max_timestamp).

    Example:

    summary = generate_summary(analyzer.results)
print(f"Total Events: {summary['total_events']}")
print(f"Failure Rate: {summary['failure_rate']:.2%}")

    Configuration¶

    Result Analysis supports optional configuration via AnalyzerConfig class.

    Parameters:

    Parameter Type Default Description
    timezone str UTC Timezone for timestamp normalization.
    severity_weights dict {} Custom weights for risk calculation.
    anomaly_window int 3600 Time window (seconds) for anomaly detection.

    Example:

    from simpleaudit.results import ResultAnalyzer, AnalyzerConfig

config = AnalyzerConfig(
    timezone="US/Eastern",
    severity_weights={"login": 1.0, "delete": 2.5},
    anomaly_window=1800
)

analyzer = ResultAnalyzer(results, config=config)

    Best Practices¶

    1. Batch Processing: For large datasets (>10k events), use to_dataframe() for vectorized operations. Faster than iterative filtering.
    2. Memory Management: AuditResult objects immutable. Avoid storing raw lists in memory for long periods. Use streaming if processing continuous logs.
    3. Timezone Consistency: Ensure all timestamps converted to UTC before analysis. ResultAnalyzer handles conversion if config.timezone set.
    4. Anomaly Thresholds: Start with threshold=2.0. Adjust based on false positive rate. High threshold misses subtle attacks. Low threshold generates noise.
    5. Persistence: Save to_json() output for historical comparison. Enables trend analysis across audit periods.

    Error Handling¶

    • ValueError: Raised if aggregate_by receives invalid key or function.
    • TypeError: Raised if results list contains non-AuditResult objects.
    • EmptyDatasetError: Raised if detect_anomalies called on empty dataset.

    Example:

    try:
    analyzer.aggregate_by("invalid_key")
except ValueError as e:
    logger.error(f"Aggregation failed: {e}")

    Integration¶

    Result Analysis module integrates seamlessly with SimpleAudit logger.

    from simpleaudit import SimpleAudit
from simpleaudit.results import ResultAnalyzer

audit = SimpleAudit()
audit.log("user_1", "login", "auth", status="success")
audit.log("user_2", "delete", "file:secret.txt", status="success", severity=8)

# Analyze
analyzer = ResultAnalyzer(audit.get_results())
print(analyzer.aggregate_by("action", "count"))
# Output: {"login": 1, "delete": 1}

    This module provides robust foundation for audit result interpretation. Developers should leverage to_dataframe() for complex analysis and detect_anomalies for security monitoring.
