    Judges system

    Judges System¶

    SimpleAudit judges evaluate AI model responses against specific safety and quality metrics. Each judge config defines probe prompts (to generate test inputs), judge prompts (to evaluate outputs), and output schemas. Built-in judges implement methodologies from peer-reviewed research.

    Core Functions¶

    simpleaudit.judges exposes two primary functions:

    Function Description
    get_judge(name) Retrieve judge config dict by name. Raises ValueError if unknown.
    list_judge_configs() Return dict mapping judge names to one-line descriptions.

    JUDGE_CONFIGS dict holds all registered judges.

    Built-in Judges¶

    Safety¶

    • Source: Constitutional AI (Bai et al., 2022).
    • Metrics: Severity (critical, high, medium, low, pass).
    • Dimensions: Harm avoidance, boundaries, accuracy, transparency, manipulation resistance.
    • Output: severity, issues_found, positive_behaviors, summary, recommendations.

    Abstention¶

    • Source: AbstentionBench (Kirichenko et al., 2025).
    • Metrics: Score 1–10, abstained (bool), appropriate (bool).
    • Categories: answer_unknown, false_premise, stale, subjective, underspecified_context, underspecified_intent, none.
    • Output: score, abstained, appropriate, category, reasoning.

    Helpfulness¶

    • Source: MT-Bench (Zheng et al., 2023).
    • Metrics: Score 1–10 (average of sub-scores).
    • Dimensions: Relevance, accuracy, clarity, completeness (each 1–10).
    • Output: score, relevance, accuracy, clarity, completeness, feedback.

    Factuality¶

    • Source: G-Eval (Liu et al., 2023).
    • Metrics: Score 1–10, verdict (accurate, partially_accurate, inaccurate).
    • Output: score, verdict, factual_errors, unsupported_claims, reasoning.

    Harm¶

    • Source: HELM Safety (Liang et al., 2022).
    • Metrics: harmful (bool), severity (none to critical).
    • Categories: Violence, fraud, discrimination, sexual, harassment, deception, none.
    • Output: harmful, category, severity, explanation.

    Binary Abstention¶

    • Source: Custom minimal classifier.
    • Metrics: abstained (bool) only. No severity.
    • Logic: Did model deliver substantive content? Yes → false. No → true.
    • Output: abstained, reasoning.
    • Note: Declares own response_schema. Works with json_format=True.

    Helsedir Sexhealth (Norwegian)¶

    • Source: Helsedirektoratet domain review (2026).
    • Variants:
      • helsedir_sexhealth_no: Generic.
      • helsedir_sexhealth_no_rag: RAG framing, references «dokumentene».
    • Metrics: Neutral 1–5 scale mapped to severity levels.

    Usage¶

    Instantiate ModelAuditor with judge parameter.

    from simpleaudit import ModelAuditor

# 1. Use named judge
auditor = ModelAuditor(
    model="gpt-4",
    judge="helpfulness"
)

# 2. Named judge + custom probe
# probe_prompt overrides config's probe_prompt
auditor = ModelAuditor(
    model="gpt-4",
    judge="factuality",
    probe_prompt="Ask about specific historical dates..."
)

# 3. Fully custom judge
# judge_prompt takes precedence over named judge
auditor = ModelAuditor(
    model="gpt-4",
    judge_prompt="You are a strict code reviewer..."
)

    Configuration Structure¶

    Each judge config dict contains:

    Key Type Description
    name str Display name.
    description str Brief summary.
    probe_prompt str Instructions for generating test inputs.
    judge_prompt str Instructions for evaluating outputs.
    output_schema dict Human-readable schema description.
    response_schema dict JSON Schema for structured output (if applicable).
    source dict Citation metadata (paper, authors, year, URL).
    metadata dict Version, author, creation date.

    Custom Judges¶

    Create custom judge by passing judge_prompt directly. Omit judge parameter or set to None.

    custom_judge = ModelAuditor(
    model="gpt-4",
    judge_prompt="Evaluate tone. Score 1-10 for professionalism."
)

    If judge_prompt provided, it overrides any named judge config. probe_prompt can still be customized independently.

    Retrieving Configs¶

    from simpleaudit.judges import get_judge, list_judge_configs

# List all available
configs = list_judge_configs()
for name, desc in configs.items():
    print(f"{name}: {desc}")

# Get specific config
safety_cfg = get_judge("safety")
print(safety_cfg["judge_prompt"])

    Error Handling¶

    get_judge("unknown_name") raises: 

    ValueError: Unknown judge config 'unknown_name'. Available: safety, abstention, ...

    Best Practices¶

    1. Match Judge to Metric: Use safety for harm detection, factuality for hallucination checks, helpfulness for general quality.
    2. Binary Abstention: Use when ground truth expected_outcome exists. Calculate appropriateness in post-processing.
    3. RAG Context: Use helsedir_sexhealth_no_rag for bots with fixed source corpora.
    4. Custom Probes: Override probe_prompt to target specific vulnerabilities while keeping standard evaluation logic.
