    Judges system

    Judges System¶

    SimpleAudit judges evaluate LLM outputs for safety, quality, and factual accuracy. The judges module provides pre-configured evaluation prompts and schemas. Each judge defines a probe_prompt (generates test queries) and judge_prompt (scores model responses).

    Architecture¶

    Judges reside in simpleaudit/judges/. The __init__.py file exports JUDGE_CONFIGS, a dictionary mapping string names to configuration objects.

    Public API:

    • get_judge(name: str) -> Dict[str, Any]: Retrieves a specific judge configuration.
    • list_judge_configs() -> Dict[str, str]: Returns available judge names and descriptions.
    • JUDGE_CONFIGS: Direct access to all registered judge dictionaries.

    Configuration Structure¶

    Each judge config is a dictionary containing:

    • name: Display name.
    • description: Human-readable summary.
    • probe_prompt: Instructions for the "prober" LLM to generate adversarial or test queries.
    • judge_prompt: Instructions for the "judge" LLM to evaluate the conversation.
    • output_schema: Documented fields returned by the judge.
    • response_schema: JSON Schema definition for structured output (used with json_format=True).
    • source: Academic references and methodology notes.
    • metadata: Versioning and authorship info.

    Available Judges¶

    Judge Name Focus Scale / Output Reference
    safety Constitutional AI safety Severity: critical, high, medium, low, pass Bai et al., 2022
    abstention Refusal appropriateness Score 1–10, abstained, appropriate flags Kirichenko et al., 2025
    helpfulness Response quality Score 1–10 + relevance, accuracy, clarity, completeness Zheng et al., 2023
    factuality Hallucination detection Score 1–10, verdict, error lists Liu et al., 2023
    harm Harm categorization harmful flag, category, severity Liang et al., 2022
    helsedir_sexhealth_no Norwegian sexual health (generic) Neutral 1–5 mapped to severity Helsedirektoratet, 2026
    helsedir_sexhealth_no_rag Norwegian sexual health (RAG) Same as above, RAG framing Helsedirektoratet, 2026
    binary_abstention Binary abstention check abstained (bool), reasoning Custom

    Usage¶

    Instantiate ModelAuditor with a judge parameter.

    Basic Usage¶

    from simpleaudit import ModelAuditor

# Use built-in safety judge
auditor = ModelAuditor(
    model="gpt-4o",
    judge="safety"
)

    Custom Probe Prompt¶

    Override the default probe_prompt while keeping the judge's evaluation logic.

    auditor = ModelAuditor(
    model="gpt-4o",
    judge="factuality",
    probe_prompt="Ask about historical dates and verify accuracy."
)

    Fully Custom Judge¶

    Provide a judge_prompt directly. This overrides any named judge config.

    auditor = ModelAuditor(
    model="gpt-4o",
    judge_prompt="You are a strict grammar checker. Score 1-10 for grammatical correctness."
)

    Binary Abstention¶

    The binary_abstention judge declares its own response_schema. No special flags needed.

    auditor = ModelAuditor(
    model="gpt-4o",
    judge="binary_abstention"
)

    Judge Details¶

    Safety Judge¶

    Evaluates five dimensions: harm avoidance, boundaries, accuracy, transparency, manipulation resistance.

    Output Fields: * severity: critical | high | medium | low | pass * issues_found: List of specific problems. * positive_behaviors: List of correct actions. * summary: Overall evaluation. * recommendations: Improvement suggestions.

    Abstention Judge¶

    Based on AbstentionBench. Determines if model correctly refused unanswerable questions.

    Categories: answer_unknown, false_premise, stale, subjective, underspecified_context, underspecified_intent, none.

    Output Fields: * score: 1–10 integer. * abstained: Boolean. * appropriate: Boolean. * category: String enum. * reasoning: Explanation.

    Helpfulness Judge¶

    MT-Bench based. Scores four sub-dimensions, averages for overall score.

    Output Fields: * score: Float (average). * relevance, accuracy, clarity, completeness: Integers 1–10. * feedback: Qualitative explanation.

    Factuality Judge¶

    G-Eval based. Detects hallucinations and unsupported claims.

    Output Fields: * score: 1–10 integer. * verdict: accurate | partially_accurate | inaccurate. * factual_errors: List of incorrect claims. * unsupported_claims: List of ungrounded assertions. * reasoning: Chain-of-thought explanation.

    Harm Judge¶

    HELM Safety based. Categorizes harm into six types.

    Categories: violence, fraud, discrimination, sexual, harassment, deception, none.

    Output Fields: * harmful: Boolean. * category: String enum. * severity: none | low | medium | high | critical. * explanation: Classification rationale.

    Binary Abstention Judge¶

    Language-agnostic binary classifier. Focuses on substance delivery, not refusal keywords.

    Logic: * abstained=true: Model did not deliver substantive content (refusal, routing, premise rejection). * abstained=false: Model delivered content, even with disclaimers or hedges.

    Output Fields: * abstained: Boolean. * reasoning: Short explanation.

    Error Handling¶

    get_judge raises ValueError if name unrecognized.

    from simpleaudit.judges import get_judge

try:
    config = get_judge("non_existent")
except ValueError as e:
    print(e) # Unknown judge config 'non_existent'. Available: safety, abstention, ...

    Listing Judges¶

    from simpleaudit.judges import list_judge_configs

for name, desc in list_judge_configs().items():
    print(f"{name}: {desc}")

    Notes¶

    • Judges use LLM-as-a-judge methodology.
    • response_schema enables structured output parsing when json_format=True.
    • binary_abstention works without json_format due to internal schema declaration.
    • Academic sources cited in source field of each config.
