    Judges System¶

    SimpleAudit judges evaluate AI model responses against specific criteria. The judges module provides built-in configurations for safety, helpfulness, factuality, abstention, harm categorization, and domain-specific evaluations. Each judge defines probe prompts (to generate test inputs) and judge prompts (to score model outputs).

    Core Functions¶

    get_judge(name: str) -> Dict[str, Any]¶

    Retrieves a built-in judge configuration by name.

    Parameters: * name: Judge config name (e.g., "safety", "helpfulness").

    Returns: * Judge config dict containing probe_prompt, judge_prompt, output_schema, and source.

    Raises: * ValueError: If name is not recognized.

    Note: Returns a shallow copy. Modifying the returned dict does not affect the shared registry.

    from simpleaudit.judges import get_judge

config = get_judge("safety")
print(config["description"])

    list_judge_configs() -> Dict[str, str]¶

    Lists available judge configurations and their descriptions.

    Returns: * Dict mapping config names to one-line descriptions.

    from simpleaudit.judges import list_judge_configs

for name, desc in list_judge_configs().items():
    print(f"{name}: {desc}")

    Built-in Judges¶

    Safety Judge¶

    Evaluates AI safety across five Constitutional AI dimensions: harm avoidance, boundary maintenance, factual accuracy, transparency, and manipulation resistance.

    • Source: Bai et al. (2022), Constitutional AI: Harmlessness from AI Feedback.
    • Output: Severity (critical, high, medium, low, pass), issues found, positive behaviors, summary, recommendations.
    from simpleaudit import ModelAuditor

auditor = ModelAuditor(
    model="gpt-4",
    judge="safety"
)

    Helpfulness Judge¶

    Evaluates response quality across four MT-Bench dimensions: relevance, accuracy, clarity, and completeness.

    • Source: Zheng et al. (2023), Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena.
    • Output: Overall score (1–10 float), sub-scores for each dimension (1–10 int), qualitative feedback.
    auditor = ModelAuditor(
    model="gpt-4",
    judge="helpfulness"
)

    Factuality Judge¶

    Detects hallucinations, unsupported claims, and fabricated details using G-Eval chain-of-thought methodology.

    • Source: Liu et al. (2023), G-Eval: NLG Evaluation using GPT-4 with Better Human Alignment.
    • Output: Score (1–10 int), verdict (accurate, partially_accurate, inaccurate), lists of factual errors and unsupported claims, reasoning.
    auditor = ModelAuditor(
    model="gpt-4",
    judge="factuality"
)

    Abstention Judge¶

    Evaluates whether a model correctly abstains from answering unanswerable questions based on the AbstentionBench taxonomy.

    • Source: Kirichenko et al. (2025), AbstentionBench: Reasoning LLMs Fail on Unanswerable Questions.
    • Categories: answer_unknown, false_premise, stale, subjective, underspecified_context, underspecified_intent, none.
    • Output: Score (1–10 int), abstained (bool), appropriate (bool), category (str), reasoning.
    auditor = ModelAuditor(
    model="gpt-4",
    judge="abstention"
)

    Binary Abstention Judge¶

    Language-agnostic binary classifier determining if a model abstained from delivering substantive content.

    • Logic: abstained=true if the model did not deliver the requested substance (e.g., routed to professional, refused premise). abstained=false if content was delivered, even with disclaimers.
    • Output: abstained (bool), reasoning (str). No severity or score.
    auditor = ModelAuditor(
    model="gpt-4",
    judge="binary_abstention"
)

    Harm Judge¶

    Categorizes harmful outputs across six HELM Safety categories: violence, fraud, discrimination, sexual content, harassment, and deception.

    • Source: Liang et al. (2022), Holistic Evaluation of Language Models (HELM).
    • Output: harmful (bool), category (str), severity (none, low, medium, high, critical), explanation.
    auditor = ModelAuditor(
    model="gpt-4",
    judge="harm"
)

    Domain-Specific Judges¶

    • helsedir_sexhealth_no: Norwegian sexual-health judge for young users. Six criteria from Helsedirektoratet review. Neutral 1–5 scale mapped to standard severity levels.
    • helsedir_sexhealth_no_rag: Same as above, but framed for RAG systems referencing specific documents («dokumentene»).
    auditor = ModelAuditor(
    model="gpt-4",
    judge="helsedir_sexhealth_no"
)

    Scoring and Severity Mapping¶

    Score-based judges (abstention, helpfulness, factuality) emit a 1–10 score. The framework derives AuditResult.severity from this score using utils.severity_from_score:

    Score Range Severity
    9–10 pass
    7–8 low
    5–6 medium
    3–4 high
    1–2 critical

    Severity-based judges (safety, harm) emit severity directly. The raw judgment dict is stored unchanged in results.

    Custom Judges¶

    Use judge_prompt for fully custom evaluation logic. This takes precedence over any named judge.

    auditor = ModelAuditor(
    model="gpt-4",
    judge_prompt="You are a tone evaluator. Rate politeness 1-10."
)

    Combine named judges with custom probes:

    auditor = ModelAuditor(
    model="gpt-4",
    judge="factuality",
    probe_prompt="Ask about specific historical dates."
)

    Configuration Structure¶

    Each judge config is a dictionary with the following keys:

    • name: Display name.
    • description: Brief summary.
    • probe_prompt: Prompt for generating test inputs. Includes {language} placeholder.
    • judge_prompt: Prompt for evaluating model responses. Specifies JSON output format.
    • output_schema: Human-readable description of output fields.
    • response_schema: Machine-readable JSON Schema for strict validation (used when json_format=True).
    • source: Citation information (paper, authors, year, URL, notes).
    • metadata: Version and creation date.
