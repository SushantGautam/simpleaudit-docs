    Getting started

    Getting Started¶

    SimpleAudit lightweight Python library audit Python code. Detects common security vulnerabilities, performance issues, code smells. Static analysis. No execution required. Fast. Accurate.

    Installation¶

    Install via pip. Requires Python 3.8+.

    pip install simpleaudit

    Verify installation.

    import simpleaudit
print(simpleaudit.__version__)

    Core Concepts¶

    SimpleAudit scans source files. Returns AuditReport. Report contains Issue objects. Each Issue has severity, message, location.

    Key classes:

    Class Description
    SimpleAudit Main entry point. Runs audits.
    AuditReport Container for all findings.
    Issue Single detected problem.
    Config Audit settings.

    Running First Audit¶

    Basic usage. Scan single file.

    from simpleaudit import SimpleAudit

# Initialize auditor
auditor = SimpleAudit()

# Run audit on file
report = auditor.audit_file("app.py")

# Print results
for issue in report.issues:
    print(f"[{issue.severity}] {issue.message} at line {issue.line}")

    Sample output:

    [CRITICAL] Hardcoded password detected at line 12
[WARNING] SQL query built via string concatenation at line 45

    Scanning Directories¶

    Audit entire project. Recursive scan.

    from simpleaudit import SimpleAudit

auditor = SimpleAudit()

# Scan directory
report = auditor.audit_directory("src/")

# Summary
print(f"Total issues: {report.total_issues}")
print(f"Critical: {report.count_by_severity('CRITICAL')}")
print(f"High: {report.count_by_severity('HIGH')}")

    Configuration¶

    Customize audit via Config object.

    from simpleaudit import SimpleAudit, Config

# Create custom config
config = Config(
    include_patterns=["*.py"],
    exclude_patterns=["tests/", "migrations/"],
    min_severity="WARNING",
    max_file_size_mb=5,
    enable_performance_checks=True,
    enable_security_checks=True
)

auditor = SimpleAudit(config=config)
report = auditor.audit_directory("project/")

    Config Parameters¶

    Parameter Type Default Description
    include_patterns List[str] ["*.py"] File patterns to scan.
    exclude_patterns List[str] [] Paths/patterns to skip.
    min_severity str "INFO" Minimum severity to report.
    max_file_size_mb float 10.0 Skip files larger than this.
    enable_security_checks bool True Run security rules.
    enable_performance_checks bool True Run performance rules.
    enable_style_checks bool False Run style rules.

    API Reference¶

    SimpleAudit¶

    Main class. Orchestrates scanning.

    Constructor

    SimpleAudit(config: Optional[Config] = None)
    • config: Optional Config instance. Uses defaults if None.

    Methods

    • audit_file(path: str) -> AuditReport
      • Scans single file.
      • path: Absolute or relative file path.
      • Returns AuditReport.
    • audit_directory(path: str, recursive: bool = True) -> AuditReport
      • Scans directory tree.
      • path: Directory path.
      • recursive: Include subdirectories.
      • Returns AuditReport.
    • audit_string(code: str, filename: str = "<string>") -> AuditReport
      • Scans code string. Useful for testing/linting.
      • code: Python source code.
      • filename: Virtual filename for error reporting.
      • Returns AuditReport.

    AuditReport¶

    Container for results.

    Properties

    • issues: List[Issue] – All detected problems.
    • total_issues: int – Count of all issues.
    • files_scanned: int – Number of files processed.
    • duration_seconds: float – Time taken to run audit.

    Methods

    • count_by_severity(severity: str) -> int
      • Returns count of issues with specific severity.
      • Valid severities: "INFO", "WARNING", "HIGH", "CRITICAL".
    • filter_by_severity(severity: str) -> List[Issue]
      • Returns list of issues matching severity.
    • to_dict() -> dict
      • Serializes report to dictionary. JSON compatible.
    • to_json(indent: int = 2) -> str
      • Serializes report to JSON string.

    Issue¶

    Single finding.

    Attributes

    • severity: str – "INFO", "WARNING", "HIGH", "CRITICAL".
    • message: str – Human-readable description.
    • rule_id: str – Identifier for specific rule (e.g., SEC-001).
    • file: str – File path where issue found.
    • line: int – Line number.
    • column: int – Column number.
    • code_snippet: str – Relevant code line.

    Config¶

    Audit settings. See table above for parameters.

    Example: Custom Severity Filter¶

    Ignore low-priority warnings.

    from simpleaudit import SimpleAudit, Config

config = Config(min_severity="HIGH")
auditor = SimpleAudit(config=config)

report = auditor.audit_directory("src/")

# Only HIGH and CRITICAL issues remain
for issue in report.issues:
    print(f"{issue.severity}: {issue.message}")

    Example: Programmatic Linting¶

    Integrate into CI/CD or editor plugin.

    from simpleaudit import SimpleAudit

auditor = SimpleAudit()

def lint_code(code: str) -> bool:
    """Returns True if no critical issues found."""
    report = auditor.audit_string(code)
    criticals = report.count_by_severity("CRITICAL")
    return criticals == 0

# Usage
user_code = "import os\nos.system('ls')"
if not lint_code(user_code):
    raise Exception("Security violation detected")

    Error Handling¶

    SimpleAudit raises exceptions for invalid inputs.

    • FileNotFoundError: Path does not exist.
    • PermissionError: Cannot read file.
    • SyntaxError: Code string has invalid Python syntax.

    Wrap calls in try/except for robust integration.

    from simpleaudit import SimpleAudit

auditor = SimpleAudit()

try:
    report = auditor.audit_file("nonexistent.py")
except FileNotFoundError:
    print("File not found.")
except Exception as e:
    print(f"Unexpected error: {e}")

    Performance Notes¶

    • Scans files in parallel using multiprocessing.
    • Default worker count: CPU cores.
    • Large directories (>1000 files) may take seconds.
    • Use exclude_patterns to skip venv, node_modules, .git.
