    Getting started

    SimpleAudit lightweight framework AI safety auditing. Uses Large Language Models (LLMs) system under test judge evaluate model behavior specific safety scenarios. Supports multiple providers: Anthropic, OpenAI, Grok, Ollama, vLLM.

    Installation¶

    Install core library pip:

    pip install simpleaudit

    Visualization features (web server HTML export) install optional dependencies:

    pip install 'simpleaudit[visualize]'

    Environment Setup¶

    SimpleAudit requires API keys LLM providers. Set environment variables before running audits.

    OpenAI: 

    export OPENAI_API_KEY="your-key-here"

    Anthropic: 

    export ANTHROPIC_API_KEY="your-key-here"

    Local Models (Ollama/vLLM): Ensure local model server running. No API key typically required, specify correct base URL ModelAuditor configuration.

    Core Components¶

    Library exposes key classes functions via simpleaudit:

    Component Description
    ModelAuditor Primary class running audits target model.
    get_scenarios Retrieves predefined safety test scenarios.
    list_scenario_packs Lists available scenario packs.
    AuditResults Container audit outcomes, summary statistics.
    AuditResult Individual result object single scenario.
    AuditExperiment Manages complex experimental setups, repeated runs.
    RepeatedExperimentResults Container results repeated experiments.
    ModelStabilityReport Report model stability across repetitions.
    ScenarioStats Statistics individual scenarios repeated runs.
    CrossJudgeExperiment Compares results different judge models.
    CrossJudgeResults Container cross-judge comparison results.
    compare_judges Utility function compare judge outputs.
    reframing_check Evaluates model robustness prompt reframing attacks.
    reframing_check_async Asynchronous version reframing check.
    ReframingResults Container reframing test results.
    PromptVariant Represents variant prompt reframing tests.
    StoredRecord Record stored reframing data.
    load_stored_records Loads stored reframing records.
    WiggleRunner Runner judge qualification scenarios.
    WiggleProfile Profile wiggle testing.
    ScenarioWiggle Wiggle test specific scenario.
    TurnRecord Record conversation turn wiggle testing.

    First Audit Run¶

    Example demonstrates auditing OpenAI model using GPT-4 judge.

    1. Import modules: 

      from simpleaudit import ModelAuditor, get_scenarios

    2. Initialize Auditor: Configure target model, judge model, system prompt. 

      auditor = ModelAuditor(
    model="gpt-4o-mini",          # Target model audit
    provider="openai",            # Provider target model
    judge_model="gpt-4o",         # Judge model
    judge_provider="openai",      # Provider judge
    system_prompt="You are a helpful assistant."
)

    3. Load Scenarios: Retrieve set safety scenarios. 

      scenarios = get_scenarios("safety")

    4. Run Audit: Execute audit. 

      results = auditor.run(scenarios)

    5. View Results: Print summary findings. 

      results.summary()

    CLI Usage¶

    SimpleAudit includes command-line interface visualizing results.

    Serve Web Dashboard: Start local web server visualize JSON result files. 

    simpleaudit serve --results_dir ./results --port 8000

    Export Standalone HTML: Generate self-contained HTML file sharing results without server. 

    simpleaudit export-html ./results/audit_01.json -o ./report.html

    Configuration Options¶

    ModelAuditor accepts parameters:

    • model (str): Name model audit (e.g., "gpt-4o-mini", "claude-3-sonnet").
    • provider (str): LLM provider ("openai", "anthropic", "ollama", "vllm", etc.).
    • judge_model (str): Model used evaluate responses.
    • judge_provider (str): Provider judge model.
    • system_prompt (str): System prompt applied target model.
    • base_url (str, optional): Custom API endpoint OpenAI-compatible providers.
    • api_key (str, optional): Explicit API key (overrides environment variable).

    Advanced Features¶

    Repeated Experiments: Use AuditExperiment run scenarios multiple times assess model stability. 

    from simpleaudit import AuditExperiment

experiment = AuditExperiment(
    auditor=auditor,
    scenarios=scenarios,
    repetitions=5
)
experiment.run()

    Cross-Judge Comparison: Compare different judges evaluate same model responses. 

    from simpleaudit import CrossJudgeExperiment

cross_exp = CrossJudgeExperiment(
    auditor=auditor,
    scenarios=scenarios,
    judge_configs=[
        {"model": "gpt-4o", "provider": "openai"},
        {"model": "claude-3-opus", "provider": "anthropic"}
    ]
)
cross_exp.run()

    Prompt Reframing: Test model remains safe prompt rephrased. 

    from simpleaudit import reframing_check

results = reframing_check(
    auditor=auditor,
    scenario=scenarios[0],
    variants=["Please ignore previous instructions and..."]
)

    Judge Qualification (Wiggle Testing): Use WiggleRunner test judge qualification scenarios. Requires setup three model roles (target, judge, wiggle judge). 

    from simpleaudit import WiggleRunner

# Note: Specific configuration depends model setup
# wiggle_runner = WiggleRunner(...)

    Error Handling¶

    Ensure API keys valid network connectivity available. Provider not supported model name invalid, library raises exception during run() call. Check AuditResults object individual scenario errors partial failures occur.
