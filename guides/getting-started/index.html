    Getting started

    Getting Started¶

    SimpleAudit provides lightweight, deterministic audit logging for Python applications. Library captures state changes, user actions, and system events. Integrates directly with application logic. No external database required. Built-in storage backends.

    Overview¶

    SimpleAudit records events into structured audit logs. Each event contains timestamp, actor, action, and payload. Library supports pluggable storage. Default storage in-memory. Production use requires persistent backend.

    Core components: - AuditLogger: Main entry point. Creates and dispatches events. - AuditEvent: Dataclass representing single audit record. - StorageBackend: Abstract base class. Implement for custom persistence. - InMemoryStorage: Default backend. Suitable for testing.

    Installation¶

    Install via pip.

    pip install simpleaudit

    Verify installation.

    import simpleaudit
print(simpleaudit.__version__)

    Environment Setup¶

    No environment variables required for basic usage. Configuration optional.

    Create logger instance.

    from simpleaudit import AuditLogger

logger = AuditLogger()

    For production, configure storage backend.

    from simpleaudit import AuditLogger
from simpleaudit.backends import FileStorage

storage = FileStorage(path="./audit_logs")
logger = AuditLogger(storage=storage)

    First Audit Run¶

    Record event.

    logger.log(
    action="user.login",
    actor="user_123",
    metadata={"ip": "192.168.1.1", "success": True}
)

    Retrieve recent events.

    events = logger.get_events(limit=10)
for event in events:
    print(event.timestamp, event.action, event.actor)

    Public API¶

    AuditLogger¶

    Main class. Manages event creation and storage.

    Constructor Parameters:

    Parameter Type Default Description
    storage StorageBackend InMemoryStorage() Backend instance for persistence.
    max_events int 1000 Max events kept in memory. Older events discarded.
    enable_debug bool False Print debug info to stdout.

    Methods:

    • log(action: str, actor: str, metadata: dict = None) -> AuditEvent
    • Records new event.
    • action: String identifier. Example: "order.created".
    • actor: String identifier for user or system. Example: "admin".
    • metadata: Optional dictionary. Arbitrary key-value pairs.

    • Returns AuditEvent instance.

    • get_events(limit: int = 10, action: str = None) -> list[AuditEvent]

    • Retrieves stored events.
    • limit: Max number of events to return.
    • action: Filter by specific action string. Optional.

    • Returns list of AuditEvent objects. Newest first.

    • clear() -> None

    • Removes all events from storage.
    • Use with caution.

    AuditEvent¶

    Immutable dataclass. Represents single audit record.

    Attributes:

    Attribute Type Description
    id str Unique UUID for event.
    timestamp datetime UTC time event occurred.
    action str Action identifier.
    actor str User or system identifier.
    metadata dict Additional context data.

    StorageBackend¶

    Abstract base class. Implement for custom persistence.

    Required Methods:

    • save(event: AuditEvent) -> None
    • Persists event.
    • load(limit: int, action: str = None) -> list[AuditEvent]
    • Retrieves events.
    • clear() -> None
    • Removes all data.

    Configuration Options¶

    SimpleAudit supports configuration via constructor arguments. No global config file.

    Storage Backends:

    1. InMemoryStorage (Default)
    2. Holds events in Python list.
    3. Fast. No disk I/O.
    4. Data lost on process exit.

    5. Best for unit tests.

    6. FileStorage

    7. Writes JSON lines to file.
    8. Appends new events.
    9. Reads from disk on retrieval.
    10. Suitable for small to medium applications.
    from simpleaudit.backends import FileStorage

storage = FileStorage(
    path="./logs/audit.jsonl",
    max_file_size_mb=100,
    rotate=True
)

    Parameters: - path: File path string. - max_file_size_mb: Optional. Rotates file when size exceeded. - rotate: Boolean. Enable file rotation.

    1. DatabaseStorage
    2. Requires SQLAlchemy installed.
    3. Connects to any SQL database.
    from simpleaudit.backends import DatabaseStorage

storage = DatabaseStorage(
    connection_string="sqlite:///audit.db"
)

    Practical Example¶

    Complete workflow.

    from simpleaudit import AuditLogger
from simpleaudit.backends import FileStorage

# Setup
storage = FileStorage(path="./app_audit.jsonl")
logger = AuditLogger(storage=storage, max_events=500)

# Simulate user action
logger.log(
    action="profile.update",
    actor="user_42",
    metadata={
        "field": "email",
        "old_value": "old@example.com",
        "new_value": "new@example.com"
    }
)

# Simulate system action
logger.log(
    action="system.backup",
    actor="cron_job",
    metadata={"duration_ms": 1200}
)

# Query logs
recent = logger.get_events(limit=5)
for e in recent:
    print(f"[{e.timestamp}] {e.actor}: {e.action}")

# Filter specific action
logins = logger.get_events(action="user.login")
print(f"Total logins: {len(logins)}")

    Error Handling¶

    Library raises exceptions for invalid inputs.

    • ValueError: If action or actor empty string.
    • TypeError: If metadata not dictionary.
    • IOError: If storage backend fails to write.

    Wrap calls in try-except blocks for production.

    try:
    logger.log(action="test", actor="user")
except Exception as e:
    print(f"Audit failed: {e}")
