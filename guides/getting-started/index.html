    Getting started

    Getting Started¶

    SimpleAudit Python library provides automated code audit capabilities. Detects security vulnerabilities, code smells, performance bottlenecks. Integrates directly into CI/CD pipelines.

    Overview¶

    SimpleAudit scans Python codebases. Identifies issues: - Security flaws (injection, hardcoded secrets) - Performance anti-patterns - Code quality violations

    Library uses static analysis. No runtime execution required. Fast, deterministic results.

    Installation¶

    Install via pip:

    pip install simpleaudit

    Verify installation:

    import simpleaudit
print(simpleaudit.__version__)

    Requires Python 3.8+. No external dependencies.

    Environment Setup¶

    Create virtual environment:

    python -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows

    Install library:

    pip install simpleaudit

    Optional: Install development dependencies for contributing:

    pip install -r requirements-dev.txt

    First Audit Run¶

    Basic usage:

    from simpleaudit import Auditor

# Initialize auditor
auditor = Auditor()

# Run audit on directory
results = auditor.audit_directory("./src")

# Print results
for issue in results.issues:
    print(f"{issue.severity}: {issue.message} at {issue.file}:{issue.line}")

    Single file audit:

    results = auditor.audit_file("./app.py")

    Public API¶

    Auditor Class¶

    Main entry point. Configures and executes audits.

    Constructor Parameters:

    Parameter Type Default Description
    config dict {} Configuration overrides
    rules list None Specific rules to enable
    ignore list [] File patterns to ignore

    Methods:

    Method Parameters Returns Description
    audit_directory path: str AuditResults Scan directory recursively
    audit_file path: str AuditResults Scan single file
    set_config key: str, value: any None Update configuration
    get_report format: str str Generate report (json, html, text)

    AuditResults Class¶

    Container for audit findings.

    Attributes:

    Attribute Type Description
    issues list[Issue] All detected issues
    summary dict Statistics by severity
    duration float Audit time in seconds
    files_scanned int Count of files analyzed

    Methods:

    Method Parameters Returns Description
    filter severity: str list[Issue] Filter issues by severity
    to_json indent: int str Serialize to JSON
    to_html template: str str Generate HTML report

    Issue Class¶

    Represents single detected problem.

    Attributes:

    Attribute Type Description
    rule_id str Rule identifier (e.g., "SEC-001")
    severity str "critical", "high", "medium", "low"
    message str Human-readable description
    file str File path
    line int Line number
    column int Column position
    code_snippet str Context code
    suggestion str Fix recommendation

    Configuration Options¶

    Pass config dict to Auditor:

    auditor = Auditor(config={
    "severity_threshold": "medium",  # Ignore low severity
    "max_file_size": 102400,         # Skip files > 100KB
    "exclude_patterns": ["test_*.py", "*.min.py"],
    "enable_rules": ["SEC", "PERF"], # Rule categories
    "disable_rules": ["SEC-003"]     # Specific rule IDs
})

    Configuration Keys:

    Key Type Default Description
    severity_threshold str "low" Minimum severity to report
    max_file_size int 1048576 Max file size in bytes
    exclude_patterns list [] Glob patterns to skip
    enable_rules list None Rule categories to run
    disable_rules list [] Specific rules to skip
    max_issues_per_file int 100 Cap issues per file

    Rule Categories¶

    SimpleAudit includes built-in rules:

    Category Prefix Examples
    Security SEC Hardcoded passwords, SQL injection, eval() usage
    Performance PERF N+1 queries, inefficient loops, memory leaks
    Quality QUAL Long functions, high complexity, unused imports
    Style STYLE PEP8 violations, naming conventions

    View all rules:

    from simpleaudit.rules import list_rules

for rule in list_rules():
    print(f"{rule.id}: {rule.description}")

    Complete Example¶

    from simpleaudit import Auditor

# Configure auditor
auditor = Auditor(config={
    "severity_threshold": "medium",
    "exclude_patterns": ["tests/", "migrations/"]
})

# Run audit
results = auditor.audit_directory("./project")

# Print summary
print(f"Scanned {results.files_scanned} files in {results.duration:.2f}s")
print(f"Found {len(results.issues)} issues")

# Show critical/high issues
for issue in results.filter("critical"):
    print(f"\n[CRITICAL] {issue.rule_id}")
    print(f"  File: {issue.file}:{issue.line}")
    print(f"  Message: {issue.message}")
    print(f"  Suggestion: {issue.suggestion}")

# Generate JSON report
report = results.to_json(indent=2)
with open("audit_report.json", "w") as f:
    f.write(report)

    CLI Usage¶

    Command-line interface available:

    # Basic audit
simpleaudit ./src

# With options
simpleaudit ./src --severity high --format html --output report.html

# Specific rules
simpleaudit ./src --rules SEC,PERF

# Ignore patterns
simpleaudit ./src --ignore "test_*.py" --ignore "vendor/"

    Error Handling¶

    Audit errors raise SimpleAuditError:

    from simpleaudit import Auditor
from simpleaudit.exceptions import SimpleAuditError

try:
    results = auditor.audit_directory("/nonexistent/path")
except SimpleAuditError as e:
    print(f"Audit failed: {e}")

    Common errors: - FileNotFoundError: Path doesn't exist - PermissionError: Cannot read file - InvalidConfigError: Bad configuration value
