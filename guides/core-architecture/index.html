    Core architecture

    Core Architecture¶

    SimpleAudit modular design separates concerns into distinct layers. System processes data through pipeline stages. Each stage isolated, testable.

    Overview¶

    Library captures system events. Events flow through collector, processor, storage layers. Architecture follows unidirectional data flow.

    graph LR
    A[Event Source] --> B[Collector]
    B --> C[Processor]
    C --> D[Storage]
    D --> E[Query Interface]

    Modules:

    • collector.py: Event ingestion.
    • processor.py: Data normalization, filtering.
    • storage.py: Persistence backend.
    • query.py: Retrieval API.

    Data Flow¶

    1. Ingestion: Collector receives raw events. Events arrive via file, network, or function call.
    2. Normalization: Processor standardizes format. Removes noise. Applies rules.
    3. Storage: Storage writes processed events. Supports multiple backends.
    4. Query: Query interface retrieves data. Filters, sorts, aggregates.

    Data moves one direction. No circular dependencies.

    Public API¶

    SimpleAudit Class¶

    Main entry point. Manages lifecycle.

    from simpleaudit import SimpleAudit

audit = SimpleAudit(
    backend="sqlite",
    db_path="audit.db",
    log_level="INFO"
)

    Parameters:

    Parameter Type Default Description
    backend str "memory" Storage engine: memory, sqlite, json.
    db_path str None File path for persistent backends.
    log_level str "WARNING" Logging verbosity.

    Methods:

    • start(): Begin event collection.
    • stop(): Halt collection, flush buffers.
    • record(event: dict): Manually log event.
    • query(filter: dict) -> list[dict]: Retrieve events.

    Event Dataclass¶

    Standard event structure.

    from simpleaudit.models import Event

event = Event(
    timestamp=1715625600,
    source="app-server-01",
    action="login",
    user="admin",
    metadata={"ip": "192.168.1.5"}
)

    Fields:

    Field Type Required Description
    timestamp int Yes Unix epoch seconds.
    source str Yes Origin identifier.
    action str Yes Event type.
    user str No Associated user.
    metadata dict No Additional key-value data.

    Module Interactions¶

    Collector Module¶

    File: simpleaudit/collector.py

    Handles input streams.

    from simpleaudit.collector import FileCollector

collector = FileCollector(path="/var/log/app.log")
collector.start()

    FileCollector tails log file. Parses lines into Event objects. Sends to Processor.

    Processor Module¶

    File: simpleaudit/processor.py

    Applies transformation rules.

    from simpleaudit.processor import RuleProcessor

processor = RuleProcessor()
processor.add_rule("mask_ip", lambda e: e.metadata.get("ip", "").split(".")[0] + ".***")

    Rules execute in order. Each rule modifies event in-place.

    Built-in Rules:

    • normalize_timestamp: Convert string timestamps to epoch.
    • filter_noise: Drop events matching ignore patterns.
    • mask_sensitive: Redact PII fields.

    Storage Module¶

    File: simpleaudit/storage.py

    Abstracts persistence.

    from simpleaudit.storage import SQLiteStorage

storage = SQLiteStorage(db_path="audit.db")
storage.write(event)

    Backends:

    • MemoryStorage: In-memory list. Fast, volatile.
    • SQLiteStorage: File-based. Persistent.
    • JSONStorage: File-based. Human-readable.

    All backends implement StorageInterface:

    class StorageInterface(ABC):
    @abstractmethod
    def write(self, event: Event): pass

    @abstractmethod
    def read(self, filter: dict) -> list[Event]: pass

    Query Module¶

    File: simpleaudit/query.py

    High-level retrieval.

    results = audit.query({
    "action": "login",
    "user": "admin",
    "time_range": (1715625600, 1715712000)
})

    Filter Keys:

    Key Type Description
    action str Exact match.
    user str Exact match.
    source str Exact match.
    time_range tuple (start_epoch, end_epoch).
    metadata dict Key-value match.

    Configuration¶

    Configuration via constructor or config file.

    Config File (audit.yaml):

    backend: sqlite
db_path: ./data/audit.db
log_level: DEBUG
processors:
  - name: mask_ip
    field: metadata.ip
    method: first_octet

    Library loads config on init. Overrides constructor args.

    Error Handling¶

    Exceptions inherit from SimpleAuditError.

    • StorageError: Backend failure.
    • ParseError: Invalid event format.
    • ConfigError: Invalid configuration.

    Catch specific exceptions for robust handling.

    from simpleaudit.exceptions import StorageError

try:
    audit.record(event)
except StorageError as e:
    logger.error(f"Failed to write: {e}")

    Performance Considerations¶

    • Batching: Storage buffers writes. Flushes every 100 events or 5 seconds.
    • Indexing: SQLiteStorage creates indexes on timestamp, action, user.
    • Memory: MemoryStorage grows unbounded. Use for short sessions only.

    Tune batch size via SimpleAudit(batch_size=500).

    Extending¶

    Add custom processor rule:

    class CustomRule:
    def process(self, event: Event) -> Event:
        event.metadata["processed"] = True
        return event

audit.processor.add_rule("custom", CustomRule())

    Add custom storage backend:

    from simpleaudit.storage import StorageInterface

class ElasticsearchStorage(StorageInterface):
    def __init__(self, url: str):
        self.url = url

    def write(self, event: Event):
        # Implement ES index logic
        pass

    def read(self, filter: dict) -> list[Event]:
        # Implement ES query logic
        return []

    Register backend:

    audit.storage = ElasticsearchStorage(url="http://localhost:9200")

    Summary¶

    SimpleAudit separates ingestion, processing, storage, query. Clean interfaces allow swapping components. Data flows unidirectionally. Configuration flexible. Extensible via rule and backend plugins.
