    Core architecture

    Core Architecture¶

    SimpleAudit architecture centers around immutable audit event objects, pluggable storage backends, and deterministic hashing chains. System designed for tamper-evident logging. No mutable state in core event objects.

    System Overview¶

    Data flow: Application generates AuditEvent → AuditLogger validates and serializes → StorageBackend persists event → ChainVerifier validates integrity.

    Key components:

    • AuditEvent: Immutable dataclass representing single log entry.
    • AuditLogger: Main entry point. Handles event creation, hashing, and dispatch.
    • StorageBackend: Abstract base class for persistence strategies.
    • ChainVerifier: Validates hash chain integrity.
    • Config: Global configuration container.

    Module Interactions¶

    graph TD
    A[Application Code] -->|create| B(AuditLogger)
    B -->|validate| C(AuditEvent)
    C -->|hash| D[SHA-256]
    B -->|persist| E(StorageBackend)
    E -->|write| F[(Database/File)]
    G[ChainVerifier] -->|read| E
    G -->|verify| H[Chain Integrity]

    AuditLogger acts as facade. It encapsulates event creation, cryptographic hashing, and storage delegation. Application code interacts only with AuditLogger. Direct access to AuditEvent or StorageBackend discouraged for standard use cases.

    Core Classes¶

    AuditEvent¶

    Immutable representation of a single audit record.

    Parameters:

    Parameter Type Description
    timestamp datetime Event occurrence time (UTC).
    actor str User or system identifier.
    action str Action performed (e.g., "login", "delete").
    resource str Target resource identifier.
    metadata dict Arbitrary key-value pairs.
    prev_hash str Hex digest of previous event.
    hash str Hex digest of current event.

    Properties:

    • to_json(): Returns JSON string representation.
    • to_dict(): Returns dictionary representation.

    Example:

    from simpleaudit.models import AuditEvent
from datetime import datetime, timezone

event = AuditEvent(
    timestamp=datetime.now(timezone.utc),
    actor="user_123",
    action="file_upload",
    resource="doc_456.pdf",
    metadata={"size": 1024},
    prev_hash="0" * 64,
    hash=""  # Calculated by logger
)

    AuditLogger¶

    Primary interface for creating and persisting audit events.

    Constructor Parameters:

    Parameter Type Default Description
    backend StorageBackend None Storage instance. Defaults to InMemoryBackend.
    config Config None Configuration object.
    hash_algorithm str "sha256" Hashing algorithm.

    Methods:

    • log(actor, action, resource, metadata=None) -> AuditEvent Creates, hashes, and persists new event. Returns created AuditEvent.

    • get_last_event() -> Optional[AuditEvent] Retrieves most recent event from storage.

    • verify_chain() -> bool Validates entire hash chain. Returns True if intact.

    Example:

    from simpleaudit import AuditLogger
from simpleaudit.backends import InMemoryBackend

backend = InMemoryBackend()
logger = AuditLogger(backend=backend)

# Log first event
event1 = logger.log(
    actor="admin",
    action="system_start",
    resource="core"
)

# Log second event (links to first)
event2 = logger.log(
    actor="admin",
    action="user_create",
    resource="user_789",
    metadata={"role": "viewer"}
)

print(f"Event 1 Hash: {event1.hash}")
print(f"Event 2 Prev Hash: {event2.prev_hash}")
assert event2.prev_hash == event1.hash

    StorageBackend¶

    Abstract base class. Implementations must define:

    • save(event: AuditEvent) -> None
    • get_all() -> List[AuditEvent]
    • get_last() -> Optional[AuditEvent]

    Built-in Backends:

    1. InMemoryBackend:
    2. Stores events in Python list.
    3. Use for testing or ephemeral sessions.

    4. No persistence across restarts.

    5. FileBackend:

    6. Appends JSON lines to file.
    7. Parameters: file_path (str), encoding (str, default "utf-8").

    8. Use for lightweight local logging.

    9. SQLAlchemyBackend:

    10. Uses SQLAlchemy ORM.
    11. Parameters: engine (SQLAlchemy Engine).
    12. Use for production databases (PostgreSQL, MySQL, SQLite).

    Example: File Backend

    from simpleaudit.backends import FileBackend

backend = FileBackend(file_path="audit.log")
logger = AuditLogger(backend=backend)
logger.log(actor="test", action="init", resource="app")

    ChainVerifier¶

    Utility class for independent chain validation.

    Methods:

    • verify(events: List[AuditEvent]) -> VerificationResult Checks hash linkage and cryptographic integrity.

    VerificationResult Fields:

    Field Type Description
    is_valid bool Overall chain status.
    broken_at_index Optional[int] Index of first broken link.
    errors List[str] List of error messages.

    Example:

    from simpleaudit.verifier import ChainVerifier

verifier = ChainVerifier()
events = backend.get_all()
result = verifier.verify(events)

if not result.is_valid:
    print(f"Chain broken at index {result.broken_at_index}")
    for err in result.errors:
        print(err)

    Configuration¶

    Config class holds global settings.

    Attributes:

    Attribute Type Default Description
    hash_algorithm str "sha256" Algorithm for event hashing.
    timestamp_format str "%Y-%m-%dT%H:%M:%SZ" ISO 8601 format string.
    max_metadata_size int 4096 Max bytes for metadata JSON.

    Usage:

    from simpleaudit.config import Config

config = Config(
    hash_algorithm="sha512",
    max_metadata_size=8192
)
logger = AuditLogger(config=config)

    Data Flow Details¶

    1. Event Creation: AuditLogger.log() receives input. Constructs AuditEvent instance. prev_hash set from last stored event. If no previous event, prev_hash is zero-padded string (64 chars for SHA-256).

    2. Hashing: Canonical JSON serialization of event fields (excluding hash field). Hash computed using configured algorithm. Result stored in event.hash.

    3. Persistence: AuditLogger calls backend.save(event). Backend implementation handles storage specifics.

    4. Verification: ChainVerifier iterates events. Recalculates hash for each event. Compares recalculated hash with stored hash. Compares prev_hash of current event with hash of previous event. Any mismatch triggers error.

    Error Handling¶

    Exceptions raised:

    • AuditValidationError: Raised if event data invalid (e.g., missing actor, metadata too large).
    • StorageError: Raised if backend fails to persist or retrieve data.
    • ChainIntegrityError: Raised if verification fails (only if strict_mode=True in config).

    Best Practice: Wrap logger.log() calls in try-except blocks. Log errors to separate error channel. Do not silently swallow StorageError.

    Performance Considerations¶

    • Hashing: SHA-256 computation negligible for typical metadata sizes.
    • Storage: I/O bound. Use async backends if available (not in core library).
    • Memory: InMemoryBackend grows unbounded. Use FileBackend or SQLAlchemyBackend for long-running processes.
    • Batching: No native batch logging. For high-throughput scenarios, implement custom backend that buffers writes.

    File Structure¶

    simpleaudit/

│   ├── memory.py      # InMemoryBackend

│   └── sql.py         # SQLAlchemyBackend
├── verifier.py        # ChainVerifier, VerificationResult
└── exceptions.py      # Custom exceptions

    Security Notes¶

    • Events immutable after creation.
    • Hash chain prevents retroactive modification.
    • Metadata must be JSON-serializable.
    • No encryption at rest by default. Use encrypted storage backend or database-level encryption for sensitive data.
    • Timestamps trusted from system clock. NTP sync recommended.

    Migration Guide¶

    From v1.0 to v2.0:

    • AuditLogger constructor now requires explicit backend parameter (previously optional).
    • AuditEvent.metadata changed from str to dict.
    • verify_chain() method moved from AuditLogger to ChainVerifier.

    Update Code:

    # Old (v1.0)
logger = AuditLogger()
logger.verify_chain()

# New (v2.0)
backend = InMemoryBackend()
logger = AuditLogger(backend=backend)
verifier = ChainVerifier()
verifier.verify(backend.get_all())
