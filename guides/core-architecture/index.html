    Core architecture

    Core Architecture¶

    SimpleAudit provides lightweight audit logging for Python applications. System captures function calls, arguments, and return values. Design prioritizes zero-overhead when disabled. Minimal dependency footprint.

    High-Level Design¶

    Architecture follows observer pattern. Core components:

    1. AuditLogger: Main entry point. Manages lifecycle, configuration, and active state.
    2. AuditEvent: Data class. Stores timestamp, function name, arguments, result, error details.
    3. AuditHandler: Abstract base class. Defines interface for output destinations.
    4. ConsoleHandler: Default implementation. Writes to sys.stdout.
    5. FileHandler: Writes to disk. Supports rotation.
    6. AuditDecorator: Wraps functions. Intercepts calls, logs events.

    Data flow:

    Function Call
    ↓
AuditDecorator.__call__
    ↓
Check AuditLogger.enabled
    ↓ (if enabled)
Create AuditEvent
    ↓
Pass to AuditHandler.handle()
    ↓
Write output (console/file)

    When disabled, decorator returns original function immediately. No event creation. Negligible overhead.

    Module Structure¶

    simpleaudit/
├── __init__.py          # Public API exports
├── core.py              # AuditLogger, AuditEvent
├── handlers.py          # AuditHandler, ConsoleHandler, FileHandler
├── decorators.py        # AuditDecorator, audit() function
└── config.py            # Configuration dataclasses

    Public API¶

    AuditLogger¶

    Main controller. Singleton pattern recommended for global state.

    Parameters:

    Parameter Type Default Description
    enabled bool True Master switch.
    handlers List[AuditHandler] [ConsoleHandler()] Output destinations.
    filter Callable[[AuditEvent], bool] None Custom filter function.

    Methods:

    • enable(): Set enabled = True.
    • disable(): Set enabled = False.
    • add_handler(handler: AuditHandler): Append to handler list.
    • remove_handler(handler: AuditHandler): Remove specific handler.
    • clear_handlers(): Empty handler list.

    Example:

    from simpleaudit import AuditLogger, ConsoleHandler, FileHandler

logger = AuditLogger(
    enabled=True,
    handlers=[ConsoleHandler(), FileHandler("audit.log")]
)

# Later in application
logger.disable()

    AuditEvent¶

    Immutable data object. Created internally by decorators.

    Attributes:

    Attribute Type Description
    timestamp datetime UTC time of call.
    function_name str Qualified name (module.func).
    args tuple Positional arguments.
    kwargs dict Keyword arguments.
    result Any Return value (if success).
    error Exception Exception object (if failure).
    duration_ms float Execution time.

    Example:

    event = AuditEvent(
    timestamp=datetime.utcnow(),
    function_name="myapp.process",
    args=(1, 2),
    kwargs={"verbose": True},
    result=42,
    error=None,
    duration_ms=12.5
)

    AuditHandler¶

    Abstract base class. Subclass to create custom output.

    Required Method:

    • handle(event: AuditEvent) -> None: Process event. Must be implemented.

    Optional Method:

    • flush() -> None: Force write to storage.

    Example Custom Handler:

    from simpleaudit.handlers import AuditHandler
from simpleaudit.core import AuditEvent

class JsonHandler(AuditHandler):
    def __init__(self, filepath: str):
        self.filepath = filepath

    def handle(self, event: AuditEvent):
        import json
        data = {
            "time": event.timestamp.isoformat(),
            "func": event.function_name,
            "args": str(event.args),
            "result": str(event.result),
            "error": str(event.error) if event.error else None
        }
        with open(self.filepath, "a") as f:
            f.write(json.dumps(data) + "\n")

    audit() Decorator¶

    Primary usage interface. Wraps function for auditing.

    Parameters:

    Parameter Type Default Description
    logger AuditLogger None Specific logger instance. Uses global if None.
    include_args bool True Log argument values.
    include_result bool True Log return value.
    ignore_exceptions bool False Log exceptions but do not re-raise.

    Example:

    from simpleaudit import audit, AuditLogger

logger = AuditLogger()

@audit(logger=logger)
def calculate_total(items: list, tax_rate: float = 0.0) -> float:
    total = sum(items)
    return total * (1 + tax_rate)

# Usage
result = calculate_total([10, 20, 30], tax_rate=0.1)
# Output: [AUDIT] calculate_total(args=([10, 20, 30],), kwargs={'tax_rate': 0.1}, result=55.0)

    Class Method Usage:

    class PaymentProcessor:
    @audit()
    def process(self, amount: float) -> bool:
        # ...
        return True

    Decorator handles self automatically. Excludes self from logged args by default.

    Configuration Options¶

    Configuration via AuditLogger constructor or environment variables.

    Environment Variables:

    Variable Description Default
    SIMPLEAUDIT_ENABLED "true" / "false" "true"
    SIMPLEAUDIT_LOG_FILE Path for default FileHandler None
    SIMPLEAUDIT_LOG_LEVEL "DEBUG", "INFO", "ERROR" "INFO"

    Programmatic Configuration:

    import os
os.environ["SIMPLEAUDIT_ENABLED"] = "false"

from simpleaudit import AuditLogger
logger = AuditLogger()
assert logger.enabled == False

    Data Flow Details¶

    1. Interception: AuditDecorator.__call__ executes.
    2. Check: logger.enabled evaluated. If False, call original function directly. Return result.
    3. Capture Start: Record start_time.
    4. Execution: Call wrapped function. Catch exceptions.
    5. Capture End: Record end_time. Calculate duration_ms.
    6. Event Creation: Instantiate AuditEvent. Populate fields.
    7. Filtering: If logger.filter exists, call it. If returns False, discard event.
    8. Dispatch: Iterate logger.handlers. Call handler.handle(event) for each.
    9. Error Handling: If handler raises exception, log to stderr. Do not crash application.

    Performance Considerations¶

    • Disabled Mode: Overhead < 1 microsecond. Single boolean check.
    • Enabled Mode: Overhead depends on handler. ConsoleHandler slowest due to I/O.
    • Argument Serialization: Large objects may cause memory spikes. Use include_args=False for heavy payloads.
    • Thread Safety: AuditLogger state changes not thread-safe. Use threading.Lock for concurrent enable/disable. Handlers should be thread-safe.

    Integration Patterns¶

    Flask/FastAPI Middleware:

    from simpleaudit import AuditLogger, audit

logger = AuditLogger()

@app.before_request
def audit_request():
    # Log request metadata manually if needed
    pass

@app.route("/api/data")
@audit(logger=logger)
def get_data():
    return jsonify({"status": "ok"})

    Testing:

    import unittest
from simpleaudit import AuditLogger, ConsoleHandler

class TestAudit(unittest.TestCase):
    def test_logging(self):
        logger = AuditLogger(enabled=True, handlers=[ConsoleHandler()])

        @audit(logger=logger)
        def add(a, b):
            return a + b

        result = add(1, 2)
        self.assertEqual(result, 3)
        # Verify output captured (use capsys in pytest)

    Limitations¶

    • No distributed tracing support.
    • No automatic redaction of sensitive data (passwords, tokens). Implement custom filter.
    • AuditEvent stores raw arguments. Ensure no PII if logging to persistent storage.
    • Async functions require audit_async() decorator (separate module).

    Summary¶

    SimpleAudit core architecture separates concerns: logging logic (core), output mechanisms (handlers), and interception (decorators). AuditLogger acts as central coordinator. Developers configure once, decorate functions, and receive structured audit trails. System remains lightweight by design. Disable when not needed.
