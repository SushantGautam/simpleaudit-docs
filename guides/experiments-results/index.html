    Experiments results

    Experiments & Results¶

    simpleaudit.experiments module manages experiment lifecycle. Defines runs, processes outputs, aggregates repeated results. Ensures reproducibility.

    Overview¶

    Module handles three core tasks:

    1. Experiment Definition: Create structured records for test runs.
    2. Output Processing: Parse raw model outputs into structured data.
    3. Result Aggregation: Combine multiple runs into final metrics.

    Use this module when running batch evaluations or comparing model versions.

    Classes¶

    Experiment¶

    Represents single experimental run.

    Attributes:

    Attribute Type Description
    id str Unique identifier. Auto-generated if not provided.
    name str Human-readable name.
    model str Model identifier.
    config dict Configuration parameters.
    timestamp datetime Creation time.
    status str Current state (pending, running, completed, failed).

    Methods:

    • save(path: str): Persist experiment metadata to JSON file.
    • load(path: str): Class method. Load experiment from JSON.

    Result¶

    Stores processed output from single sample.

    Attributes:

    Attribute Type Description
    sample_id str Identifier for input data point.
    raw_output str Unprocessed model response.
    parsed dict Structured data extracted from raw_output.
    metrics dict Calculated scores (e.g., accuracy, latency).
    error str Error message if processing failed. None if success.

    Aggregator¶

    Combines multiple Result objects.

    Methods:

    • add(result: Result): Add result to collection.
    • calculate_metrics(): Compute aggregate statistics.
    • to_dataframe(): Return pandas.DataFrame of all results.

    Functions¶

    define_experiment(name, model, config)¶

    Creates new Experiment instance.

    Parameters:

    • name (str): Experiment label.
    • model (str): Model name/version.
    • config (dict): Hyperparameters. Keys: temperature, max_tokens, seed.

    Returns: Experiment object.

    process_output(raw_text, schema)¶

    Parses raw model output into structured dictionary.

    Parameters:

    • raw_text (str): Raw string from model.
    • schema (dict): Expected JSON schema. Defines required keys and types.

    Returns: dict containing parsed data. Raises ParsingError if schema mismatch.

    aggregate_results(results: list[Result])¶

    Computes mean, median, standard deviation for all metrics.

    Parameters:

    • results (list[Result]): List of processed results.

    Returns: dict with keys: mean, median, std, count.

    Code Examples¶

    1. Defining an Experiment¶

    from simpleaudit.experiments import define_experiment
from datetime import datetime

# Create experiment
exp = define_experiment(
    name="GPT-4o Baseline",
    model="gpt-4o-2024-05-13",
    config={
        "temperature": 0.7,
        "max_tokens": 1024,
        "seed": 42
    }
)

print(f"Experiment ID: {exp.id}")
print(f"Status: {exp.status}")

# Save to disk
exp.save("experiments/gpt4o_baseline.json")

    2. Processing Outputs¶

    from simpleaudit.experiments import process_output, Result

# Define expected schema
schema = {
    "answer": "str",
    "confidence": "float"
}

# Simulate raw model output
raw_text = '{"answer": "Paris", "confidence": 0.95}'

# Parse output
try:
    parsed_data = process_output(raw_text, schema)
    print(f"Parsed: {parsed_data}")

    # Create Result object
    result = Result(
        sample_id="q_001",
        raw_output=raw_text,
        parsed=parsed_data,
        metrics={"accuracy": 1.0, "latency": 0.23}
    )
except Exception as e:
    print(f"Processing failed: {e}")

    3. Aggregating Results¶

    from simpleaudit.experiments import Aggregator, Result

# Initialize aggregator
agg = Aggregator()

# Add multiple results
results = [
    Result(sample_id="1", raw_output="", parsed={}, metrics={"score": 0.8}),
    Result(sample_id="2", raw_output="", parsed={}, metrics={"score": 0.9}),
    Result(sample_id="3", raw_output="", parsed={}, metrics={"score": 0.7})
]

for r in results:
    agg.add(r)

# Calculate aggregate metrics
stats = agg.calculate_metrics()
print(f"Mean Score: {stats['mean']:.2f}")
print(f"Std Dev: {stats['std']:.2f}")

# Export to DataFrame
df = agg.to_dataframe()
print(df.head())

    Configuration Options¶

    config dictionary in define_experiment supports:

    Key Type Default Description
    temperature float 0.7 Sampling randomness.
    max_tokens int 1024 Max response length.
    seed int None Random seed for reproducibility.
    top_p float 1.0 Nucleus sampling threshold.

    Error Handling¶

    • ParsingError: Raised by process_output when raw text does not match schema.
    • FileNotFoundError: Raised by Experiment.load if path invalid.
    • ValueError: Raised by Aggregator.calculate_metrics if no results added.

    Always wrap process_output in try-except blocks when processing batch data. Log errors to Result.error field to maintain data integrity.

    Best Practices¶

    1. Unique IDs: Use UUIDs for Experiment.id to avoid collisions.
    2. Schema Validation: Define strict JSON schemas for process_output to catch malformed outputs early.
    3. Seed Management: Always set seed in config for reproducible experiments.
    4. Batch Processing: Use Aggregator for large datasets. Avoid storing all results in memory if possible; stream to disk.
    5. Logging: Log Experiment metadata to external tracking system (e.g., MLflow, Weights & Biases) alongside local JSON files.
