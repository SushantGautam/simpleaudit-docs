    Experiments & Results¶

    simpleaudit.experiments module defines experiments, processes raw outputs, aggregates repeated results. Core subsystem for managing experimental runs.

    Overview¶

    Experiments represent single test configurations. Results capture individual run outputs. Aggregations combine multiple runs into statistical summaries. Module handles data structures, processing logic, result consolidation.

    Core Classes¶

    Experiment¶

    Defines single experimental setup.

    class Experiment:
    def __init__(self, name: str, config: dict, iterations: int = 1):
        """
        Initialize experiment.

        Args:
            name: Unique identifier string.
            config: Dictionary containing parameters.
            iterations: Number of times to run experiment. Default 1.
        """
        self.name = name
        self.config = config
        self.iterations = iterations
        self.results = []

    Attributes:

    Attribute Type Description
    name str Unique experiment identifier.
    config dict Parameter key-value pairs.
    iterations int Repetition count.
    results list Collected Result objects.

    Result¶

    Stores single run output.

    class Result:
    def __init__(self, experiment_name: str, metrics: dict, metadata: dict = None):
        """
        Store single execution result.

        Args:
            experiment_name: Parent experiment identifier.
            metrics: Dictionary of measured values.
            metadata: Optional context information.
        """
        self.experiment_name = experiment_name
        self.metrics = metrics
        self.metadata = metadata or {}
        self.timestamp = datetime.now()

    Attributes:

    Attribute Type Description
    experiment_name str Associated experiment.
    metrics dict Measured performance/quality values.
    metadata dict Contextual data.
    timestamp datetime Execution time.

    Aggregator¶

    Processes repeated results. Computes statistics.

    class Aggregator:
    def __init__(self, method: str = "mean"):
        """
        Initialize aggregation strategy.

        Args:
            method: Aggregation function. Options: "mean", "median", "std".
        """
        self.method = method

    def aggregate(self, results: list[Result]) -> dict:
        """
        Combine results into summary statistics.

        Args:
            results: List of Result objects.

        Returns:
            Dictionary containing aggregated metrics.
        """
        if not results:
            return {}

        metric_keys = set()
        for r in results:
            metric_keys.update(r.metrics.keys())

        aggregated = {}
        for key in metric_keys:
            values = [r.metrics[key] for r in results if key in r.metrics]
            aggregated[key] = self._compute(values)

        return aggregated

    def _compute(self, values: list[float]) -> float:
        if self.method == "mean":
            return sum(values) / len(values)
        elif self.method == "median":
            sorted_vals = sorted(values)
            mid = len(sorted_vals) // 2
            if len(sorted_vals) % 2 == 0:
                return (sorted_vals[mid - 1] + sorted_vals[mid]) / 2
            return sorted_vals[mid]
        elif self.method == "std":
            mean = sum(values) / len(values)
            variance = sum((x - mean) ** 2 for x in values) / len(values)
            return variance ** 0.5
        raise ValueError(f"Unknown method: {self.method}")

    Functions¶

    run_experiment¶

    Executes experiment multiple times. Collects results.

    def run_experiment(experiment: Experiment, task_func: callable) -> list[Result]:
    """
    Execute experiment specified number of times.

    Args:
        experiment: Experiment configuration object.
        task_func: Callable receiving config, returning metrics dict.

    Returns:
        List of Result objects.
    """
    results = []
    for i in range(experiment.iterations):
        metrics = task_func(experiment.config)
        result = Result(
            experiment_name=experiment.name,
            metrics=metrics,
            metadata={"iteration": i}
        )
        results.append(result)
        experiment.results.append(result)
    return results

    compare_experiments¶

    Compares aggregated results across experiments.

    def compare_experiments(experiment_results: dict[str, list[Result]], 
                        metric: str, 
                        method: str = "mean") -> dict:
    """
    Compare specific metric across multiple experiments.

    Args:
        experiment_results: Mapping of experiment names to result lists.
        metric: Metric key to compare.
        method: Aggregation method.

    Returns:
        Dictionary of experiment names to aggregated metric values.
    """
    aggregator = Aggregator(method=method)
    comparison = {}
    for exp_name, results in experiment_results.items():
        aggregated = aggregator.aggregate(results)
        if metric in aggregated:
            comparison[exp_name] = aggregated[metric]
    return comparison

    Usage Examples¶

    Basic Experiment¶

    from simpleaudit.experiments import Experiment, run_experiment, Aggregator

def sample_task(config):
    import time
    start = time.time()
    # Simulate work
    time.sleep(config.get("duration", 0.1))
    return {"latency": time.time() - start, "throughput": 1000}

exp = Experiment(
    name="baseline_test",
    config={"duration": 0.1, "threads": 4},
    iterations=5
)

results = run_experiment(exp, sample_task)
print(f"Collected {len(results)} results")

    Aggregating Results¶

    aggregator = Aggregator(method="mean")
summary = aggregator.aggregate(results)
print(f"Average latency: {summary['latency']:.4f}s")
print(f"Average throughput: {summary['throughput']:.2f} ops/s")

    Comparing Configurations¶

    exp_a = Experiment("config_a", {"threads": 2}, iterations=10)
exp_b = Experiment("config_b", {"threads": 8}, iterations=10)

results_a = run_experiment(exp_a, sample_task)
results_b = run_experiment(exp_b, sample_task)

comparison = compare_experiments(
    {"config_a": results_a, "config_b": results_b},
    metric="latency",
    method="median"
)

for name, value in comparison.items():
    print(f"{name}: {value:.4f}s")

    Configuration Options¶

    Experiment config dictionary accepts arbitrary keys. Common parameters:

    Key Type Description
    duration float Task execution time in seconds.
    threads int Concurrency level.
    batch_size int Data batch size.
    timeout float Maximum execution time.

    Custom keys supported. Task function receives full config dictionary.

    Error Handling¶

    • run_experiment propagates exceptions from task_func.
    • Aggregator._compute raises ValueError for unknown methods.
    • Empty result lists return empty dictionaries.
    • Missing metrics handled gracefully during aggregation.

    Best Practices¶

    • Use unique experiment names.
    • Set iterations ≥ 3 for statistical significance.
    • Store metadata for debugging.
    • Choose aggregation method based on distribution:
    • mean for normal distributions
    • median for skewed data
    • std for variance analysis
    • Log raw results before aggregation.
    • Version control experiment configurations.

    Performance Notes¶

    • Aggregation O(n·m) where n = results, m = metrics.
    • Memory usage proportional to stored results.
    • For large datasets, consider streaming aggregation.
    • Timestamps use system clock. Ensure NTP sync for distributed systems.
