    Test scenarios

    Test Scenarios¶

    simpleaudit.scenarios module provides built-in adversarial test cases for auditing AI systems. Packs target specific failure modes: safety, RAG integrity, healthcare boundaries, and epistemic honesty.

    Available Packs¶

    SCENARIO_PACKS dictionary maps pack names to scenario lists.

    Pack Name Description Count
    safety General AI safety (hallucination, manipulation, privacy) 8
    rag Retrieval-Augmented Generation (source attribution, confusion) 8
    health Healthcare domain (diagnosis, prescription, emergency) 8
    system_prompt System prompt adherence/bypass testing Variable
    helpmed Help and medical scenarios Variable
    ung UNG scenarios Variable
    bullshitbench_v1 BullshitBench v1 (business/management) 55
    bullshitbench_v2 BullshitBench v2 (software/finance/legal/medical/physics) 100
    bullshitbench Combined v1 + v2 155
    health_bullshit Health-specific broken premise scenarios 15
    epistemic_safety All bullshitbench + health_bullshit 170
    hei_refusal Norwegian youth Q&A refusal/guidance edge cases 47
    nav_aap NAV welfare scenarios 15
    skatteetaten Norwegian Tax Administration scenarios In development
    helfo Helfo health-economics scenarios 8
    lanekassen Lånekassen student-finance scenarios 8
    vision_integrity Chart-reading integrity (requires vision models) 8
    all All text-based scenarios combined Variable

    Note: vision_integrity excluded from all and epistemic_safety. Requires vision-capable target, judge, and auditor models.

    Public API¶

    get_scenarios(pack_name: str) -> List[Dict]¶

    Retrieves scenario list for specified pack. Returns shallow copy to prevent mutation of shared registry.

    Parameters: * pack_name (str): Key from SCENARIO_PACKS.

    Returns: * List[Dict]: List of scenario dictionaries.

    Raises: * ValueError: If pack_name unrecognized.

    list_scenario_packs() -> Dict[str, int]¶

    Lists available packs and scenario counts.

    Returns: * Dict[str, int]: Mapping pack names to scenario counts.

    duplicate_scenario_names(scenarios: List[Dict]) -> Dict[str, int]¶

    Validates custom scenario lists. Returns scenario names appearing more than once. Duplicate names corrupt stability statistics in RepeatedExperimentResults.stability.

    Parameters: * scenarios (List[Dict]): List of scenario dicts. Each must have name key.

    Returns: * Dict[str, int]: Mapping duplicated names to occurrence counts. Empty dict if all unique.

    Scenario Schema¶

    Scenarios use two schemas:

    Legacy Schema (v1): Used by safety, rag, health, system_prompt, helpmed, ung.

    {
  "name": "Scenario Name",
  "description": "Detailed test description"
}

    Extended Schema (v2.0): Used by bullshitbench_*, health_bullshit, hei_refusal, nav_aap, helfo, lanekassen, vision_integrity.

    {
  "schema_version": "2.0",
  "name": "Unique Identifier",
  "description": "Summary of test intent",
  "test_prompt": "Actual prompt sent to model",
  "language": "en",
  "expected_behavior": [
    "Expected action 1",
    "NOT expected action 2"
  ],
  "category": "Primary Category",
  "subcategory": "Specific Subcategory",
  "severity": "low | medium | high | critical",
  "source": {
    "type": "synthetic | adapted",
    "origin": "Source attribution",
    "inspiration": "Contextual rationale"
  },
  "metadata": {
    "author": "Author Name",
    "date_created": "YYYY-MM-DD",
    "rationale": "Detailed explanation of broken premise",
    "tags": ["tag1", "tag2"],
    "variations": [
      {
        "test_prompt": "Alternative prompt",
        "note": "Context for variation"
      }
    ]
  }
}

    Usage Examples¶

    Load and inspect scenarios:

    from simpleaudit.scenarios import get_scenarios, list_scenario_packs

# List all available packs
packs = list_scenario_packs()
print(packs)
# {'safety': 8, 'rag': 8, 'health': 8, ...}

# Load specific pack
health_scenarios = get_scenarios("health")
print(len(health_scenarios))  # 8

# Access scenario details
first_scenario = health_scenarios[0]
print(first_scenario["name"])       # "Health - Emergency Response"
print(first_scenario["description"])

    Validate custom scenarios:

    from simpleaudit.scenarios import duplicate_scenario_names

custom_scenarios = [
    {"name": "Test A", "description": "..."},
    {"name": "Test B", "description": "..."},
    {"name": "Test A", "description": "..."}  # Duplicate
]

duplicates = duplicate_scenario_names(custom_scenarios)
if duplicates:
    print(f"Warning: Duplicate names found: {duplicates}")
    # {'Test A': 2}

    Iterate through extended schema scenarios:

    from simpleaudit.scenarios import get_scenarios

bsb_scenarios = get_scenarios("bullshitbench_v1")

for scenario in bsb_scenarios:
    name = scenario["name"]
    prompt = scenario["test_prompt"]
    severity = scenario["severity"]
    expected = scenario["expected_behavior"]

    print(f"[{severity.upper()}] {name}")
    print(f"Prompt: {prompt}")
    print(f"Expected: {expected[0]}")
    print("-" * 40)

    Key Considerations¶

    1. Immutability: get_scenarios returns shallow copy. Modifying returned list does not affect internal SCENARIO_PACKS registry.
    2. Vision Integrity: vision_integrity pack requires vision-capable models for target, judge, and auditor. Excluded from all to prevent failures in text-only setups.
    3. Naming Uniqueness: Scenario names must be unique within a pack. Duplicate names cause stability statistics to collapse into single entries. Use duplicate_scenario_names for validation.
    4. BullshitBench Alignment:
      • BullshitBench Score 0 (full engagement) → SimpleAudit high/critical
      • BullshitBench Score 1 (hedged answer) → SimpleAudit medium
      • BullshitBench Score 2 (clear identification) → SimpleAudit pass
    5. Health Safety: health and health_bullshit packs test high-severity scenarios where incorrect information causes real harm. Expected behaviors emphasize refusal, deferral to professionals, and challenging false premises.
