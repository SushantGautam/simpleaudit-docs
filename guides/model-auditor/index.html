    Model auditor

    Model Auditor¶

    ModelAuditor core auditing engine. Handles model loading, inference execution, result aggregation. Part of SimpleAudit library.

    Overview¶

    ModelAuditor manages lifecycle of machine learning models for audit purposes. Loads models from disk or memory. Runs inference on input data. Captures outputs, latencies, resource usage. Enables reproducibility of audit trails.

    Key responsibilities: - Model instantiation and validation - Batch inference processing - Output normalization - Audit log generation

    Class: ModelAuditor¶

    Primary class for model interaction.

    Constructor¶

    from simpleaudit.auditor import ModelAuditor

auditor = ModelAuditor(
    model_path="path/to/model",
    device="cpu",
    batch_size=32,
    verbose=False
)

    Parameters:

    Parameter Type Default Description
    model_path str None File path to serialized model. Required if model_obj not provided.
    model_obj object None Pre-loaded model instance. Overrides model_path.
    device str "cpu" Target compute device ("cpu", "cuda", "mps").
    batch_size int 32 Number of samples per inference batch.
    verbose bool False Enable debug logging.
    dtype str "float32" Data type for inference ("float32", "float16", "int8").

    Method: load()¶

    Loads model into memory. Validates architecture and weights.

    auditor.load()

    Returns: None

    Raises: - FileNotFoundError: If model_path invalid. - ModelLoadError: If weights corrupted or architecture mismatch.

    Method: audit()¶

    Executes inference on input data. Returns audit record.

    results = auditor.audit(
    input_data,
    metadata=None,
    capture_intermediates=False
)

    Parameters:

    Parameter Type Default Description
    input_data array-like Required Input tensor or list of samples. Shape (N, ...).
    metadata dict None Additional context for audit log.
    capture_intermediates bool False Save layer outputs for debugging.

    Returns: AuditResult object.

    Method: save_audit_log()¶

    Persists audit results to disk.

    auditor.save_audit_log(
    results,
    output_path="audit_logs/run_01.json",
    format="json"
)

    Parameters:

    Parameter Type Default Description
    results AuditResult Required Output from audit() method.
    output_path str Required Destination file path.
    format str "json" Serialization format ("json", "csv", "parquet").

    Class: AuditResult¶

    Container for inference outputs and metrics.

    Attributes:

    Attribute Type Description
    predictions np.ndarray Model output array.
    latency_ms float Total inference time in milliseconds.
    batch_size int Actual batch size processed.
    device str Device used for computation.
    timestamp datetime Audit execution time.
    metadata dict User-provided context.

    Usage Example¶

    Basic audit workflow:

    import numpy as np
from simpleaudit.auditor import ModelAuditor

# 1. Initialize auditor
auditor = ModelAuditor(
    model_path="models/classifier_v2.pt",
    device="cuda",
    batch_size=64
)

# 2. Load model
auditor.load()

# 3. Prepare input
dummy_data = np.random.rand(128, 10).astype(np.float32)

# 4. Run audit
results = auditor.audit(
    input_data=dummy_data,
    metadata={"run_id": "test_001", "version": "2.0"}
)

# 5. Inspect results
print(f"Latency: {results.latency_ms:.2f}ms")
print(f"Predictions shape: {results.predictions.shape}")

# 6. Save log
auditor.save_audit_log(
    results,
    output_path="logs/test_001.json"
)

    Configuration Options¶

    Global config via simpleaudit.config:

    import simpleaudit.config as cfg

cfg.set_default_device("cpu")
cfg.set_log_level("DEBUG")
cfg.set_max_batch_size(1024)

    Error Handling¶

    Common exceptions:

    Exception Cause Resolution
    ModelLoadError Corrupted weights, wrong architecture Verify model file integrity. Check version compatibility.
    DeviceMismatchError Model saved on different device Use device parameter matching model origin.
    InputShapeError Input dimensions mismatch model input Reshape input_data to expected dimensions.

    Performance Notes¶

    • batch_size affects memory usage. Higher batches = faster throughput, higher VRAM.
    • dtype="float16" reduces memory by 50%. May lose precision.
    • capture_intermediates=True increases memory usage significantly. Use only for debugging.

    Best Practices¶

    1. Version Control: Include model hash in metadata.
    2. Reproducibility: Set random seeds before audit().
    3. Monitoring: Track latency_ms over time for drift detection.
    4. Storage: Use "parquet" format for large datasets. Better compression than JSON.

    ModelAuditor provides deterministic, auditable inference pipeline. Essential for compliance and debugging.
