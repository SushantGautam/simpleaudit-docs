    Visualization server

    Visualization Server¶

    The visualization/server.py module provides a FastAPI-based web interface for visualizing SimpleAudit results. It serves a local web server that displays audit data stored in JSON files. The server supports optional authentication via environment variables and provides REST API endpoints for file discovery and data retrieval.

    Overview¶

    The visualization server binds to a local host (default 127.0.0.1) and exposes the following capabilities:

    • Serves the main visualization HTML page at /
    • Serves a standalone scenario viewer at /scenario_viewer.html
    • Provides a file tree API at /api/files
    • Provides JSON file retrieval at /api/json/{file_path}
    • Supports optional secret-based authentication
    • Validates JSON files to ensure they contain valid audit results

    Configuration¶

    Configuration is controlled via environment variables:

    Variable Description Default
    SIMPLEAUDIT_VISUALIZER_SECRET Secret key for authentication. If blank, authentication disabled. ""
    SIMPLEAUDIT_VISUALIZER_EMAIL Contact email displayed in frontend when auth enabled. "sushant@simula.no"

    Public Functions¶

    start_server(results_dir, host="127.0.0.1", port=8000)¶

    Starts the FastAPI server.

    Parameters:

    • results_dir (str): Directory containing JSON result files. Relative paths resolved from current working directory.
    • host (str): Host to bind to. Default "127.0.0.1".
    • port (int): Port to run on. Default 8000.

    Behavior:

    1. Reads environment variables for secret and contact email
    2. Resolves results_dir to absolute path
    3. Validates directory exists and is a directory
    4. Prints startup information
    5. Starts uvicorn server

    Example:

    from simpleaudit.visualization.server import start_server

start_server(results_dir="./results", port=8080)

    is_valid_audit_json(file_path)¶

    Checks if a JSON file contains valid audit results.

    Parameters:

    • file_path (str): Full path to the JSON file.

    Returns:

    • bool: True if file contains valid audit results, False otherwise.

    Validation Logic:

    • File must be valid JSON
    • JSON must be either:
    • A non-empty array, OR
    • An object with a results key containing a non-empty array

    Example:

    from simpleaudit.visualization.server import is_valid_audit_json

if is_valid_audit_json("./results/audit_2024.json"):
    print("Valid audit file")

    get_file_tree(directory, base_path="")¶

    Recursively gets the file tree structure for JSON files.

    Parameters:

    • directory (str): Full path to scan.
    • base_path (str): Relative path from root results directory. Default "".

    Returns:

    • List[Dict]: List of dicts representing folders and JSON files.

    Folder Structure:

    {
    "name": "folder_name",
    "type": "folder",
    "path": "relative/path",
    "children": [...]
}

    File Structure:

    {
    "name": "file.json",
    "type": "file",
    "path": "relative/path/file.json"
}

    Only folders containing valid JSON files (directly or in subdirectories) are included.

    API Endpoints¶

    GET /¶

    Serves the main visualization page.

    Response:

    • 200: HTML content of visualizer.html
    • 500: Error if template not found

    GET /scenario_viewer.html¶

    Serves the standalone scenario viewer page.

    Response:

    • 200: HTML content of scenario_viewer.html
    • 500: Error if template not found

    GET /favicon.png¶

    Serves the favicon.

    Response:

    • 200: PNG image
    • 404: If favicon not found

    GET /api/auth¶

    Verifies authentication status.

    Headers:

    • X-Secret: Required if secret configured.

    Response:

    {
    "ok": true,
    "enabled": true,
    "contact_email": "sushant@simula.no"
}
    • enabled: true if secret configured, false otherwise
    • contact_email: From environment variable or default

    Errors:

    • 401: If secret configured but missing/incorrect

    GET /api/files¶

    Gets the file tree of JSON files in the results directory.

    Headers:

    • X-Secret: Required if secret configured.

    Response:

    {
    "tree": [
        {
            "name": "folder",
            "type": "folder",
            "path": "folder",
            "children": [
                {
                    "name": "audit.json",
                    "type": "file",
                    "path": "folder/audit.json"
                }
            ]
        }
    ]
}

    Errors:

    • 401: If secret configured but missing/incorrect
    • 404: If results directory not found
    • 500: If results directory not set

    GET /api/json/{file_path}¶

    Gets the contents of a specific JSON file.

    Path Parameters:

    • file_path: Relative path to JSON file within results directory.

    Headers:

    • X-Secret: Required if secret configured.

    Response:

    • 200: JSON content of the file

    Security:

    • Prevents path traversal attacks
    • Only serves .json files
    • Validates file exists within results directory

    Errors:

    • 400: If not a JSON file or invalid JSON
    • 401: If secret configured but missing/incorrect
    • 403: If path escapes results directory
    • 404: If file not found
    • 500: If error reading file

    Usage Examples¶

    Basic Usage¶

    import os
from simpleaudit.visualization.server import start_server

# Set optional authentication
os.environ["SIMPLEAUDIT_VISUALIZER_SECRET"] = "my-secret-key"
os.environ["SIMPLEAUDIT_VISUALIZER_EMAIL"] = "admin@example.com"

# Start server
start_server(results_dir="./audit_results", port=8080)

    With Authentication¶

    When secret is configured, all API endpoints (except /api/auth) require the X-Secret header:

    import requests

# Check auth status
response = requests.get("http://127.0.0.1:8080/api/auth")
print(response.json())
# {'ok': True, 'enabled': True, 'contact_email': 'admin@example.com'}

# Get files with secret
headers = {"X-Secret": "my-secret-key"}
response = requests.get("http://127.0.0.1:8080/api/files", headers=headers)
print(response.json())

# Get specific JSON file
response = requests.get(
    "http://127.0.0.1:8080/api/json/audit_2024.json",
    headers=headers
)
print(response.json())

    Without Authentication¶

    If SIMPLEAUDIT_VISUALIZER_SECRET is not set or empty, authentication is disabled:

    from simpleaudit.visualization.server import start_server

# No secret set
start_server(results_dir="./audit_results")

# Access without headers
import requests
response = requests.get("http://127.0.0.1:8000/api/files")
print(response.json())

    File Structure¶

    The server expects the following files in the same directory as server.py:

    • visualizer.html: Main visualization page
    • scenario_viewer.html: Standalone scenario viewer
    • thumbnail.png: Favicon image

    Security Considerations¶

    1. Path Traversal Prevention: The /api/json/{file_path} endpoint validates that requested paths do not escape the results directory using os.path.normpath and prefix checking.

    2. JSON Validation: Only files containing valid audit results (non-empty arrays or objects with results key) are included in the file tree.

    3. Authentication: When enabled, all API endpoints require the correct X-Secret header. The /api/auth endpoint allows clients to check if authentication is enabled and retrieve the contact email.

    4. Local Binding: Default host is 127.0.0.1, binding only to localhost. Change host parameter for network access.

    Error Handling¶

    The server handles various error conditions:

    • Missing results directory: Returns 404 or prints error message
    • Invalid JSON files: Excluded from file tree, return 400 when accessed directly
    • Path traversal attempts: Return 403
    • Missing authentication: Return 401
    • Missing template files: Return 500
