    Visualization server

    Visualization Server¶

    SimpleAudit includes a local web server for visualizing audit results. Built on FastAPI and Uvicorn, this module serves an interactive interface to explore JSON output files. The server binds to a local host by default, ensuring secure access to sensitive audit data.

    Overview¶

    The visualization/server.py module provides:

    • FastAPI Application: app instance titled "SimpleAudit Visualizer".
    • File Tree API: Recursive scanning of result directories for valid JSON files.
    • Authentication: Optional secret-based access control via environment variables.
    • Static Assets: Serves HTML templates, favicon, and JSON data.

    Configuration¶

    Configuration occurs via environment variables. The server reads these values at startup.

    Variable Description Default
    SIMPLEAUDIT_VISUALIZER_SECRET Authentication key. If set, requests require X-Secret header. "" (disabled)
    SIMPLEAUDIT_VISUALIZER_EMAIL Contact email displayed in frontend when auth enabled. sushant@simula.no

    Starting the Server¶

    Use start_server to launch the Uvicorn server.

    from simpleaudit.visualization.server import start_server

# Start server on localhost port 8000
start_server(
    results_dir="./audit_results",
    host="127.0.0.1",
    port=8000
)

    Parameters:

    • results_dir (str): Path to directory containing JSON result files. Must exist.
    • host (str): Network interface to bind. Default "127.0.0.1".
    • port (int): TCP port. Default 8000.

    Behavior:

    1. Resolves results_dir to absolute path.
    2. Validates directory existence.
    3. Prints startup info to console.
    4. Runs Uvicorn with log_level="info".

    API Endpoints¶

    All API endpoints support optional authentication. If SIMPLEAUDIT_VISUALIZER_SECRET is set, requests must include header X-Secret: <your_secret>.

    GET /¶

    Serves main visualization page.

    • Response: HTMLResponse
    • Content: visualizer.html template.
    • Error: 500 if template missing.

    GET /scenario_viewer.html¶

    Serves standalone scenario viewer.

    • Response: HTMLResponse
    • Content: scenario_viewer.html template.
    • Error: 500 if template missing.

    GET /favicon.png¶

    Serves application icon.

    • Response: FileResponse (PNG image).
    • Source: thumbnail.png in module directory.
    • Error: 404 if file missing.

    GET /api/auth¶

    Verifies authentication status. Frontend uses this to determine if login overlay required.

    • Auth: Checked. Returns 401 if secret mismatch.
    • Response: JSONResponse
    {
  "ok": true,
  "enabled": true,
  "contact_email": "user@example.com"
}
    • enabled: true if SIMPLEAUDIT_VISUALIZER_SECRET set.
    • contact_email: Value from SIMPLEAUDIT_VISUALIZER_EMAIL.

    GET /api/files¶

    Retrieves file tree of valid audit JSON files.

    • Auth: Required if secret configured.
    • Response: JSONResponse
    {
  "tree": [
    {
      "name": "folder_name",
      "type": "folder",
      "path": "folder_name",
      "children": [
        {
          "name": "result.json",
          "type": "file",
          "path": "folder_name/result.json"
        }
      ]
    }
  ]
}
    • Logic:
      • Recursively scans RESULTS_DIR.
      • Includes only folders containing valid JSON files.
      • Validates JSON structure via is_valid_audit_json.

    GET /api/json/{file_path:path}¶

    Fetches content of specific JSON file.

    • Auth: Required if secret configured.
    • Path Parameter: file_path - Relative path from results root.
    • Response: JSONResponse containing file data.
    • Security:
      • Prevents directory traversal (../).
      • Rejects non-.json files.
      • Returns 403 for path escape attempts.
      • Returns 404 if file missing.
      • Returns 400 for invalid JSON.

    Validation Logic¶

    The server validates JSON files before listing them. Function is_valid_audit_json checks:

    1. File parses as valid JSON.
    2. Data is either:
      • Non-empty list.
      • Dictionary with non-empty results list.

    Invalid files excluded from file tree.

    Authentication Flow¶

    1. No Secret: SIMPLEAUDIT_VISUALIZER_SECRET empty.

      • check_secret returns immediately.
      • All endpoints accessible.
      • /api/auth returns {"enabled": false}.

    2. Secret Configured:

      • Client sends X-Secret header.
      • Server compares header value to SECRET.
      • Mismatch raises HTTPException (401 Unauthorized).
      • Frontend displays contact email from /api/auth response.

    Internal Functions¶

    get_file_tree(directory, base_path)¶

    Recursively builds file tree structure.

    • Args:
      • directory: Absolute path to scan.
      • base_path: Relative path prefix.
    • Returns: List of dictionaries representing folders/files.
    • Sorting: Entries sorted alphabetically.
    • Filtering:
      • Directories included only if they contain valid JSON files.
      • Files must end with .json and pass validation.

    check_secret(request)¶

    Dependency function for FastAPI.

    • Logic:
      • If SECRET empty: no-op.
      • Else: Extract X-Secret header.
      • Raise 401 if header missing or mismatched.

    Example Usage¶

    Basic Setup:

    # No authentication
python -c "from simpleaudit.visualization.server import start_server; start_server('./results')"

    With Authentication:

    export SIMPLEAUDIT_VISUALIZER_SECRET="my_secure_key"
export SIMPLEAUDIT_VISUALIZER_EMAIL="admin@company.com"
python -c "from simpleaudit.visualization.server import start_server; start_server('./results')"

    API Request with Auth:

    curl -H "X-Secret: my_secure_key" http://127.0.0.1:8000/api/files

    Troubleshooting¶

    • Port in use: Change port parameter in start_server.
    • Directory not found: Ensure results_dir path exists and is absolute or relative to current working directory.
    • Empty file tree: Verify JSON files match validation criteria (non-empty list or results key).
    • 401 Unauthorized: Check X-Secret header matches environment variable value.

    Security Notes¶

    • Server binds to 127.0.0.1 by default. Do not expose to public networks without additional security measures.
    • Path traversal protection implemented in /api/json endpoint.
    • Environment variables read at server start. Restart server to change secrets.
