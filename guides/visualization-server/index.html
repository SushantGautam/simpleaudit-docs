    Visualization server

    Visualization Server¶

    SimpleAudit includes a local web server for viewing audit results and metrics. Built on FastAPI, the server renders interactive visualizations of JSON result files. It supports single-run results and multi-model experiments. Authentication optional.

    Overview¶

    The server serves static HTML templates and provides API endpoints for file discovery and data retrieval. It scans a configured results directory recursively. Valid JSON files containing audit data appear in the file tree. The frontend renders charts and tables based on the JSON structure.

    Key Features: * File Tree API: Recursively lists JSON files and folders. * Data Endpoint: Serves specific JSON files for visualization. * Authentication: Optional secret-based access control. * Standalone Export: Generates self-contained HTML files with inlined data. * Experiment Support: Detects multi-model run structures.

    Configuration¶

    Configure the server via environment variables.

    Variable Default Description
    SIMPLEAUDIT_VISUALIZER_SECRET "" Authentication secret. If empty, auth disabled.
    SIMPLEAUDIT_VISUALIZER_EMAIL "sushant@simula.no" Contact email displayed when auth enabled.

    Set the results directory programmatically before starting the server:

    from simpleaudit.visualization.server import app, RESULTS_DIR
import os

# Set the directory containing audit result JSON files
RESULTS_DIR = "/path/to/results"

    API Endpoints¶

    GET /¶

    Serves the main visualization page (visualizer.html). Returns 500 if template missing.

    GET /scenario_viewer.html¶

    Serves the standalone scenario viewer page.

    GET /favicon.png¶

    Serves the application favicon (thumbnail.png). Returns 404 if missing.

    GET /api/auth¶

    Checks authentication status.

    • Response: JSON object.
      • ok: Boolean.
      • enabled: Boolean. True if SIMPLEAUDIT_VISUALIZER_SECRET set.
      • contact_email: String. Value of SIMPLEAUDIT_VISUALIZER_EMAIL.

    GET /api/files¶

    Retrieves the file tree of the results directory.

    • Authentication: Requires X-Secret header if auth enabled.
    • Response: JSON object with tree key.
    • Tree Node Structure:
      • name: String. File or folder name.
      • type: String. "folder", "file", or "experiment".
      • path: String. Relative path from results root.
      • children: List. Only for folders.
      • models: List. Only for experiments. Model labels with loadable runs.

    GET /api/json/{file_path}¶

    Retrieves contents of a specific JSON file.

    • Authentication: Requires X-Secret header if auth enabled.
    • Path Parameter: file_path - Relative path to JSON file.
    • Security: Prevents directory traversal. Path must resolve within RESULTS_DIR.
    • Response: JSON file contents.
    • Errors:
      • 400: Invalid path or not a JSON file.
      • 403: Access denied (path traversal attempt).
      • 404: File not found.
      • 500: Results directory not set.

    Data Validation¶

    The server validates JSON structure before serving. Valid data must match one of these shapes:

    1. Legacy: List of audit result objects. 

      [
  {"scenario_name": "test", "severity": "high"},
  {"scenario_name": "test2", "severity": "low"}
]

    2. Current: Object with results list. 

      {
  "results": [
    {"scenario_name": "test", "severity": "high"}
  ]
}

    3. Experiment: Object with runs dictionary. 

      {
  "runs": {
    "model_a": [
      {"results": [{"scenario_name": "test", "severity": "high"}]}
    ]
  }
}

    Validation Logic: * _looks_like_audit_result(obj): Checks for scenario_name or name key AND severity key. * _experiment_models(data): Extracts model labels from runs dict. A model is valid if it contains at least one run with a non-empty results list of valid audit objects. * is_valid_audit_data(data): Returns True if data matches any valid shape. * is_valid_audit_json(file_path): Reads file and validates content.

    Standalone HTML Export¶

    Generate a self-contained HTML file with inlined audit data. No server required for viewing.

    Function: export_standalone_html(json_path, output_path)

    • Parameters:
      • json_path (str): Path to valid audit results JSON.
      • output_path (str): Destination for generated HTML file.
    • Returns: Output path string.
    • Raises: ValueError if JSON invalid or template missing </head> anchor.

    Implementation Details: 1. Loads and validates JSON. 2. Reads visualizer.html template. 3. Escapes JSON payload to prevent script injection. 4. Injects data into window.__inlinedData, window.__inlinedName, and window.__standaloneMode. 5. Writes modified HTML to output_path.

    Example Usage:

    from simpleaudit.visualization.server import export_standalone_html

# Create standalone HTML from results
output_file = export_standalone_html(
    json_path="results/audit_2023.json",
    output_path="reports/audit_2023.html"
)
print(f"Standalone report created: {output_file}")

    Authentication¶

    When SIMPLEAUDIT_VISUALIZER_SECRET is set, all API endpoints (except /api/auth) require authentication.

    Mechanism: * Client sends X-Secret header with the secret value. * Server compares header value to configured secret using secrets.compare_digest. * Comparison uses UTF-8 encoded bytes to prevent timing attacks and handle non-ASCII characters safely. * Mismatch returns 401 Unauthorized.

    Example Request:

    curl -H "X-Secret: my-secret-key" http://localhost:8000/api/files

    Running the Server¶

    Start the server using Uvicorn.

    import uvicorn
from simpleaudit.visualization.server import app, RESULTS_DIR

# Configure results directory
RESULTS_DIR = "/path/to/audit/results"

# Start server
if __name__ == "__main__":
    uvicorn.run(app, host="127.0.0.1", port=8000)

    Access the visualizer at http://127.0.0.1:8000.

    Troubleshooting¶

    • 500 Error on /: Ensure visualizer.html exists in the same directory as server.py.
    • Empty File Tree: Verify RESULTS_DIR is set and contains valid JSON files.
    • 403 on JSON Endpoint: Check for path traversal attempts. Ensure file_path is relative and does not escape RESULTS_DIR.
    • Auth Failures: Verify X-Secret header matches SIMPLEAUDIT_VISUALIZER_SECRET. Check for trailing whitespace in environment variables.
