    Visualization server

    Visualization Server¶

    The visualization module provides a local web interface for viewing SimpleAudit results and metrics. Built on FastAPI and Uvicorn, this server serves a single-page application (SPA) that renders audit data from JSON files. It supports optional authentication via a shared secret and provides a REST API for retrieving file trees and raw JSON content.

    Overview¶

    The server scans a specified directory for valid audit result JSON files. It validates these files to ensure they contain either a non-empty array or an object with a results array. The frontend consumes the API to display a file tree and render specific audit results.

    Key features: - File Tree API: Recursively lists JSON files, filtering out invalid or empty results. - Authentication: Optional protection via X-Secret header. - Security: Prevents directory traversal attacks. - Configuration: Configurable via environment variables.

    Configuration¶

    The server reads configuration from environment variables. These can be set before starting the server or passed to the start_server function (which re-reads them).

    Variable Description Default
    SIMPLEAUDIT_VISUALIZER_SECRET Secret string required in X-Secret header. If empty, authentication is disabled. ""
    SIMPLEAUDIT_VISUALIZER_EMAIL Contact email displayed in the frontend when authentication is enabled. "sushant@simula.no"

    Public API¶

    start_server(results_dir, host, port)¶

    Starts the FastAPI server using Uvicorn.

    Parameters: - results_dir (str): Path to the directory containing JSON result files. Resolved relative to the current working directory. - host (str): Host address to bind to. Default: "127.0.0.1". - port (int): Port number to listen on. Default: 8000.

    Behavior: 1. Resolves results_dir to an absolute path. 2. Validates that the directory exists. 3. Re-reads SIMPLEAUDIT_VISUALIZER_SECRET and SIMPLEAUDIT_VISUALIZER_EMAIL from the environment. 4. Starts the Uvicorn server.

    Example: 

    from simpleaudit.visualization.server import start_server

# Start server on localhost:8000, scanning ./results
start_server("./results", host="127.0.0.1", port=8000)

    is_valid_audit_json(file_path)¶

    Checks if a JSON file contains valid audit results.

    Parameters: - file_path (str): Full path to the JSON file.

    Returns: - bool: True if the file contains a non-empty list or a dict with a non-empty results list. False otherwise.

    Validation Logic: 1. File must be valid JSON. 2. Root element must be: - A list with length > 0, OR - A dict with a results key that is a list with length > 0.

    get_file_tree(directory, base_path)¶

    Recursively builds a tree structure of valid JSON files.

    Parameters: - directory (str): Full path to scan. - base_path (str): Relative path from the root results directory. Default: "".

    Returns: - List[Dict]: List of dictionaries representing folders and files. - Folder: {"name": str, "type": "folder", "path": str, "children": List[Dict]} - File: {"name": str, "type": "file", "path": str}

    Behavior: - Only includes folders that contain valid JSON files (directly or in subdirectories). - Only includes .json files that pass is_valid_audit_json. - Entries are sorted alphabetically.

    HTTP Endpoints¶

    The server exposes the following endpoints. All API endpoints (except /api/auth) require authentication if SIMPLEAUDIT_VISUALIZER_SECRET is set.

    GET /¶

    Serves the main visualization HTML page (visualizer.html).

    GET /scenario_viewer.html¶

    Serves the standalone scenario viewer page.

    GET /favicon.png¶

    Serves the favicon (thumbnail.png).

    GET /api/auth¶

    Checks authentication status.

    Headers: - X-Secret: (Optional) Secret string. Required if authentication is enabled.

    Response: 

    {
  "ok": true,
  "enabled": false,
  "contact_email": "sushant@simula.no"
}
    - enabled: true if SIMPLEAUDIT_VISUALIZER_SECRET is set. - contact_email: Value of SIMPLEAUDIT_VISUALIZER_EMAIL.

    Status Codes: - 200: Success. - 401: Unauthorized (if secret is set and X-Secret header is missing or incorrect).

    GET /api/files¶

    Retrieves the file tree of valid JSON files in the results directory.

    Headers: - X-Secret: (Optional) Secret string.

    Response: 

    {
  "tree": [
    {
      "name": "run_1",
      "type": "folder",
      "path": "run_1",
      "children": [
        {
          "name": "results.json",
          "type": "file",
          "path": "run_1/results.json"
        }
      ]
    }
  ]
}

    Status Codes: - 200: Success. - 401: Unauthorized. - 404: Results directory not found. - 500: Results directory not set.

    GET /api/json/{file_path}¶

    Retrieves the contents of a specific JSON file.

    Path Parameters: - file_path: Relative path to the JSON file within the results directory.

    Headers: - X-Secret: (Optional) Secret string.

    Response: The raw JSON content of the file.

    Security: - Prevents directory traversal. Paths must resolve within RESULTS_DIR. - Only serves .json files.

    Status Codes: - 200: Success. - 400: Invalid JSON or not a JSON file. - 401: Unauthorized. - 403: Access denied (path traversal attempt). - 404: File not found. - 500: Error reading file.

    Usage Example¶

    1. Set Environment Variables: 

      export SIMPLEAUDIT_VISUALIZER_SECRET="my-secret-key"
export SIMPLEAUDIT_VISUALIZER_EMAIL="dev@example.com"

    2. Start Server: 

      from simpleaudit.visualization.server import start_server

start_server("./audit_results", host="0.0.0.0", port=8080)

    3. Access Web Interface:

    4. Open http://localhost:8080 in a browser.
    5. If authentication is enabled, the frontend will prompt for the secret.
    6. Use the file tree to select an audit result.
    7. The frontend fetches /api/json/{file_path} with the X-Secret header to display results.

    Security Notes¶

    • Directory Traversal: The /api/json/{file_path} endpoint uses os.path.normpath and checks if the resolved path starts with the results directory to prevent accessing files outside the intended scope.
    • Authentication: If SIMPLEAUDIT_VISUALIZER_SECRET is set, all API requests (except /api/auth) must include the X-Secret header with the correct value. The frontend handles this by storing the secret in memory and adding it to API requests.
    • Local Binding: By default, the server binds to 127.0.0.1. Use caution when binding to 0.0.0.0 or other external interfaces, especially without authentication.
