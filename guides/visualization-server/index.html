    Visualization server

    Visualization Server¶

    FastAPI web interface viewing SimpleAudit results metrics. Local server. No external dependencies beyond fastapi uvicorn.

    Overview¶

    visualization/server.py provides HTTP endpoints serving audit JSON files. Renders visualizer.html scenario_viewer.html. Recursively scans results directory. Validates JSON structure. Optional authentication via secret header.

    Configuration¶

    Server reads environment variables at startup.

    Variable Default Description
    SIMPLEAUDIT_VISUALIZER_SECRET "" Auth token. Blank disables auth.
    SIMPLEAUDIT_VISUALIZER_EMAIL sushant@simula.no Contact email shown in frontend.

    Core Functions¶

    start_server(results_dir, host="127.0.0.1", port=8000)¶

    Starts FastAPI server.

    Parameters:

    • results_dir (str): Path containing JSON result files.
    • host (str): Bind address. Default 127.0.0.1.
    • port (int): Port number. Default 8000.

    Behavior:

    1. Reads env vars.
    2. Resolves results_dir absolute path.
    3. Validates directory existence.
    4. Prints server URL.
    5. Runs uvicorn.

    Example:

    from simpleaudit.visualization.server import start_server

start_server("./results", port=8080)

    is_valid_audit_json(file_path)¶

    Validates JSON file structure.

    Returns:

    • True: File contains non-empty list OR dict with non-empty results list.
    • False: Invalid JSON, empty data, or IO error.

    Logic:

    • Accepts [...]
    • Accepts {"results": [...]}
    • Rejects other structures.

    get_file_tree(directory, base_path="")¶

    Recursively builds file tree.

    Returns:

    • List of dicts.
    • Folder dict: {"name", "type": "folder", "path", "children"}
    • File dict: {"name", "type": "file", "path"}

    Filters:

    • Includes only .json files.
    • Includes only valid audit JSON files.
    • Excludes empty folders.

    HTTP Endpoints¶

    GET /¶

    Serves main visualization page.

    • Loads visualizer.html.
    • Returns HTMLResponse.
    • Returns 500 if template missing.

    GET /scenario_viewer.html¶

    Serves standalone scenario viewer.

    • Loads scenario_viewer.html.
    • Returns HTMLResponse.

    GET /favicon.png¶

    Serves favicon.

    • Loads thumbnail.png.
    • Returns FileResponse.
    • Returns 404 if missing.

    GET /api/auth¶

    Checks authentication status.

    Response:

    {
  "ok": true,
  "enabled": false,
  "contact_email": "sushant@simula.no"
}
    • enabled: True if SECRET set.
    • contact_email: From env var.

    Auth Behavior:

    • If SECRET set, requires X-Secret header.
    • Returns 401 if header missing/wrong.

    GET /api/files¶

    Retrieves file tree.

    Security:

    • Requires X-Secret if auth enabled.

    Response:

    {
  "tree": [
    {
      "name": "folder1",
      "type": "folder",
      "path": "folder1",
      "children": []
    }
  ]
}

    Errors:

    • 500: Results directory not set.
    • 404: Results directory missing.

    GET /api/json/{file_path}¶

    Retrieves specific JSON file content.

    Path Parameter:

    • file_path: Relative path from results root.

    Security:

    • Requires X-Secret if auth enabled.
    • Prevents path traversal.
    • Ensures path stays within RESULTS_DIR.

    Validation:

    • Must exist.
    • Must end with .json.
    • Must be valid JSON.

    Response:

    • Raw JSON data from file.

    Errors:

    • 403: Path escapes results directory.
    • 404: File not found.
    • 400: Not JSON file OR invalid JSON syntax.
    • 500: Read error.

    Authentication¶

    Optional security layer.

    Enable:

    Set SIMPLEAUDIT_VISUALIZER_SECRET environment variable.

    Usage:

    1. Client sends X-Secret header.
    2. Header value must match env var.
    3. Mismatch returns 401 Unauthorized.

    Example Request:

    curl -H "X-Secret: my-secret-key" http://localhost:8000/api/files

    Frontend Integration:

    • Frontend calls /api/auth.
    • If enabled: true, displays login overlay.
    • Overlay shows contact_email.
    • User enters secret.
    • Frontend stores secret for subsequent API calls.

    File Structure Requirements¶

    Results directory must contain JSON files.

    Valid Structures:

    1. Array: 

      [
  {"metric": "value"}
]

    2. Object with Results: 

      {
  "metadata": "info",
  "results": [
    {"metric": "value"}
  ]
}

    Invalid Structures:

    • Empty arrays []
    • Objects without results key
    • Non-JSON files
    • Malformed JSON

    Error Handling¶

    Server handles common errors gracefully.

    Status Code Condition
    400 Invalid JSON syntax OR non-JSON file extension
    401 Missing/incorrect X-Secret header
    403 Path traversal attempt
    404 File/directory not found
    500 Server internal error OR missing template

    Development Notes¶

    • Uses uvicorn ASGI server.
    • Static HTML files located in visualization/ directory.
    • RESULTS_DIR global variable updated by start_server.
    • Environment variables re-read in start_server to support testing.
    • Path normalization prevents directory escape attacks.

    Example Usage¶

    1. Prepare Results:

    Create ./results/audit1.json:

    {
  "results": [
    {"test": "pass", "time": 0.5}
  ]
}

    2. Start Server:

    import os
os.environ["SIMPLEAUDIT_VISUALIZER_SECRET"] = "dev-secret"

from simpleaudit.visualization.server import start_server

start_server("./results", host="0.0.0.0", port=8000)

    3. Access Interface:

    • Open http://localhost:8000
    • Enter secret dev-secret if prompted.
    • Browse file tree.
    • Click JSON file to view data.

    4. API Access:

    # Check auth status
curl http://localhost:8000/api/auth

# Get file tree
curl -H "X-Secret: dev-secret" http://localhost:8000/api/files

# Get specific file
curl -H "X-Secret: dev-secret" http://localhost:8000/api/json/audit1.json

    Troubleshooting¶

    "Results directory not set"

    • Ensure start_server called before accessing API.
    • Verify results_dir path valid.

    "Access denied"

    • Check file_path parameter.
    • Ensure no ../ sequences.
    • Verify file exists within results root.

    Auth failing

    • Verify SIMPLEAUDIT_VISUALIZER_SECRET env var set.
    • Check X-Secret header spelling.
    • Ensure header value matches env var exactly.

    Template not found

    • Verify visualizer.html exists in visualization/ folder.
    • Check file permissions.

    Security Considerations¶

    • Path Traversal: Blocked via os.path.normpath check.
    • File Access: Restricted to .json files only.
    • Authentication: Optional. Disable by leaving secret blank.
    • Local Binding: Default 127.0.0.1 prevents external access. Change host only if needed.

    Dependencies¶

    • fastapi
    • uvicorn
    • pydantic (via FastAPI)

    Install:

    pip install fastapi uvicorn
