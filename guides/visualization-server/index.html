    Visualization server

    Visualization Server¶

    SimpleAudit Visualization Server FastAPI application. Serves local dashboard for inspecting audit results. Renders JSON data interactive web interface. Supports optional authentication via secret key.

    Overview¶

    Module visualization/server.py exposes HTTP API. Binds local host. Serves static HTML templates. Scans directory tree for valid JSON files. Returns file structure data. Frontend fetches JSON content renders visualizations.

    Server uses uvicorn ASGI server. Default port 8000. Default host 127.0.0.1. Security path traversal prevention. File validation checks.

    Configuration¶

    Configuration via environment variables. Set before starting server.

    Variable Default Description
    SIMPLEAUDIT_VISUALIZER_SECRET "" Authentication token. Blank disables auth.
    SIMPLEAUDIT_VISUALIZER_EMAIL sushant@simula.no Contact email shown in UI when auth enabled.

    Public Functions¶

    start_server(results_dir, host, port)¶

    Starts FastAPI application. Blocks execution until server stops.

    Parameters:

    • results_dir (str): Path directory containing JSON result files. Relative paths resolve from current working directory.
    • host (str): Network interface bind address. Default "127.0.0.1".
    • port (int): TCP port number. Default 8000.

    Behavior:

    1. Reads environment variables SIMPLEAUDIT_VISUALIZER_SECRET, SIMPLEAUDIT_VISUALIZER_EMAIL.
    2. Resolves results_dir absolute path.
    3. Validates directory existence.
    4. Prints startup information console.
    5. Launches uvicorn server.

    Example:

    from simpleaudit.visualization.server import start_server

# Start server on default port
start_server("results/audit_run_01")

# Custom host and port
start_server("./output", host="0.0.0.0", port=9000)

    Error Handling:

    • Prints error message if directory missing.
    • Returns None silently on failure.
    • Does not raise exceptions for invalid paths.

    is_valid_audit_json(file_path)¶

    Validates JSON file structure. Checks content matches SimpleAudit result format.

    Parameters:

    • file_path (str): Full path JSON file.

    Returns:

    • bool: True if valid audit results, False otherwise.

    Validation Logic:

    1. File must parse valid JSON.
    2. Root object must be list with length > 0.
    3. OR root object must be dict containing key results.
    4. results value must be list with length > 0.

    Example:

    from simpleaudit.visualization.server import is_valid_audit_json

valid = is_valid_audit_json("path/to/results.json")
# Returns True if file contains valid audit data

    get_file_tree(directory, base_path)¶

    Recursively scans directory structure. Builds nested dictionary representation.

    Parameters:

    • directory (str): Full path scan directory.
    • base_path (str): Relative path prefix. Default "".

    Returns:

    • List[Dict]: List folder/file nodes.

    Node Structure:

    • Folder node: 
      {
  "name": "folder_name",
  "type": "folder",
  "path": "relative/path",
  "children": [ ... ]
}
    • File node: 
      {
  "name": "file.json",
  "type": "file",
  "path": "relative/path/file.json"
}

    Filtering:

    • Includes only .json files.
    • Validates JSON content via is_valid_audit_json.
    • Excludes empty folders.
    • Ignores permission errors.

    HTTP Endpoints¶

    Server exposes REST API endpoints. Frontend consumes these.

    GET /¶

    Serves main visualization HTML page.

    • Response: HTMLResponse
    • Status: 200 OK, 500 if template missing.

    GET /scenario_viewer.html¶

    Serves standalone scenario viewer page.

    • Response: HTMLResponse
    • Status: 200 OK, 500 if template missing.

    GET /favicon.png¶

    Serves application icon.

    • Response: FileResponse (PNG image)
    • Status: 200 OK, 404 if file missing.

    GET /api/auth¶

    Checks authentication status. Frontend calls this on load.

    • Headers: X-Secret (optional, required if auth enabled).
    • Response: 
      {
  "ok": true,
  "enabled": false,
  "contact_email": "sushant@simula.no"
}
    • Status:
      • 200: Auth check passed or disabled.
      • 401: Secret configured but missing/incorrect header.

    GET /api/files¶

    Retrieves file tree structure.

    • Auth: Requires X-Secret header if enabled.
    • Response: 
      {
  "tree": [ ... ]
}
    • Status:
      • 200: Success.
      • 401: Unauthorized.
      • 404: Results directory not found.
      • 500: Results directory not set.

    GET /api/json/{file_path}¶

    Retrieves specific JSON file content.

    • Path Parameter: file_path relative path from results directory.
    • Auth: Requires X-Secret header if enabled.
    • Response: Raw JSON data from file.
    • Status:
      • 200: Success.
      • 400: Not JSON file or invalid JSON syntax.
      • 401: Unauthorized.
      • 403: Path traversal attempt detected.
      • 404: File not found.
      • 500: Read error.

    Security Note:

    Endpoint prevents directory traversal attacks. Validates resolved path stays within RESULTS_DIR. Rejects paths escaping root directory.

    Authentication¶

    Authentication optional. Enabled via SIMPLEAUDIT_VISUALIZER_SECRET environment variable.

    Mechanism:

    1. Server reads secret from environment.
    2. Frontend displays password prompt if auth enabled.
    3. Frontend sends X-Secret header with all API requests.
    4. Server validates header matches secret.
    5. Mismatch returns 401 Unauthorized.

    Disabling Auth:

    Set SIMPLEAUDIT_VISUALIZER_SECRET empty string. Or do not set variable. Server skips validation.

    Contact Email:

    When auth enabled, frontend displays contact email. Value from SIMPLEAUDIT_VISUALIZER_EMAIL. Helps users request access to secret.

    Usage Example¶

    Complete workflow running visualization server.

    # 1. Set environment variables
export SIMPLEAUDIT_VISUALIZER_SECRET="my-secret-token"
export SIMPLEAUDIT_VISUALIZER_EMAIL="admin@example.com"

# 2. Start server via Python script
python -c "
from simpleaudit.visualization.server import start_server
start_server('results/2023-10-01')
"

    Terminal output:

    Starting SimpleAudit Visualizer...
Results directory: /home/user/project/results/2023-10-01
Server: http://127.0.0.1:8000
Press Ctrl+C to stop
INFO:     Started server process [12345]
INFO:     Waiting for application startup.
INFO:     Application startup complete.

    Open browser http://127.0.0.1:8000. Enter secret my-secret-token if prompted. Browse file tree. Click JSON files view visualizations.

    Troubleshooting¶

    Port Already In Use:

    Change port parameter.

    start_server("results", port=8001)

    Directory Not Found:

    Check path relative to current working directory. Use absolute paths for clarity.

    start_server("/absolute/path/to/results")

    Invalid JSON Files Ignored:

    Files failing is_valid_audit_json check do not appear in tree. Verify JSON structure matches SimpleAudit output format. Root must be list or dict with results list.

    Authentication Failing:

    Verify X-Secret header matches environment variable exactly. Check for whitespace characters. Ensure frontend sends header with all API requests.
