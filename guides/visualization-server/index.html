    Visualization server

    Visualization Server¶

    SimpleAudit includes local web server module visualization/server.py. Built with FastAPI and uvicorn. Serves interactive interface for exploring audit results. Loads JSON files from specified directory. Provides file tree navigation and data retrieval endpoints. Supports optional authentication via environment variables.

    Overview¶

    Server binds to 127.0.0.1:8000 by default. Serves static HTML templates: - visualizer.html: Main dashboard. - scenario_viewer.html: Standalone viewer. - thumbnail.png: Favicon.

    Server scans results directory recursively. Filters files: - Must end .json. - Must contain valid audit data (non-empty array or object with results key).

    Invalid JSON files ignored. Directory structure preserved in API response.

    Configuration¶

    Server reads configuration from environment variables at startup.

    Variable Default Description
    SIMPLEAUDIT_VISUALIZER_SECRET "" Auth token. If empty, auth disabled. If set, requests require X-Secret header.
    SIMPLEAUDIT_VISUALIZER_EMAIL sushant@simula.no Contact email displayed in frontend when auth enabled.

    Public API¶

    start_server¶

    Initializes and runs the FastAPI application.

    def start_server(results_dir: str, host: str = "127.0.0.1", port: int = 8000)

    Parameters:

    • results_dir (str): Path to directory containing JSON result files. Relative paths resolved against current working directory.
    • host (str): Network interface to bind. Default "127.0.0.1".
    • port (int): Port number. Default 8000.

    Behavior: 1. Resolves results_dir to absolute path. 2. Validates directory exists and is a directory. 3. Prints startup information to console. 4. Starts uvicorn server. Blocks execution until stopped.

    Example:

    from simpleaudit.visualization.server import start_server

# Start server on default host/port
start_server("./audit_results")

# Start server on specific port
start_server("/path/to/results", host="0.0.0.0", port=8080)

    HTTP Endpoints¶

    All API endpoints prefixed /api/. Static assets served at root.

    GET /¶

    Serves main visualization page (visualizer.html).

    • Response: text/html
    • Status: 200 OK or 500 Internal Server Error if template missing.

    GET /scenario_viewer.html¶

    Serves standalone scenario viewer page.

    • Response: text/html
    • Status: 200 OK or 500 Internal Server Error if template missing.

    GET /favicon.png¶

    Serves favicon image.

    • Response: image/png
    • Status: 200 OK or 404 Not Found.

    GET /api/auth¶

    Checks authentication status. Used by frontend to determine if login required.

    • Headers: X-Secret (optional, required if auth enabled).
    • Response: application/json 
      {
  "ok": true,
  "enabled": false,
  "contact_email": "sushant@simula.no"
}
    • Status:
    • 200 OK: Auth check passed or auth disabled.
    • 401 Unauthorized: Secret configured but missing/incorrect X-Secret header.

    GET /api/files¶

    Retrieves file tree structure of valid JSON files in results directory.

    • Headers: X-Secret (required if auth enabled).
    • Response: application/json 
      {
  "tree": [
    {
      "name": "folder_name",
      "type": "folder",
      "path": "folder_name",
      "children": [
        {
          "name": "result.json",
          "type": "file",
          "path": "folder_name/result.json"
        }
      ]
    }
  ]
}
    • Status:
    • 200 OK: Success.
    • 401 Unauthorized: Auth failed.
    • 404 Not Found: Results directory not found.
    • 500 Internal Server Error: Results directory not set.

    GET /api/json/{file_path}¶

    Retrieves contents of specific JSON file.

    • Path Parameter: file_path - Relative path from results directory.
    • Headers: X-Secret (required if auth enabled).
    • Response: application/json - Raw JSON data from file.
    • Status:
    • 200 OK: Success.
    • 400 Bad Request: File not JSON or invalid JSON.
    • 401 Unauthorized: Auth failed.
    • 403 Forbidden: Path traversal attempt detected.
    • 404 Not Found: File not found.
    • 500 Internal Server Error: Read error.

    Security Note: Server validates file_path to prevent directory traversal attacks. Path must remain within RESULTS_DIR.

    Authentication¶

    Authentication disabled by default. Enable by setting SIMPLEAUDIT_VISUALIZER_SECRET environment variable.

    Mechanism: 1. Server reads SIMPLEAUDIT_VISUALIZER_SECRET. 2. If non-empty, all /api/* endpoints require X-Secret header. 3. Header value must match secret exactly. 4. Frontend detects auth requirement via /api/auth endpoint. 5. Frontend displays contact email from SIMPLEAUDIT_VISUALIZER_EMAIL.

    Example Setup:

    export SIMPLEAUDIT_VISUALIZER_SECRET="my-secret-token"
export SIMPLEAUDIT_VISUALIZER_EMAIL="admin@example.com"
python -m simpleaudit.visualization.server

    Client Request:

    import requests

url = "http://127.0.0.1:8000/api/files"
headers = {"X-Secret": "my-secret-token"}

response = requests.get(url, headers=headers)
print(response.json())

    File Validation Logic¶

    Function is_valid_audit_json determines if file included in tree.

    Valid Conditions: 1. JSON parses successfully. 2. Data is list with length > 0. 3. Data is dict with key results containing list with length > 0.

    Invalid Conditions: 1. JSON parse error. 2. File not readable. 3. Data is empty list. 4. Data is dict without results key. 5. Data is dict with results key but value not list or empty list.

    Troubleshooting¶

    Server fails to start: - Check results_dir exists. - Check port not in use. - Check Python dependencies installed (fastapi, uvicorn).

    401 Unauthorized errors: - Verify X-Secret header present. - Verify header value matches SIMPLEAUDIT_VISUALIZER_SECRET. - Check environment variable set before server start.

    Empty file tree: - Verify JSON files valid per validation logic. - Check file permissions. - Ensure files end .json.

    Template not found: - Verify visualizer.html and scenario_viewer.html exist in visualization/ directory. - Check file permissions.
