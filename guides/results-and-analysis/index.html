    Results and analysis

    Results and Analysis¶

    SimpleAudit results subsystem processes raw audit events, stores persistent records, and generates analytical summaries. Module handles data transformation, database persistence, and statistical interpretation. Core components: ResultProcessor, ResultStore, Analyzer.

    Overview¶

    Audit pipeline produces raw events. Results module transforms events into structured records. Stores records in database. Analyzes stored data for patterns, anomalies, trends. Developers interact via ResultProcessor for ingestion, ResultStore for persistence, Analyzer for insights.

    Classes¶

    ResultProcessor¶

    Processes raw audit events. Validates, normalizes, enriches data.

    Constructor

    ResultProcessor(config: dict = None)
    • config: Optional configuration dictionary. Keys:
      • schema_version: String. Target schema version. Default "1.0".
      • enrichers: List of enricher class names. Default [].
      • validators: List of validator class names. Default [].

    Methods

    • process(event: dict) -> dict Processes single event. Returns normalized record. Raises ValidationError if invalid.
    • process_batch(events: list[dict]) -> list[dict] Processes list of events. Returns list of normalized records. Stops on first error.
    • validate(event: dict) -> bool Checks event against schema. Returns boolean.

    ResultStore¶

    Persists audit results to backend. Supports SQLite, PostgreSQL.

    Constructor

    ResultStore(connection_string: str, table_name: str = "audit_results")
    • connection_string: Database connection URI. Example: "sqlite:///audit.db".
    • table_name: Target table name. Default "audit_results".

    Methods

    • save(record: dict) -> int Inserts single record. Returns primary key ID.
    • save_batch(records: list[dict]) -> int Inserts multiple records. Returns count inserted.
    • query(filters: dict = None, limit: int = 100) -> list[dict] Retrieves records.
      • filters: Dictionary of field-value pairs. Example: {"user_id": 123, "status": "success"}.
      • limit: Max records to return. Default 100.
    • delete_before(date: datetime) -> int Removes records older than specified date. Returns count deleted.

    Analyzer¶

    Generates statistical insights from stored results.

    Constructor

    Analyzer(store: ResultStore)
    • store: Instance of ResultStore.

    Methods

    • summary(time_range: tuple[datetime, datetime] = None) -> dict Computes aggregate statistics.
      • time_range: Optional tuple (start, end). Default all time.
      • Returns dictionary:
        • total_events: Integer.
        • success_rate: Float (0.0-1.0).
        • avg_latency_ms: Float.
        • top_users: List of dictionaries.
    • anomalies(threshold: float = 3.0) -> list[dict] Detects statistical outliers.
      • threshold: Z-score threshold. Default 3.0.
      • Returns list of anomaly records.
    • trend(metric: str, interval: str = "hour") -> list[dict] Calculates time-series trend.
      • metric: Metric name. Example: "count", "latency".
      • interval: Aggregation interval. Options: "minute", "hour", "day".

    Configuration¶

    Processor configuration via dictionary:

    config = {
    "schema_version": "1.0",
    "enrichers": ["GeoIPEnricher", "UserContextEnricher"],
    "validators": ["SchemaValidator", "RangeValidator"]
}

    Store configuration via connection string:

    • SQLite: "sqlite:///path/to/db.sqlite"
    • PostgreSQL: "postgresql://user:pass@host:5432/dbname"

    Usage Examples¶

    Processing and Storing¶

    from simpleaudit.results import ResultProcessor, ResultStore
from datetime import datetime

# Initialize components
processor = ResultProcessor(config={"schema_version": "1.0"})
store = ResultStore("sqlite:///audit.db")

# Sample raw event
raw_event = {
    "timestamp": datetime.now().isoformat(),
    "user_id": 42,
    "action": "login",
    "status": "success",
    "ip_address": "192.168.1.1"
}

# Process event
processed = processor.process(raw_event)

# Store result
record_id = store.save(processed)
print(f"Stored record ID: {record_id}")

    Batch Processing¶

    events = [
    {"timestamp": "2023-10-01T10:00:00", "user_id": 1, "action": "view", "status": "success"},
    {"timestamp": "2023-10-01T10:00:01", "user_id": 2, "action": "edit", "status": "fail"}
]

processed_records = processor.process_batch(events)
count = store.save_batch(processed_records)
print(f"Inserted {count} records")

    Querying Results¶

    # Filter by user and status
results = store.query(filters={"user_id": 42, "status": "success"}, limit=10)

for record in results:
    print(record["timestamp"], record["action"])

    Analysis¶

    from datetime import timedelta

analyzer = Analyzer(store)

# Overall summary
stats = analyzer.summary()
print(f"Total events: {stats['total_events']}")
print(f"Success rate: {stats['success_rate']:.2%}")

# Recent anomalies
recent_start = datetime.now() - timedelta(days=7)
anomalies = analyzer.anomalies(threshold=2.5)
for anomaly in anomalies:
    print(f"Anomaly at {anomaly['timestamp']}: {anomaly['metric']}")

# Hourly trend
trend_data = analyzer.trend(metric="count", interval="hour")

    Data Schema¶

    Normalized record structure:

    Field Type Description
    id Integer Primary key. Auto-generated.
    timestamp String (ISO 8601) Event occurrence time.
    user_id Integer User identifier.
    action String Audit action type.
    status String Result status. Values: success, fail, pending.
    metadata JSON Additional context data.
    latency_ms Float Processing time in milliseconds.

    Error Handling¶

    • ValidationError: Raised by ResultProcessor.process() when event fails schema validation.
    • StoreError: Raised by ResultStore methods on database connection or write failures.
    • AnalysisError: Raised by Analyzer when data insufficient for calculation.

    Best Practices¶

    • Use process_batch() for high-volume ingestion. Reduces overhead.
    • Implement retention policy. Call store.delete_before() regularly.
    • Cache Analyzer results if querying same time range frequently.
    • Validate connection strings before initializing ResultStore.
    • Log ValidationError exceptions for debugging malformed events.

    File Structure¶

    • simpleaudit/results/__init__.py: Exports public classes.
    • simpleaudit/results/processor.py: ResultProcessor implementation.
    • simpleaudit/results/store.py: ResultStore implementation.
    • simpleaudit/results/analyzer.py: Analyzer implementation.
    • simpleaudit/results/schemas.py: Validation schemas.
